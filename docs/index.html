🗃️ 数据结构 线性表、树、图、排序、查找 ⚙️ 计算机组成原理 CPU、存储器、指令系统、I/O 💾 操作系统 进程、内存、文件、设备管理 🌐 计算机网络 TCP/IP、HTTP、路由、传输层

英语

📖 阅读理解 题型归纳、解题技巧、真题精读 🔍 长难句分析 句子成分、从句拆解、翻译方法 ✍️ 写作 应用文、短文、模板句型 🌏 翻译 英译中技巧、策略、真题练习 🔤 完形填空 词汇辨析、逻辑关系、解题步骤
🎯 CET-6 英语六级
🎧 六级听力 长对话、篇章、讲座 📚 六级阅读 选词填空、长篇、仔细阅读 🌍 六级翻译 汉译英、文化社会话题 📝 六级写作 议论文、说明文、应用文
📜

政治

专业课

📋 软件过程与项目管理 项目范围、进度、成本、质量、风险、配置管理
📅

备考计划

基础阶段

3月 – 6月

  • 数学：系统复习教材，完成课后习题
  • 英语：背单词，做真题阅读
  • 408：过一遍教材，建立知识框架

强化阶段

7月 – 9月

  • 数学：大量刷题，总结题型
  • 英语：真题二刷，整理写作模板
  • 408：深入理解，做练习题

冲刺阶段

10月 – 12月

  • 全真模拟，查漏补缺
  • 背诵政治，掌握时政
  • 调整心态，保持状态
