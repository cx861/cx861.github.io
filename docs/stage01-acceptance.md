## 本轮纠正

1. X均匀分布于(0,1)、Y=X(1−X)时，区间内部的分布函数应为1−√(1−4y)，不是√(1−4y)。
2. 同阶方阵有一侧逆即可推出可逆，左右验算是复核方法，不能宣称一侧逆不足。
3. 置信区间与双侧检验的对偶关系涉及参数假设值集合，不能直接说样本空间不拒绝域等于参数区间。
4. 笔记页没有MathJax，将阶段一6篇笔记中的裸TeX改为可直接阅读的符号。
5. 分类卡片、页首总数和各题组题数已按正文校对。
