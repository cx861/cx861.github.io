第一章 函数与极限

1.1 映射与函数

映射的概念

设 X、Y 是两个非空集合，如果存在一个法则 f，使得对 X 中每个元素 x，按法则 f，在 Y 中有唯一确定的元素 y 与之对应，则称 f 为从 X 到 Y 的映射。

函数的定义

函数是特殊的映射，其定义域和值域都是实数集的子集。

函数的特性

  • 有界性
  • 单调性
  • 奇偶性
  • 周期性

1.2 数列的极限

数列极限的定义

设 {xn} 为一数列，如果存在常数 a，对于任意给定的正数 ε（不论它多么小），总存在正整数 N，使得当 n > N 时，不等式 |xn - a| < ε 都成立，那么就称常数 a 是数列 {xn} 的极限。

收敛数列的性质

  • 唯一性
  • 有界性
  • 保号性

1.3 函数的极限

函数极限的定义

设函数 f(x) 在点 x0 的某去心邻域内有定义，如果存在常数 A，对于任意给定的正数 ε，总存在正数 δ，使得当 0 < |x - x0| < δ 时，有 |f(x) - A| < ε，则称 A 为函数 f(x) 当 x → x0 时的极限。

1.4 无穷小与无穷大

无穷小的定义

极限为零的变量称为无穷小。

无穷小的性质

  • 有限个无穷小的和、差、积仍是无穷小
  • 有界函数与无穷小的乘积是无穷小

1.5 极限存在准则

夹逼准则

如果数列 {xn}, {yn}, {zn} 满足 yn ≤ xn ≤ zn，且 lim yn = lim zn = a，则 lim xn = a。

两个重要极限

lim(x→0) sinx/x = 1
lim(x→∞) (1 + 1/x)^x = e

1.6 函数的连续性

连续的定义

设函数 f(x) 在点 x0 的某邻域内有定义，如果 lim(x→x0) f(x) = f(x0)，则称函数 f(x) 在点 x0 连续。

间断点的分类

  • 第一类间断点：可去间断点、跳跃间断点
  • 第二类间断点：无穷间断点、振荡间断点

注意：可导必连续，但连续不一定可导。

第二章 导数与微分

2.1 导数概念

导数的定义

f'(x₀) = lim(Δx→0) [f(x₀ + Δx) - f(x₀)] / Δx

导数的几何意义

切线的斜率。

2.2 函数的求导法则

基本初等函数的导数公式

  • (C)' = 0
  • (x^μ)' = μx^(μ-1)
  • (sinx)' = cosx
  • (cosx)' = -sinx
  • (e^x)' = e^x
  • (lnx)' = 1/x

四则运算法则

(u ± v)' = u' ± v'
(uv)' = u'v + uv'
(u/v)' = (u'v - uv')/v²

2.3 高阶导数

高阶导数的定义

f''(x) = [f'(x)]'

莱布尼茨公式

(uv)^(n) = Σ(k=0 to n) C(n,k) u^(k) v^(n-k)

2.4 隐函数及参数方程求导

隐函数求导

方程 F(x,y) = 0 确定的函数 y = f(x)，两边对 x 求导。

参数方程求导

x = φ(t), y = ψ(t)，则 dy/dx = ψ'(t)/φ'(t)

2.5 函数的微分

微分的定义

dy = f'(x)dx

第三章 微分中值定理与导数的应用

3.1 微分中值定理

罗尔定理

如果函数 f(x) 在 [a,b] 上连续，在 (a,b) 内可导，且 f(a) = f(b)，则存在 ξ ∈ (a,b)，使得 f'(ξ) = 0。

拉格朗日中值定理

如果函数 f(x) 在 [a,b] 上连续，在 (a,b) 内可导，则存在 ξ ∈ (a,b)，使得 f(b) - f(a) = f'(ξ)(b - a)。

柯西中值定理

如果函数 f(x) 和 g(x) 在 [a,b] 上连续，在 (a,b) 内可导，且 g'(x) ≠ 0，则存在 ξ ∈ (a,b)，使得 [f(b) - f(a)]/[g(b) - g(a)] = f'(ξ)/g'(ξ)。

3.2 洛必达法则

0/0 型和 ∞/∞ 型

lim f(x)/g(x) = lim f'(x)/g'(x)

3.3 泰勒公式

泰勒中值定理

f(x) = f(x₀) + f'(x₀)(x - x₀) + f''(x₀)(x - x₀)²/2! + ... + f^(n)(x₀)(x - x₀)^n/n! + R_n(x)

3.4 函数的单调性与极值

单调性判定

f'(x) > 0，单调递增；f'(x) < 0，单调递减。

极值的判定

  • 第一充分条件：导数由正变负为极大值，由负变正为极小值
  • 第二充分条件：f''(x₀) < 0 为极大值，f''(x₀) > 0 为极小值

3.5 曲线的凹凸性与拐点

凹凸性的判定

f''(x) > 0，凹；f''(x) < 0，凸。

拐点的定义

凹凸性改变的点。

第四章 不定积分

4.1 不定积分的概念与性质

原函数与不定积分

如果 F'(x) = f(x)，则 F(x) 是 f(x) 的一个原函数。不定积分：∫f(x)dx = F(x) + C

4.2 换元积分法

第一换元法（凑微分法）

∫f[φ(x)]φ'(x)dx = ∫f(u)du，其中 u = φ(x)

第二换元法

∫f(x)dx = ∫f[ψ(t)]ψ'(t)dt，其中 x = ψ(t)

4.3 分部积分法

分部积分公式

∫u dv = uv - ∫v du

第五章 定积分

5.1 定积分的概念与性质

定积分的定义

∫[a,b] f(x)dx = lim(λ→0) Σf(ξ_i)Δx_i

5.2 微积分基本公式

牛顿-莱布尼茨公式

∫[a,b] f(x)dx = F(b) - F(a)，其中 F'(x) = f(x)

5.3 定积分的换元法和分部积分法

换元法

∫[a,b] f(x)dx = ∫[α,β] f[φ(t)]φ'(t)dt

分部积分法

∫[a,b] u dv = [uv][a,b] - ∫[a,b] v du

5.4 反常积分

无穷限反常积分

∫[a,∞) f(x)dx = lim(b→∞) ∫[a,b] f(x)dx

第六章 定积分的应用

6.1 定积分在几何上的应用

平面图形的面积

  • 直角坐标系下：A = ∫[a,b] |f(x) - g(x)|dx
  • 极坐标系下：A = (1/2)∫[α,β] r²(θ)dθ

旋转体的体积

  • 圆盘法：V = π∫[a,b] f²(x)dx
  • 壳层法：V = 2π∫[a,b] x f(x)dx

第七章 微分方程

7.1 微分方程的基本概念

微分方程的定义

含有未知函数及其导数的方程。

阶、解、通解、特解

  • 阶：最高阶导数的阶数
  • 解：满足方程的函数
  • 通解：含有任意常数的解
  • 特解：确定了任意常数的解

7.2 可分离变量的微分方程

形式

f(x)dx = g(y)dy

解法

分离变量后两边积分。

7.3 一阶线性微分方程

形式

dy/dx + P(x)y = Q(x)

通解公式

y = e^(-∫P(x)dx)[∫Q(x)e^(∫P(x)dx)dx + C]

7.4 二阶常系数线性齐次微分方程

形式

y'' + py' + qy = 0

解法

特征方程：r² + pr + q = 0，根据特征根的情况写出通解。
