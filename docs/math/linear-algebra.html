第一章 行列式

1.1 二阶与三阶行列式

二阶行列式

a
b
c
d

= ad - bc

三阶行列式

对角线法则：实线上元素乘积之和减去虚线上元素乘积之和。

1.2 n阶行列式的定义

排列与逆序

  • 排列：由1到n的n个数组成的有序数组
  • 逆序：排列中逆序对的个数
  • 奇排列与偶排列：逆序数为奇数/偶数

n阶行列式的定义

D = Σ(-1)^τ(j₁j₂...jₙ) a₁ⱼ₁ a₂ⱼ₂ ... aₙⱼₙ

1.3 行列式的性质

  • 性质1：转置行列式相等，即 D = D^T
  • 性质2：互换两行（列），行列式变号
  • 性质3：某行（列）有公因子可提取
  • 性质4：两行（列）成比例，行列式为0
  • 性质5：行列式可按行（列）拆分
  • 性质6：某行（列）的k倍加到另一行（列），行列式不变

1.4 行列式按行（列）展开

余子式与代数余子式

  • 余子式 Mij：去掉第i行第j列后的行列式
  • 代数余子式 Aij = (-1)^(i+j) Mij

展开定理

D = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + ... + aᵢₙAᵢₙ
D = a₁ⱼA₁ⱼ + a₂ⱼA₂ⱼ + ... + aₙⱼAₙⱼ

1.5 克拉默法则

非齐次线性方程组

如果系数行列式 D ≠ 0，则方程组有唯一解：xj = Dj/D

齐次线性方程组

  • 如果 D ≠ 0，则只有零解
  • 如果有非零解，则 D = 0

注意：克拉默法则只适用于系数行列式非零的情况。

第二章 矩阵及其运算

2.1 矩阵的概念

矩阵的定义

m×n 个数排成的m行n列的数表。

特殊矩阵

  • 零矩阵：所有元素都是0
  • 单位矩阵：主对角线为1，其余为0
  • 对角矩阵：非主对角线元素都是0
  • 三角矩阵：上三角或下三角
  • 对称矩阵：A = A^T
  • 反对称矩阵：A = -A^T

2.2 矩阵的运算

矩阵的加法

对应元素相加。

数与矩阵相乘

数乘每个元素。

矩阵与矩阵相乘

第一个矩阵的列数等于第二个矩阵的行数，乘积矩阵的元素 cij = Σaik bkj

2.3 逆矩阵

逆矩阵的定义

AB = BA = E，则 B 是 A 的逆矩阵。

逆矩阵的性质

  • (A⁻¹)⁻¹ = A
  • (kA)⁻¹ = k⁻¹A⁻¹
  • (AB)⁻¹ = B⁻¹A⁻¹
  • (Aᵀ)⁻¹ = (A⁻¹)ᵀ

伴随矩阵法求逆

A⁻¹ = (1/|A|)A*

第三章 矩阵的初等变换与线性方程组

3.1 矩阵的初等变换

初等行变换

  • 互换两行
  • 某行乘以非零常数
  • 某行的k倍加到另一行

初等矩阵

单位矩阵经过一次初等变换得到的矩阵。

3.2 矩阵的秩

k阶子式

任取k行k列交叉元素构成的行列式。

秩的定义

矩阵中最高阶非零子式的阶数。

秩的性质

  • r(A) = r(Aᵀ)
  • r(AB) ≤ min{r(A), r(B)}

3.3 线性方程组的解

线性方程组的矩阵形式

Ax = b

齐次线性方程组

Ax = 0，有非零解的充要条件：r(A) < n

非齐次线性方程组

Ax = b，有解的充要条件：r(A) = r(A|b)

第四章 向量组的线性相关性

4.1 向量组及其线性组合

n维向量

n个数组成的有序数组。

线性组合与线性表示

向量b可由向量组A线性表示：存在k₁,k₂,...,km，使得b = k₁α₁ + k₂α₂ + ... + kmαm

4.2 向量组的线性相关性

线性相关与线性无关的定义

  • 线性相关：存在不全为零的k₁,k₂,...,km，使得k₁α₁ + k₂α₂ + ... + kmαm = 0
  • 线性无关：只有k₁=k₂=...=km=0时成立

线性相关性的判定

向量组构成的矩阵的秩 < 向量个数，线性相关；秩 = 向量个数，线性无关。

4.3 向量组的秩

极大线性无关组

向量组中部分向量构成的线性无关组，且能表示其余所有向量。

向量组的秩

极大线性无关组所含向量的个数。

第五章 相似矩阵及二次型

5.1 向量的内积

内积的定义

[x,y] = x₁y₁ + x₂y₂ + ... + xₙyₙ

向量的长度

||x|| = √[x,x]

正交向量组

向量两两正交且长度为1。

5.2 方阵的特征值与特征向量

特征值与特征向量的定义

Ax = λx，λ是特征值，x是特征向量。

特征方程

|A - λE| = 0

特征值的性质

  • 特征值之和等于迹（主对角线元素之和）
  • 特征值之积等于行列式

5.3 相似矩阵

相似矩阵的定义

存在可逆矩阵P，使得P⁻¹AP = B，则A与B相似。

矩阵对角化

可对角化的充要条件：有n个线性无关的特征向量。

5.4 对称矩阵的对角化

对称矩阵的性质

  • 特征值都是实数
  • 不同特征值的特征向量正交

5.5 二次型及其标准形

二次型的定义

f(x₁,x₂,...,xₙ) = ΣΣaᵢⱼ xᵢ xⱼ

二次型的矩阵表示

f = xᵀAx，A是对称矩阵。

5.6 正定二次型

正定二次型的定义

对任意x≠0，有f(x) > 0。

正定矩阵的判定

  • 所有顺序主子式都大于0
  • 所有特征值都大于0
  • 合同于单位矩阵
