第一章 概率论的基本概念

1.1 随机试验

随机试验的特点

  • 可重复性：可以在相同条件下重复进行
  • 结果的多样性：试验可能出现多种结果
  • 结果的不确定性：试验前不能确定会出现哪一个结果

1.2 样本空间、随机事件

样本空间

随机试验所有可能结果组成的集合，记为 Ω。

随机事件

样本空间的子集，简称事件。

事件的关系与运算

  • 包含：A ⊂ B，A发生则B一定发生
  • 相等：A = B，A ⊂ B且B ⊂ A
  • 和事件：A ∪ B，A或B发生
  • 积事件：A ∩ B，A和B都发生
  • 差事件：A - B，A发生而B不发生
  • 互斥：A ∩ B = ∅，A和B不能同时发生
  • 对立：A ∪ B = Ω且A ∩ B = ∅，B是A的对立事件

1.3 频率与概率

频率的定义

频率 = 事件发生次数 / 试验次数。

概率的公理化定义

  • 非负性：P(A) ≥ 0
  • 规范性：P(Ω) = 1
  • 可列可加性：若A₁,A₂,...互斥，则P(∪Aᵢ) = ΣP(Aᵢ)

1.4 等可能概型（古典概型）

古典概型的条件

  • 样本空间有限
  • 每个基本事件等可能

古典概率的计算

P(A) = 事件A包含的基本事件数 / 基本事件总数

1.5 条件概率

条件概率的定义

P(B|A) = P(AB) / P(A)，P(A) > 0

乘法公式

P(AB) = P(A)P(B|A)

全概率公式

P(B) = ΣP(Aᵢ)P(B|Aᵢ)

贝叶斯公式

P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / ΣP(Aⱼ)P(B|Aⱼ)

1.6 独立性

两个事件独立

P(AB) = P(A)P(B)

多个事件独立

两两独立且任意多个事件的积的概率等于概率的积。

注意：独立与互斥是两个不同的概念，独立事件不一定互斥，互斥事件不一定独立。

第二章 随机变量及其分布

2.1 随机变量

随机变量的定义

定义在样本空间上的实值函数。

离散型与连续型随机变量

  • 离散型：可能取有限个或可列无限个值
  • 连续型：可能取某个区间内的所有值

2.2 离散型随机变量及其分布律

分布律的定义

P{X = xₖ} = pₖ，k = 1,2,...

常见离散分布

分布 分布律 期望 方差
0-1分布 P{X=1}=p, P{X=0}=1-p p p(1-p)
二项分布B(n,p) P{X=k}=C(n,k)pᵏ(1-p)^(n-k) np np(1-p)
泊松分布π(λ) P{X=k}=λᵏe^(-λ)/k! λ λ

2.3 随机变量的分布函数

分布函数的定义

F(x) = P{X ≤ x}

分布函数的性质

  • 单调不减
  • 右连续
  • F(-∞)=0, F(+∞)=1

2.4 连续型随机变量及其概率密度

概率密度的定义

  • f(x) ≥ 0
  • ∫(-∞,+∞) f(x)dx = 1
  • P{a < X ≤ b} = ∫[a,b] f(x)dx

常见连续分布

分布 概率密度 期望 方差
均匀分布U(a,b) f(x)=1/(b-a), a<x<b (a+b)/2 (b-a)²/12
指数分布E(λ) f(x)=λe^(-λx), x>0 1/λ 1/λ²
正态分布N(μ,σ²) f(x)=e^(-(x-μ)²/(2σ²))/(σ√(2π)) μ σ²

第三章 多维随机变量及其分布

3.1 二维随机变量

联合分布函数

F(x,y) = P{X ≤ x, Y ≤ y}

联合分布律（离散型）

P{X=xᵢ, Y=yⱼ} = pᵢⱼ

联合概率密度（连续型）

  • f(x,y) ≥ 0
  • ∫∫f(x,y)dxdy = 1

3.2 边缘分布

边缘分布律

pᵢ. = Σⱼ pᵢⱼ
p_.ⱼ = Σᵢ pᵢⱼ

边缘概率密度

f_X(x) = ∫(-∞,+∞) f(x,y)dy
f_Y(y) = ∫(-∞,+∞) f(x,y)dx

3.3 条件分布

条件概率密度

f(x|y) = f(x,y) / f_Y(y)

3.4 相互独立的随机变量

独立的定义

  • F(x,y) = F_X(x)F_Y(y)
  • 离散型：pᵢⱼ = pᵢ.p_.ⱼ
  • 连续型：f(x,y) = f_X(x)f_Y(y)

第四章 随机变量的数字特征

4.1 数学期望

离散型

E(X) = Σxₖ pₖ

连续型

E(X) = ∫(-∞,+∞) x f(x)dx

数学期望的性质

  • E(C) = C
  • E(kX) = kE(X)
  • E(X+Y) = E(X) + E(Y)
  • 若X与Y独立，则E(XY) = E(X)E(Y)

4.2 方差

方差的定义

D(X) = E[(X - E(X))²] = E(X²) - [E(X)]²

方差的性质

  • D(C) = 0
  • D(kX) = k²D(X)
  • D(X+Y) = D(X) + D(Y) + 2Cov(X,Y)
  • 若X与Y独立，则D(X+Y) = D(X) + D(Y)

4.3 协方差与相关系数

协方差

Cov(X,Y) = E[(X-E(X))(Y-E(Y))] = E(XY) - E(X)E(Y)

相关系数

ρ(X,Y) = Cov(X,Y) / (√D(X)√D(Y))

性质

  • |ρ| ≤ 1
  • ρ = ±1 当且仅当X与Y线性相关

第五章 大数定律及中心极限定理

5.1 大数定律

切比雪夫大数定律

若X₁,X₂,...,Xₙ,...相互独立，且有相同的期望和方差，则(1/n)ΣXᵢ → μ（依概率收敛）。

伯努利大数定律

频率收敛于概率。

辛钦大数定律

独立同分布，期望存在，则样本均值收敛于期望。

5.2 中心极限定理

独立同分布的中心极限定理

大量独立同分布随机变量之和近似服从正态分布。

棣莫弗-拉普拉斯定理

二项分布近似正态分布。

第六章 样本及抽样分布

6.1 随机样本

样本的定义

从总体中抽取的n个个体X₁,X₂,...,Xₙ。

简单随机样本

独立同分布于总体。

6.2 抽样分布

统计量

不含未知参数的样本函数。

常用统计量

  • 样本均值：X̄ = (1/n)ΣXᵢ
  • 样本方差：S² = (1/(n-1))Σ(Xᵢ - X̄)²
  • 样本标准差：S = √S²

6.3 常用分布

χ²分布

χ² = X₁² + X₂² + ... + Xₙ²，Xᵢ~N(0,1)独立。

t分布

t = X / √(Y/n)，X~N(0,1), Y~χ²(n)独立。

F分布

F = (X/n₁) / (Y/n₂)，X~χ²(n₁), Y~χ²(n₂)独立。

第七章 参数估计

7.1 点估计

矩估计法

用样本矩估计总体矩。

最大似然估计法

  • 似然函数：L(θ) = Πf(xᵢ;θ)
  • 取对数：lnL(θ)
  • 求导找极值点

7.2 估计量的评选标准

  • 无偏性：E(θ̂) = θ
  • 有效性：方差最小的无偏估计
  • 一致性：θ̂ → θ（依概率收敛）

7.3 区间估计

置信区间的定义

P{θ₁ < θ < θ₂} = 1 - α

单个正态总体参数的区间估计

  • 均值μ（σ²已知）：X̄ ± z_(α/2)(σ/√n)
  • 均值μ（σ²未知）：X̄ ± t_(α/2)(n-1)(S/√n)

第八章 假设检验

8.1 假设检验的基本概念

原假设与备择假设

  • H₀：原假设
  • H₁：备择假设

第一类错误与第二类错误

  • 第一类错误（弃真）：H₀为真时拒绝H₀，概率α
  • 第二类错误（取伪）：H₀为假时接受H₀，概率β

8.2 单个正态总体的假设检验

均值的检验

  • σ²已知：Z检验
  • σ²未知：t检验

方差的检验

χ²检验。
