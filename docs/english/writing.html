第一章 写作题型分析

1.1 应用文写作（小作文）

考查形式

  • 书信：建议信、投诉信、邀请信、感谢信等
  • 通知：会议通知、活动通知等
  • 报告：调查报告、述职报告等

评分标准

  • 格式正确（1-2分）
  • 内容完整（3-4分）
  • 语言表达（3-4分）
  • 语法和拼写（1-2分）

1.2 短文写作（大作文）

考查形式

  • 图画作文（英语一）
  • 图表作文（英语二）

评分标准

  • 内容切题（10-12分）
  • 结构清晰（5-6分）
  • 语言表达（10-12分）
  • 语法和拼写（3-4分）

第二章 写作结构

2.1 应用文结构

书信结构

  1. 标题（可选）
  2. 称呼
  3. 正文：
    • 开头：自我介绍，说明写信目的
    • 主体：详细说明内容
    • 结尾：表达期望或感谢
  4. 结束语
  5. 签名

2.2 短文结构

图画/图表作文结构

  1. 描述图画/图表（3-4句）
  2. 解释图画/图表含义（3-4句）
  3. 分析原因或影响（4-5句）
  4. 总结或提出建议（2-3句）

第三章 常用句型

3.1 开头句型

  • As is vividly depicted in the picture...
  • According to the chart/graph...
  • It goes without saying that...
  • Nowadays, there is a growing concern over...

3.2 主体段句型

  • There are several reasons for...
  • First and foremost, ...
  • Furthermore, ...
  • Last but not least, ...
  • On one hand, ... On the other hand, ...

3.3 结尾句型

  • In conclusion, ...
  • Taking all these factors into consideration, ...
  • It is high time that we should...
  • Only in this way can we...

第四章 高分技巧

4.1 使用多样化的词汇

  • 避免重复使用相同的词汇
  • 使用高级词汇替代普通词汇
  • 注意词汇的准确性

4.2 使用复杂句型

  • 使用复合句（状语从句、定语从句）
  • 使用倒装句
  • 使用强调句

4.3 保持段落连贯性

  • 使用连接词（however, therefore, furthermore）
  • 保持逻辑清晰

小贴士：在写作时，尽量使用自己熟悉的句型和词汇，避免为了追求复杂而出现语法错误。

第五章 常用模板

5.1 建议信模板

Dear [Recipient],

I am writing to offer my suggestions regarding [topic]. After careful consideration, I would like to propose the following recommendations:

First and foremost, [suggestion 1]. This will help [benefit].

Furthermore, [suggestion 2]. By doing so, [result].

Last but not least, [suggestion 3]. This is essential for [reason].

I hope these suggestions will be helpful. Thank you for your attention.

Sincerely,
[Your Name]

5.2 图画作文模板

As is vividly shown in the picture, [description of the picture]. The picture conveys a profound message about [theme].

There are several reasons accounting for this phenomenon. First and foremost, [reason 1]. Furthermore, [reason 2]. Last but not least, [reason 3].

From my perspective, [your opinion]. It is high time that we should [action]. Only in this way can we [result].

5.3 图表作文模板

According to the chart/graph, we can clearly see that [description of the chart].

The reasons for this trend are as follows. Firstly, [reason 1]. Secondly, [reason 2]. Finally, [reason 3].

Taking all these factors into consideration, we can draw the conclusion that [conclusion]. In the future, [prediction].
