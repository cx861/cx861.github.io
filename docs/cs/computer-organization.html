1.1 计算机系统层次结构

计算机系统的组成

指令和数据

第二章 运算方法和运算器

2.1 数据的表示

数制与编码

  • 二进制、八进制、十进制、十六进制
  • BCD码、ASCII码、Unicode

定点数与浮点数

  • 定点数：小数点位置固定
  • 浮点数：N = M × r^E，M为尾数，E为阶码

原码、反码、补码

编码方式 正数 负数
原码 最高位为0 最高位为1
反码 与原码相同 原码除符号位外取反
补码 与原码相同 反码加1

2.2 定点运算

定点加减法

[X+Y]补 = [X]补 + [Y]补
[X-Y]补 = [X]补 + [-Y]补

溢出判断

  • 双符号位法：符号位为01表示正溢出，10表示负溢出
  • 进位法：最高位进位与次高位进位不同则溢出

2.3 浮点运算

浮点加减法步骤

  1. 对阶：小阶向大阶看齐
  2. 尾数相加
  3. 规格化
  4. 舍入
  5. 溢出判断

算术逻辑单元（ALU）

实现算术运算和逻辑运算。

寄存器

暂存数据和运算结果。

第三章 存储系统

3.1 存储器概述

存储器的分类

  • 按存储介质：半导体、磁表面、光存储
  • 按存取方式：随机存取、顺序存取、直接存取、相联存取
  • 按作用：主存、辅存、高速缓存

存储系统层次结构

  • Cache-主存层次：解决速度问题
  • 主存-辅存层次：解决容量问题

3.2 主存储器

主存的基本组成

  • 存储体
  • 地址寄存器
  • 数据寄存器
  • 地址译码器
  • 控制电路

半导体存储器

  • RAM：随机存取存储器（SRAM、DRAM）
  • ROM：只读存储器（MROM、PROM、EPROM、EEPROM、Flash）

3.3 高速缓存（Cache）

Cache的工作原理

  • 程序访问的局部性原理
  • 时间局部性、空间局部性

Cache的映射方式

  • 直接映射
  • 全相联映射
  • 组相联映射

Cache的替换策略

  • 先进先出（FIFO）
  • 最近最少使用（LRU）
  • 随机替换

3.4 虚拟存储器

虚拟存储器的概念

逻辑地址空间到物理地址空间的映射。

页式虚拟存储

  • 页表：页号到物理块号的映射
  • 快表（TLB）：高速缓存页表项

页面置换算法

  • 最优置换算法（OPT）
  • 先进先出（FIFO）
  • 最近最少使用（LRU）
  • 时钟算法（Clock）

第四章 指令系统

4.1 指令格式

指令的基本格式

  • 操作码字段：指明操作类型
  • 地址码字段：指明操作数地址

指令的寻址方式

  • 立即寻址：操作数在指令中
  • 直接寻址：操作数地址在指令中
  • 间接寻址：指令中存的是操作数地址的地址
  • 寄存器寻址：操作数在寄存器中
  • 寄存器间接寻址：寄存器中存的是操作数地址
  • 相对寻址：地址 = PC + 位移量
  • 基址寻址：地址 = 基址寄存器 + 位移量
  • 变址寻址：地址 = 变址寄存器 + 位移量

4.2 指令类型

  • 数据传送类指令
  • 算术运算类指令
  • 逻辑运算类指令
  • 程序控制类指令
  • 输入输出类指令

第五章 中央处理器（CPU）

5.1 CPU的功能和组成

CPU的功能

  • 指令控制
  • 操作控制
  • 时间控制
  • 数据加工

CPU的组成

  • 运算器：ALU、寄存器、数据通路
  • 控制器：指令寄存器、程序计数器、指令译码器、时序控制逻辑

5.2 指令周期

指令周期的阶段

  1. 取指令（IF）
  2. 指令译码（ID）
  3. 执行（EX）
  4. 访存（MEM）
  5. 写回（WB）

5.3 控制器的设计

硬布线控制器

  • 由组合逻辑电路实现
  • 优点：速度快
  • 缺点：复杂、不灵活

微程序控制器

  • 微指令、微程序、控制存储器
  • 优点：规整、灵活、易于维护
  • 缺点：速度较慢

5.4 流水线技术

流水线的基本概念

将指令执行过程分成多个阶段，并行执行。

流水线的性能指标

  • 吞吐率
  • 加速比
  • 效率

流水线的冲突

  • 结构冲突
  • 数据冲突
  • 控制冲突
