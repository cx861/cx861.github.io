第一章 操作系统概述

1.1 操作系统的概念

操作系统的定义

管理计算机系统资源、控制程序执行、提供用户接口的系统软件。

操作系统的目标

  • 方便性
  • 有效性
  • 可扩充性
  • 开放性

1.2 操作系统的发展历程

  1. 手工操作阶段
  2. 批处理系统（单道批处理、多道批处理）
  3. 分时系统
  4. 实时系统
  5. 网络操作系统
  6. 分布式操作系统

1.3 操作系统的基本特征

  • 并发：多个程序同时执行
  • 共享：资源被多个进程共同使用
  • 虚拟：把物理资源抽象为逻辑资源
  • 异步：进程以不可预知的速度执行

第二章 进程管理

2.1 进程的概念

进程的定义

程序在计算机中的一次执行过程。

进程的特征

  • 动态性
  • 并发性
  • 独立性
  • 异步性

进程与程序的区别

进程 程序
动态的 静态的
一次性的 可多次执行

进程的状态

  • 就绪态
  • 运行态
  • 阻塞态

进程控制块（PCB）

进程的唯一标识，包含进程的所有信息。

2.2 进程控制

  • 进程的创建：父进程创建子进程
  • 进程的终止：正常终止、异常终止
  • 进程的阻塞与唤醒

2.3 进程调度

调度的层次

  • 高级调度（作业调度）
  • 中级调度（内存调度）
  • 低级调度（进程调度）

调度算法

  • 先来先服务（FCFS）
  • 短作业优先（SJF）
  • 时间片轮转（RR）
  • 优先级调度
  • 多级反馈队列

2.4 进程同步

临界区问题

多个进程访问共享资源时的互斥问题。

同步机制

  • 信号量
  • 管程
  • 条件变量

经典同步问题

  • 生产者-消费者问题
  • 读者-写者问题
  • 哲学家进餐问题

2.5 进程通信

  • 共享内存
  • 消息传递
  • 管道通信

第三章 内存管理

3.1 内存管理的基本概念

内存管理的目标

  • 高效利用内存
  • 方便用户使用
  • 保护内存

3.2 连续分配管理方式

  • 单一连续分配
  • 固定分区分配
  • 动态分区分配（首次适应、最佳适应、最坏适应、邻近适应）

3.3 非连续分配管理方式

分页存储管理

  • 页表：页号到物理块号的映射
  • 地址转换：逻辑地址 = 页号 + 页内偏移

分段存储管理

进程按逻辑段划分。

段页式存储管理

结合分段和分页的优点。

3.4 虚拟内存

虚拟内存的概念

利用外存扩充内存。

页面置换算法

  • 最优置换算法（OPT）
  • 先进先出（FIFO）
  • 最近最少使用（LRU）
  • 时钟算法（Clock）

第四章 文件管理

4.1 文件和文件系统

文件的定义

具有符号名的一组相关信息的集合。

文件的分类

  • 按用途：系统文件、用户文件、库文件
  • 按保护级别：只读文件、读写文件、可执行文件

4.2 文件的逻辑结构

  • 无结构文件（流式文件）
  • 有结构文件（记录式文件）

4.3 文件的物理结构

  • 连续分配
  • 链接分配
  • 索引分配
  • 多级索引

4.4 目录管理

目录结构

  • 单级目录
  • 两级目录
  • 树形目录
  • 图形目录

第五章 设备管理

5.1 I/O设备管理概述

I/O设备的分类

  • 按使用特性：人机交互设备、存储设备、网络通信设备
  • 按传输速率：低速设备、中速设备、高速设备

5.2 I/O控制方式

  • 程序查询方式
  • 程序中断方式
  • DMA方式
  • 通道方式

5.3 设备分配

设备分配的数据结构

  • 设备控制表（DCT）
  • 控制器控制表（COCT）
  • 通道控制表（CHCT）
  • 系统设备表（SDT）

5.4 缓冲管理

缓冲的作用

  • 缓解CPU与I/O设备速度不匹配的矛盾
  • 提高CPU和I/O设备的并行性
  • 减少对CPU的中断频率

缓冲的类型

  • 单缓冲
  • 双缓冲
  • 循环缓冲
  • 缓冲池
