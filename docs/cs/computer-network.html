第一章 计算机网络概述

1.1 计算机网络的定义和分类

计算机网络的定义

将地理位置不同的、具有独立功能的多个计算机系统通过通信设备和线路连接起来，在网络软件的支持下实现数据通信和资源共享的系统。

计算机网络的分类

  • 按覆盖范围：局域网（LAN）、城域网（MAN）、广域网（WAN）
  • 按拓扑结构：总线型、星型、环型、树型、网状
  • 按传输介质：有线网络、无线网络

1.2 计算机网络的功能

  • 数据通信
  • 资源共享
  • 分布式处理
  • 提高可靠性

1.3 网络体系结构

OSI七层模型

  1. 物理层
  2. 数据链路层
  3. 网络层
  4. 传输层
  5. 会话层
  6. 表示层
  7. 应用层

TCP/IP四层模型

  1. 网络接口层
  2. 网际层
  3. 传输层
  4. 应用层

第二章 物理层

2.1 物理层的基本概念

物理层的功能

  • 传输比特流
  • 定义物理介质的特性
  • 定义接口特性
  • 定义传输模式（单工、半双工、全双工）

2.2 传输介质

有线传输介质

  • 双绞线：屏蔽双绞线（STP）、非屏蔽双绞线（UTP）
  • 同轴电缆：基带同轴电缆、宽带同轴电缆
  • 光纤：单模光纤、多模光纤

无线传输介质

  • 无线电波、微波、红外线、激光

2.3 信道复用技术

  • 频分复用（FDM）
  • 时分复用（TDM）
  • 波分复用（WDM）
  • 码分复用（CDM）

第三章 数据链路层

3.1 数据链路层的基本概念

数据链路层的功能

  • 帧同步
  • 差错控制
  • 流量控制
  • 链路管理

帧的格式

帧头、数据、帧尾

3.2 差错控制

检错码

  • 奇偶校验
  • CRC（循环冗余校验）

纠错码

汉明码

3.3 流量控制

  • 停-等协议
  • 滑动窗口协议

3.4 介质访问控制

随机访问介质访问控制

  • ALOHA协议
  • CSMA协议
  • CSMA/CD协议（以太网）

局域网

  • 以太网帧格式
  • MAC地址

第四章 网络层

4.1 网络层的基本概念

网络层的功能

  • 路由选择
  • 拥塞控制
  • 网络互联

4.2 IP协议

IPv4地址

  • 32位地址，点分十进制表示
  • A类、B类、C类、D类、E类地址
  • 子网划分、子网掩码

IPv6地址

128位地址，冒号分隔十六进制表示。

IP数据报格式

  • 版本、头长度、服务类型、总长度
  • 标识、标志、片偏移、生存时间
  • 协议、校验和、源地址、目的地址

4.3 路由协议

内部网关协议

  • RIP（路由信息协议）
  • OSPF（开放最短路径优先）

外部网关协议

BGP（边界网关协议）

4.4 拥塞控制

  • 慢开始
  • 拥塞避免
  • 快重传
  • 快恢复

第五章 传输层

5.1 传输层的基本概念

传输层的功能

  • 端到端的通信
  • 流量控制
  • 差错控制
  • 复用和分用

端口号

  • 知名端口（0-1023）
  • 注册端口（1024-49151）
  • 动态端口（49152-65535）

5.2 TCP协议

TCP的特点

  • 面向连接
  • 可靠传输
  • 有序传输
  • 流量控制
  • 拥塞控制

TCP三次握手

  1. 第一次：SYN
  2. 第二次：SYN+ACK
  3. 第三次：ACK

TCP四次挥手

  1. 第一次：FIN
  2. 第二次：ACK
  3. 第三次：FIN+ACK
  4. 第四次：ACK

5.3 UDP协议

UDP的特点

  • 无连接
  • 不可靠传输
  • 面向报文
  • 开销小

UDP的应用场景

  • 实时应用（视频、音频）
  • DNS查询

第六章 应用层

6.1 应用层的基本概念

应用层协议

为应用程序提供网络服务。

6.2 常见应用层协议

HTTP协议

  • 超文本传输协议
  • 请求方法：GET、POST、PUT、DELETE
  • 状态码：200、301、404、500

HTTPS协议

安全的HTTP协议，使用SSL/TLS加密。

FTP协议

文件传输协议。

SMTP协议

简单邮件传输协议，发送邮件。

POP3协议

邮局协议版本3，接收邮件。

DNS协议

域名系统，将域名转换为IP地址。

DHCP协议

动态主机配置协议，自动分配IP地址。
