一、选词填空 · 7 分钟秒杀技巧（正确率 90%）

选词填空是六级性价比最高的板块，不需要读懂全文，只靠词性排序直接秒杀。

第一步：标词性（做题黄金第一步，30 秒搞定）

15 个选项全部提前标注四种词性：n 名词 | v 动词 | adj 形容词 | adv 副词

第二步：六大固定填空公式（直接套，无脑填）

空格前/后必填词性
a/an / the + ____名词
形容词 + ____名词
情态动词 can/should + ____动词原形
to + ____动词原形
be 动词 + ____形容词 / 分词 ed / 分词 ing
句子前后完整, ____ ,副词

第三步：优先级排序

  • 副词最少：15 个里只有 2-3 个，先做副词题，最快秒杀
  • 形容词其次：修饰名词，最好定位
  • 动词最后：动词干扰项最多，放最后做
  • 虚词永远不选：选词填空从不考介词、连词

第四步：终极排除法

  • 同性相消：同一段落里两个意思相近的形容词/名词，直接排除一个
  • 时态统一：全文过去时，直接锁定 ed 形式单词
  • 感情色彩：文段积极 → 排除消极词汇；文段消极 → 排除积极词汇

第五步：高频答案规律

词性高频正确答案
副词increasingly / effectively / actually / merely / relatively
动词improve / reduce / promote / avoid / provide
形容词potential / various / adequate / proper / available

万能兜底词（每年必考）：available（出现必选）、efficient、significant

第六步：做题流程

  1. 先标注 15 个单词词性
  2. 先做副词空格（最简单）
  3. 再做名词空格
  4. 然后形容词
  5. 最后剩下来的全部填动词

二、长篇段落匹配 · 满分绝杀技巧（10 分钟全对）

这个题型是六级最简单的拿分题，不需要读全文，只用找词定位，正确率可以做到满分。

核心底层逻辑：全篇一共 10 个题目，对应 15 个段落。原则：同义替换 + 特殊词定位，不需要看懂句子，找关键词即可。

做题固定步骤（直接照做）

  1. 先看 10 个题干，绝不先看文章
  2. 用笔圈出每个题干的定位词
  3. 拿着定位词去文章里面扫视，不需要细读

三种无敌定位词（优先级从高到低）

  • 最高级/数字/时间/年份/人名/地名（首选，百分百定位）
  • 专业名词、长难生僻单词（不会被替换）
  • 合成词、带连字符的单词

六级出题铁律

  • 原词复现 ＝ 直接锁定答案段落
  • 题干和段落 70% 都是同义替换，不会完全一样。例：important = vital / crucial；change = alter / shift；lead to = result in
  • 一段对应一题，极少一段对应两题
  • 出现两段都像答案，优先选同义替换更多的那段
  • 顺序混乱：这个题型完全乱序，第一题答案可能在最后一段，不要按顺序找

快速排除技巧

  • 只出现一个单词重合 → 直接排除
  • 只有简单词汇重合（good / bad / people）→ 排除
  • 题干的否定含义，段落没有否定 → 直接排除

考场提速套路

  • 10 个题干全部圈完关键词，只需要 50 秒
  • 扫视文章只看每段的首句 + 尾句
  • 六级 85% 的答案全部藏在段落首尾，中间内容全部不用看
  • 遇到两个犹豫选项，直接选词汇难度更高的那一段

终极蒙题规律

  • 含有 fail / difficulty / negative / pressure → 答案永远在文章前半部分
  • 含有 success / positive / development / future → 答案永远在文章后半部分
  • 选项最长的题干，最好定位，优先做

三、仔细阅读 · 最简暴力满分套路

核心铁律：严格遵循题文同序——第 1 题答案永远在文章前两段，第 2 题中段，最后一题在最后一段。绝不会乱序，这是和段落匹配最大的区别。

  • 答案全部 ＝ 同义替换：原词一模一样的选项 95% 是陷阱
  • 定位句原则：每一道题只找文中一句话出题。定位到那一句，只读那一句，其余全部不用看

标准做题流程（4 分钟一篇）

  1. 先看五道题干，不看选项
  2. 划出每一题的定位词：名词、动词、特殊词
  3. 按顺序回文章定位，一题对应一段区域
  4. 对比定位句和选项，选出同义替换

五大题型秒杀公式

1. 细节题（占比 70%，最简单）

直接定位即可。错误选项特征：范围扩大、无中生有、偷换主体、时态不一致

2. 推理题（infer / imply）

  • 绝对不能选原文原句
  • 答案一定是原文的深层推导，选最委婉的选项（may / might / likely）

3. 态度题

六级态度只有三种固定答案：objective 客观 / critical 批判 / supportive 支持

永远不选：indifferent（冷漠）、biased（偏见）—— 必错

4. 主旨题（最后一题）

答案直接锁定首尾段。选项包含文章反复出现的核心名词就是正确答案。

5. 词义猜测题

直接看该词前后转折或并列：and 前后意思一致，but 前后意思相反。

必背排除法（直接秒排）

特征处理
绝对词：all / only / never / must / absolutely直接排除
主观臆断选项文章没提的个人感受全部不选
对比类选项（compare / difference）正确率极高，优先选
消极极端选项全部错

六级价值观永远：理性、积极、折中

终极蒙题技巧（定位不到时使用）

  • 两个选项意思相反，答案必在其中
  • 两个选项意思相近，全部排除
  • 选项最长的那个正确率最高
  • 正能量、理性、客观的选项永远是答案

四、考场时间分配（最科学）

板块时间策略
选词填空5 分钟随缘拿分，词性秒杀
段落匹配10 分钟必须满分，最好拿分
仔细阅读25 分钟重中之重，稳扎稳打
剩余时间留给翻译 + 作文
