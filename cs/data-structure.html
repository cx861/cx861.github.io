第1章 绪论

1.1 数据结构的基本概念

1.1.1 基本概念和术语

术语定义关键理解
数据信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理的符号的集合数据是计算机程序加工的原料
数据元素数据的基本单位，通常作为一个整体进行考虑和处理数据元素可由若干数据项组成，数据项是构成数据元素的不可分割的最小单位
数据对象具有相同性质的数据元素的集合，是数据的子集例如：整数数据对象是集合 N = {0, ±1, ±2, ...}
数据类型一个值的集合和定义在此集合上的一组操作的总称原子类型（int, char等）+ 结构类型（struct等）
抽象数据类型(ADT)指一个数学模型及定义在该模型上的一组操作，仅取决于逻辑特性，与其在计算机内部如何表示和实现无关通常用(数据对象, 数据关系, 基本操作集)三元组表示
数据结构相互之间存在一种或多种特定关系的数据元素的集合包括逻辑结构、存储结构和数据的运算

1.1.2 数据结构的三要素

一、数据的逻辑结构

逻辑结构是指数据元素之间的逻辑关系，与数据的存储无关。

逻辑结构特点常见例子
集合数据元素之间仅同属一个集合，没有其他关系-
线性结构数据元素之间是一对一的关系线性表、栈、队列、串
树形结构数据元素之间是一对多的关系树、二叉树
图状/网状结构数据元素之间是多对多的关系图

二、数据的存储结构（物理结构）

存储结构是指数据结构在计算机中的表示（映像）。

存储结构特点优点缺点
顺序存储逻辑上相邻的元素存储在物理位置上也相邻的存储单元中随机存取，存储密度大插入删除需移动大量元素
链式存储逻辑上相邻的元素在物理位置上不一定相邻，借助指针表示元素间逻辑关系插入删除方便，不需移动元素存储密度小，只能顺序存取
索引存储在存储元素的同时还建立附加的索引表检索速度快增加了索引表的存储空间
散列存储（哈希存储）根据元素的关键字直接计算出该元素的存储地址检索、增删速度快可能出现冲突，处理冲突增加开销

三、数据的运算

施加在数据上的运算包括运算的定义（逻辑结构）和运算的实现（存储结构）。

1.2 算法与算法评价

1.2.1 算法的基本概念

概念说明
算法定义对特定问题求解步骤的一种描述，是指令的有限序列
算法的5个特性① 有穷性：必须在有穷步之后结束；② 确定性：每一条指令必须有确切的含义；③ 可行性：可以通过已实现的基本运算执行有限次来实现；④ 输入：有零个或多个输入；⑤ 输出：有一个或多个输出
好算法标准正确性、可读性、健壮性、高效率与低存储量需求（时间复杂度低 + 空间复杂度低）

1.2.2 算法效率的度量

一、时间复杂度 T(n) = O(f(n))

  • 含义：算法中所有语句的频度之和 T(n) 的数量级
  • 分析规则：
  • 加法规则：T(n) = T₁(n) + T₂(n) = O(max(f(n), g(n)))
  • 乘法规则：T(n) = T₁(n) × T₂(n) = O(f(n) × g(n))
  • 常见时间复杂度比较（从小到大）： O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)
  • 三种时间复杂度分析：
  • 最好时间复杂度：在最理想情况下的时间复杂度
  • 最坏时间复杂度：在最坏情况下的时间复杂度
  • 平均时间复杂度：所有可能输入实例在等概率出现的情况下，算法的期望运行时间

二、空间复杂度 S(n) = O(g(n))

  • 算法所耗费的存储空间，包括存储算法本身、输入输出数据、以及算法运行过程中的临时占用存储空间
  • 算法原地工作：指算法所需的辅助空间为常量，即 O(1)

1.2.3 典型的时间复杂度分析

  1. 循环主体中的变量参与循环条件的判断
  • for(i=1; i<=n; i*=2) → O(log₂n)
  • for(i=1; i<=n; i++) for(j=1; j<=n; j++) → O(n²)
  1. 循环主体中的变量与循环条件无关（递归程序）
  • 递推公式法分析递归算法

第2章 线性表

2.1 线性表的定义和基本操作

2.1.1 线性表的定义

  • 定义：具有相同数据类型的 n(n≥0) 个数据元素的有限序列
  • 特点：
  • 表中元素个数有限
  • 表中元素具有逻辑上的顺序性
  • 表中元素都是数据元素，每个元素都是原子类型
  • 表中元素的数据类型相同，占据相同大小的存储空间
  • 表中元素具有抽象性，只讨论元素间的逻辑关系

2.1.2 线性表的基本操作

操作说明
InitList(&L)初始化表，构造一个空线性表
Length(L)求表长，返回L中数据元素个数
LocateElem(L, e)按值查找，在L中查找第一个值等于e的元素
GetElem(L, i)按位查找，获取L中第i个位置的元素值
ListInsert(&L, i, e)插入，在L的第i个位置插入新元素e
ListDelete(&L, i, &e)删除，删除L中第i个元素并用e返回其值
PrintList(L)输出，按前后顺序输出所有元素值
Empty(L)判空
DestroyList(&L)销毁

2.2 线性表的顺序表示（顺序表）

2.2.1 顺序表的定义

  • 用一组地址连续的存储单元依次存储线性表中的数据元素，使得逻辑上相邻的元素在物理位置上也相邻
  • 特点：逻辑顺序 = 物理顺序，可随机存取（O(1)时间复杂度访问任意元素）
  • 存储密度高（每个结点只存数据元素）

2.2.2 顺序表基本操作的实现

操作时间复杂度说明
插入（第i个位置）O(n)需要后移 n-i+1 个元素，平均移动 n/2
删除（第i个位置）O(n)需要前移 n-i 个元素，平均移动 (n-1)/2
按值查找O(n)平均比较 (n+1)/2 次
按位查找O(1)随机存取

2.3 线性表的链式表示（链表）

2.3.1 单链表的定义

  • 通过一组任意的存储单元来存储线性表中的数据元素
  • 每个结点包含数据域(data) 和指针域(next)
  • 头指针：指向第一个结点的指针
  • 头结点：在第一个元素结点之前附加的结点（数据域可不存信息），可简化操作

2.3.2 单链表基本操作的实现

操作时间复杂度关键点
头插法建立单链表O(n)每次插入在头部，读入顺序与生成顺序相反
尾插法建立单链表O(n)增加尾指针，读入顺序与生成顺序相同
按序号查找结点O(n)从第一个结点开始顺next域逐个向下搜索
按值查找结点O(n)同上
插入结点（前插）O(n) / O(1)已知前驱O(1)；未知前驱需先查找O(n)
删除结点O(n) / O(1)已知前驱O(1)；未知前驱需先查找O(n)
求表长O(n)需遍历

特殊技巧：

  • "前插"变"后插"再交换：在p结点前插入元素s → 先将s插入p之后，再交换p和s的数据域
  • 删除p结点（已知p）：将p的后继数据复制到p，然后删除p的后继

2.3.3 双链表

  • 每个结点包含两个指针：prior（指向前驱）和next（指向后继）
  • 插入操作需修改4个指针（s->next, s->prior, p->next, s->next->prior）
  • 删除操作需修改2个指针
  • 双链表的按位查找和按值查找与单链表相同
  • 优点：可双向遍历，插入删除更方便

2.3.4 循环链表

类型特点判空条件
循环单链表最后一个结点的指针指向头结点头结点的next = 头指针
循环双链表头结点的prior指向尾结点，尾结点的next指向头结点头结点的prior = 头指针 且 头结点的next = 头指针

2.3.5 静态链表

  • 借助数组来描述链式存储结构，结点也有data域和next域（游标/cur）
  • 需要预先分配连续空间
  • 以 next == -1 作为结束标志

2.3.6 顺序表与链表的比较

比较维度顺序表链表
存取方式顺序存取 + 随机存取仅顺序存取
逻辑/物理结构逻辑相邻 = 物理相邻逻辑相邻 ≠ 物理相邻
查找按值O(n)，按位O(1)按值O(n)，按位O(n)
插入/删除O(n)，需移动元素O(1)（已知位置时），只需修改指针
空间分配静态分配（溢出问题），存储密度=1动态分配，存储密度<1

选择策略：

  • 基于存储：难估计长度/规模时→链表；长度固定→顺序表
  • 基于运算：频繁按序号访问→顺序表；频繁插入删除→链表
  • 基于环境：语言环境支持→顺序表简单；不支持→链表

第3章 栈、队列和数组

3.1 栈

3.1.1 栈的基本概念

  • 定义：只允许在一端（栈顶）进行插入和删除操作的线性表，遵循后进先出(LIFO)原则
  • 栈顶(Top)：允许插入删除的一端
  • 栈底(Bottom)：不允许操作的一端
  • 空栈：不含任何元素的空表
  • 数学性质：n个不同元素进栈，出栈序列的个数为 卡特兰数 C(2n,n)/(n+1)

3.1.2 栈的顺序存储结构

实现要点说明
结构体data[MaxSize] + int top
栈空条件top == -1（初始时top=-1）
栈满条件top == MaxSize-1
进栈data[++top] = x
出栈x = data[top--]
栈长top + 1

共享栈：两个栈共享一个数组空间，栈底分别设在两端，栈顶向中间延伸。

  • 栈空：top0 = -1（左栈空），top1 = MaxSize（右栈空）
  • 栈满：top1 - top0 = 1

3.1.3 栈的链式存储结构

  • 优点：不存在栈满上溢问题
  • 通常采用单链表实现，所有操作在表头进行
  • 链栈的插入和删除操作对应单链表的头插法和头删法

3.2 队列

3.2.1 队列的基本概念

  • 定义：只允许在表的一端（队尾）插入，另一端（队头）删除的线性表，遵循先进先出(FIFO)原则
  • 队头(Front)：允许删除的一端
  • 队尾(Rear)：允许插入的一端

3.2.2 队列的顺序存储结构

循环队列：

实现方案队空条件队满条件
牺牲一个存储单元Q.front == Q.rear(Q.rear+1) % MaxSize == Q.front
增设size/tag成员size == 0 / tag == 0size == MaxSize / tag == 1
  • 元素个数：(Q.rear - Q.front + MaxSize) % MaxSize
  • 入队：Q.rear = (Q.rear + 1) % MaxSize; Q.data[Q.rear] = x;
  • 出队：x = Q.data[Q.front]; Q.front = (Q.front + 1) % MaxSize;

3.2.3 队列的链式存储结构

  • 链队：同时带有头指针和尾指针的单链表
  • 头指针指向队头结点，尾指针指向队尾结点
  • 出队时需要判断是否变为空队（若出队前仅一个结点，出队后尾指针也要置空）

3.2.4 双端队列

  • 允许在两端进行插入和删除操作的线性表
  • 输出受限的双端队列：一端允许插入删除，另一端只允许插入
  • 输入受限的双端队列：一端允许插入删除，另一端只允许删除

3.3 栈和队列的应用

3.3.1 栈在括号匹配中的应用

  • 扫描字符串，遇左括号入栈，遇右括号时：
  • 若栈空→不匹配
  • 若栈顶左括号与当前右括号匹配→出栈
  • 若不匹配→非法
  • 最后栈空则匹配成功

3.3.2 栈在表达式求值中的应用

表达式类型运算符位置示例
中缀表达式运算符在两个操作数之间a + b
前缀表达式（波兰式）运算符在操作数之前+ a b
后缀表达式（逆波兰式）运算符在操作数之后a b +

中缀→后缀（栈中存放运算符）：

  1. 操作数直接输出
  2. 运算符与栈顶比较优先级：高则入栈，低则弹栈直到遇左括号或优先级更低的运算符
  3. 左括号直接入栈，右括号弹出到左括号（括号不输出）
  4. 遍历完将栈中剩余运算符全部弹出

后缀表达式求值（栈中存放操作数）：

  • 操作数入栈，遇运算符则弹出两个操作数计算后压回

3.3.3 栈在递归中的应用

  • 递归调用的实现依赖系统栈，保存调用返回地址、实参、局部变量
  • 递归转非递归通常需要用户自己定义栈

3.3.4 队列在层次遍历中的应用

  • 二叉树的层次遍历
  • 图的广度优先搜索(BFS)

3.3.5 队列在计算机系统中的应用

  • 打印数据缓冲区（主机→打印机 速度不匹配）
  • CPU资源竞争（FCFS先来先服务）

3.4 数组和特殊矩阵

3.4.1 数组的定义

  • n个相同类型数据元素构成的有限序列
  • 数组是线性表的推广：一维数组是线性表，二维数组是其元素为一维数组的线性表

3.4.2 数组的存储结构

  • 按行优先存储（C/C++、Java等）：
  • LOC(a[i][j]) = LOC(a[0][0]) + (i×n+j)×L
  • 按列优先存储（Fortran等）：
  • LOC(a[i][j]) = LOC(a[0][0]) + (j×m+i)×L

3.4.3 特殊矩阵的压缩存储

矩阵类型压缩方式关键技术
对称矩阵只存下三角（或上三角）+对角线$a_{ij}$ 在下三角(i≥j)时存 $B[\frac{i(i-1)}{2}+j-1]$（下标从1开始）
三角矩阵下三角矩阵：存非零区域 + 一个共享常量与对称矩阵类似，但常数单独存储
三对角矩阵只存主对角线和两条次对角线（3n-2个元素）$a_{ij}$ 存 $B[2i+j-3]$（|i-j|≤1时）
稀疏矩阵三元组表 / 十字链表只存非零元素的行、列、值

第4章 串

4.1 串的定义和实现

4.1.1 串的定义

  • 串：由零个或多个字符组成的有限序列
  • 空串 ∅：零个字符的串
  • 子串、主串：串中任意个连续字符组成的子序列
  • 空格串：由一个或多个空格组成的串（≠空串）

4.1.2 串的存储结构

存储方式特点
定长顺序存储预定最大长度，超过截断
堆分配存储动态分配，C语言的malloc/free
块链存储链表结点存放多个字符（块）

4.2 串的模式匹配

4.2.1 简单模式匹配（BF算法）

  • 主串S和模式串T，从S的第一个字符开始逐个比较
  • 匹配失败则回溯：i = i-j+2, j = 1
  • 时间复杂度：最坏O(mn)，最好O(n)

4.2.2 KMP算法

  • 核心思想：利用已匹配部分的信息，主串i不回溯
  • next数组：当模式串的第j个字符与主串失配时，将模式串跳到 next[j] 位置继续比较
j1234567
模式串abaabca
next[j]0112231

next数组手工计算规则：

  • next[1] = 0
  • 对于j>1，next[j] = S的最长相等前后缀长度 + 1
  • 即：取模式串前 j-1 个字符构成的子串，找其最长相等的前后缀长度，+1

时间复杂度：O(m+n)（比BF算法优化很多）

4.2.3 KMP算法的优化 → nextval数组

  • 当 P[j] = P[next[j]] 时，next[j]可以直接修正为 next[next[j]]
  • 避免无意义的比较

第5章 树与二叉树

5.1 树的基本概念

5.1.1 树的定义

  • 树是 n(n≥0) 个结点的有限集
  • n=0时为空树；非空树满足：
  1. 有且仅有一个根结点
  2. n>1时，其余结点可分为m个互不相交的有限集T₁...Tₘ，每个集合本身又是一棵树（根的子树）

5.1.2 基本术语

术语定义
结点的度结点拥有的子树个数
树的度树中各结点的度的最大值
叶子/终端结点度为0的结点
分支/非终端结点度大于0的结点
双亲/孩子结点子树的根称为该结点的孩子，该结点称为孩子的双亲
兄弟同一个双亲的孩子之间
结点的深度从根结点开始自顶向下逐层累加
结点的高度从叶结点开始自底向上逐层累加
树的高度/深度树中结点的最大层数
有序树/无序树子树从左到右是否有次序
路径/路径长度两个结点间经过的边数
森林m(m≥0)棵互不相交的树的集合

5.1.3 树的性质（重要）

  1. 结点数 = 总度数 + 1（所有结点的度数之和 + 1 = 总结点数）
  2. 度为m的树中第i层最多有 $m^{i-1}$ 个结点
  3. 高度为h的m叉树最多有 $(m^h-1)/(m-1)$ 个结点
  4. 具有n个结点的m叉树的最小高度为 $\lceil \log_m(n(m-1)+1) \rceil$

5.2 二叉树的概念

5.2.1 二叉树的定义

  • 每个结点最多有两棵子树（度≤2），且有左右之分，不能颠倒
  • 二叉树 ≠ 度为2的树

5.2.2 几种特殊的二叉树

类型定义特点
满二叉树高度为h，结点数为 $2^h-1$每层都满
完全二叉树与满二叉树的编号一一对应除最后一层外每层都满，最后一层向左靠拢
二叉排序树(BST)左子树<根<右子树中序遍历递增
平衡二叉树(AVL)|左右子树高度差|≤1高效的查找性能

5.2.3 二叉树的性质（重要）

  1. 非空二叉树上叶子结点数 = 度为2的结点数 + 1，即 $n_0 = n_2 + 1$
  2. 非空二叉树上第i层最多有 $2^{i-1}$ 个结点
  3. 高度为h的二叉树最多有 $2^h-1$ 个结点
  4. 具有n个结点的完全二叉树的高度为 $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$
  5. 完全二叉树中，对于编号为i的结点（i≥1）：
  • 双亲编号：$\lfloor i/2 \rfloor$
  • 左孩子编号：2i
  • 右孩子编号：2i+1

5.2.4 二叉树的存储结构

存储结构实现方式适用场景
顺序存储用数组按完全二叉树编号存储，空缺位置用0/null填充完全二叉树/满二叉树
链式存储二叉链表（lchild + data + rchild）通用的二叉树存储

5.3 二叉树的遍历和线索二叉树

5.3.1 二叉树的遍历

遍历方式次序递归算法
先序遍历(NLR)根 → 左子树 → 右子树PreOrder
中序遍历(LNR)左子树 → 根 → 右子树InOrder
后序遍历(LRN)左子树 → 右子树 → 根PostOrder
层次遍历逐层从左到右借助队列实现

由遍历序列构造二叉树：

  • 先序+中序 → 唯一确定二叉树
  • 后序+中序 → 唯一确定二叉树
  • 层次+中序 → 唯一确定二叉树
  • 先序+后序 → 不能唯一确定（除非是满二叉树等特殊情况）

非递归遍历：需借助栈实现

  • 先序：访问后压栈，向左走；栈空结束
  • 中序：一直向左压栈，弹出访问后转向右子树
  • 后序：最复杂，需增加标记判断是否从右子树返回

5.3.2 线索二叉树

概念说明
线索利用空链域（n个结点有2n个指针域，n+1个为空）存放前驱/后继指针
ltag=0lchild指向左孩子
ltag=1lchild指向直接前驱
rtag=0rchild指向右孩子
rtag=1rchild指向直接后继

三种线索二叉树：先序线索、中序线索、后序线索

中序线索二叉树的构造与遍历：

  • 中序线索化：在中序遍历过程中记录前驱，修改空指针
  • 中序线索树的遍历：不需要栈/递归，沿线索即可遍历

注意：先序线索中找前驱需要知道双亲（可能需要三叉链表）；后序线索中找后继也需要知道双亲

5.4 树、森林

5.4.1 树的存储结构

存储结构实现优缺点
双亲表示法顺序存储，每个结点存data + parent下标找双亲O(1)，找孩子需遍历
孩子表示法顺序+链式结合，每个结点链出所有孩子找孩子方便，找双亲需遍历
孩子兄弟表示法二叉链表：左指针→第一个孩子，右指针→下一个兄弟最常用，可实现树↔二叉树转换

5.4.2 树、森林与二叉树的转换

转换规则（孩子兄弟表示法）：

  • 树→二叉树：左孩子右兄弟
  • 森林→二叉树：先将每棵树转为二叉树，再将后一棵树的根作为前一棵树根的右子树
  • 二叉树→森林：断开右链得到多棵树根

核心规律：树（森林）转二叉树后，原树的叶子在二叉树中没有左孩子

5.4.3 树和森林的遍历

树的遍历对应二叉树的遍历说明
先根遍历先序遍历先访问根，再依次先根遍历每棵子树
后根遍历中序遍历先依次后根遍历每棵子树，再访问根
森林的遍历说明
先序遍历森林先访问第一棵树的根 → 先序遍历第一棵树的子树森林 → 先序遍历剩余森林
中序遍历森林（后序遍历森林）后序遍历第一棵树的子树森林 → 访问第一棵树的根 → 中序遍历剩余森林

5.5 树与二叉树的应用

5.5.1 哈夫曼树和哈夫曼编码

哈夫曼树的定义：

  • 路径长度：从根到该结点的路径上的边数
  • 带权路径长度 WPL：$\sum_{i=1}^{n} w_i \times l_i$（权值×路径长度之和）
  • 哈夫曼树：WPL最小的二叉树（最优二叉树）

哈夫曼树的构造（贪心算法）：

  1. 将n个结点看作n棵只有根的二叉树，构成森林F
  2. 在F中选取两棵根权值最小的树作为左右子树，构造新二叉树（新根权值=两子树权值之和）
  3. 从F中删除这两棵树，加入新树
  4. 重复直到F中仅剩一棵树

哈夫曼树特点：

  • 初始结点都是叶子，且权值越小离根越远
  • 没有度为1的结点（只有度为0和度为2的结点）
  • $n_0 = n_2 + 1$（叶子比分支结点多1个）
  • 结点总数为 $2n_0 - 1$

哈夫曼编码：

  • 前缀编码：任一字符的编码都不是另一字符编码的前缀
  • 哈夫曼编码是最优前缀编码
  • 构造：左分支标0，右分支标1（或相反）

5.5.2 并查集（Union-Find Set）

操作说明时间复杂度
Initial(S)初始化，每个元素自成单元素集合O(n)
Find(S, x)查找x所属集合的根（代表元）O(α(n))（优化后）
Union(S, Root1, Root2)合并两个不相交集合O(α(n))（优化后）

优化策略：

  • 按秩合并（Union by Rank）：总是将小树合并到大树上
  • 路径压缩（Path Compression）：查找时把路径上所有结点直接连到根

应用：

  • 判断图的连通性
  • Kruskal算法求最小生成树
  • 朋友圈/等价类划分问题

第6章 图

6.1 图的基本概念

6.1.1 图的定义

  • 图G由顶点集V和边集E组成：G = (V, E)
  • V(G) 表示顶点集，E(G) 表示边集

6.1.2 基本术语

术语定义
无向图边没有方向：(v,w) = (w,v)
有向图边有方向： ≠ （弧尾→弧头）
简单图无重复边，无自环
完全图无向：有n(n-1)/2条边；有向：有n(n-1)条弧
子图顶点集和边集都是原图的子集
连通无向图中v和w有路径相通
连通图无向图中任意两个顶点都连通
连通分量无向图中的极大连通子图
强连通图有向图中任意v,w都有v到w和w到v的路径
强连通分量有向图中的极大强连通子图
生成树包含全部顶点的一个极小连通子图（n个顶点n-1条边）
生成森林非连通图的每个连通分量的生成树
度无向：依附于v的边数；有向：入度+出度
网边上带有权值的图
稠密图/稀疏图边数接近完全图/边数很少

6.1.3 图的性质

  1. 无向图：所有顶点的度之和 = 边数的2倍
  2. 有向图：所有顶点的入度之和 = 出度之和 = 边数
  3. n个顶点的连通图至少有n-1条边
  4. 若连通图有n个顶点，则其生成树有n-1条边

6.2 图的存储及基本操作

6.2.1 邻接矩阵法

特性说明
存储空间O(|V|²)
判断两点邻接O(1)
找某顶点的邻接点O(|V|)
增加/删除边O(1)
适用场景稠密图
表示方式二维数组：A[i][j]=1(或权值)
  • 无向图的邻接矩阵是对称矩阵
  • 第i行（或第i列）非零元素的个数 = 顶点i的度

6.2.2 邻接表法

特性说明
存储空间无向O(|V|+2|E|)，有向O(|V|+|E|)
判断两点邻接需遍历，O(|V|)
找某顶点的邻接点O(出度)
增加/删除边O(1)~O(|V|)
适用场景稀疏图

6.2.3 十字链表（有向图）

  • 弧结点：tailvex + headvex + hlink + tlink + info
  • 顶点结点：data + firstin + firstout
  • 既容易找到出度也容易找到入度

6.2.4 邻接多重表（无向图）

  • 边结点：mark + ivex + ilink + jvex + jlink + info
  • 合适的场合：对边进行标记/删除操作

6.2.5 四种存储结构的比较

存储结构邻接矩阵邻接表十字链表邻接多重表
图类型有向+无向有向+无向有向无向
空间复杂度O(|V|²)无向O(|V|+2|E|)O(|V|+|E|)O(|V|+|E|)
找所有邻接点O(|V|)O(出度)O(出度)O(度)
删除边O(1)O(|V|) 找前驱方便方便

6.3 图的遍历

6.3.1 广度优先搜索（BFS）

  • 算法思想：类似树的层次遍历，借助队列实现
  • 时间复杂度：邻接矩阵O(|V|²)，邻接表O(|V|+|E|)
  • 空间复杂度：O(|V|)（队列中最多|V|个顶点）
  • 应用：
  • 求解单源最短路径（无权图）
  • 广度优先生成树（BFS树）

6.3.2 深度优先搜索（DFS）

  • 算法思想：类似树的先根遍历，借助栈（递归）实现
  • 时间复杂度：同BFS
  • 空间复杂度：O(|V|)（递归栈深度）
  • 应用：
  • 深度优先生成树/森林
  • 判断连通性
  • 拓扑排序的逆序

6.3.3 图的连通性

  • 无向图：调用BFS/DFS次数 = 连通分量个数
  • 有向图：从某顶点出发不一定能访问所有顶点（可能存在非强连通）

6.4 图的应用

6.4.1 最小生成树（MST）

定义：带权连通无向图中，各边权值之和最小的生成树

算法思想时间复杂度适用
Prim贪心，从顶点出发选最小边扩展O(|V|²)稠密图
Kruskal贪心，按边权排序，用并查集防环O(|E|log|E|)稀疏图

关键：最小生成树可能不唯一，但权值之和唯一

6.4.2 最短路径

问题算法时间复杂度适用
单源最短路径DijkstraO(|V|²)边权≥0
各顶点间最短路径FloydO(|V|³)允许负权（无负环）

Dijkstra算法：

  • 每次从未标记顶点中选距离最小的，更新其邻接点距离
  • 不能处理负权边

Floyd算法（动态规划）：

  • $A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$
  • 最后得到的A矩阵存放最短路径长度

6.4.3 有向无环图(DAG)描述表达式

  • 用DAG表示表达式可以节省存储空间
  • 合并重复子表达式：相同子式不重复出现

6.4.4 拓扑排序（AOV网）

  • AOV网：用顶点表示活动，有向边表示活动间的优先关系
  • 拓扑排序：对AOV网构造一个顶点的线性序列
  • 算法：
  1. 从AOV网中选一个无前驱（入度为0）的顶点并输出
  2. 网中删除该顶点及其所有出边
  3. 重复直到不存在无前驱的顶点
  • 若最后有剩余顶点→存在回路/环
  • 时间复杂度：邻接表O(|V|+|E|)，邻接矩阵O(|V|²)
  • 逆拓扑排序用DFS实现更方便

6.4.5 关键路径（AOE网）

  • AOE网：用边表示活动，权值表示持续时间，顶点表示事件
  • 关键路径：从源点到汇点路径长度最长的路径
  • 关键活动：关键路径上的活动

四个关键量：

量含义求法
ve(k)事件v_k最早发生时间正向拓扑排序取最大
vl(k)事件v_k最迟发生时间逆向拓扑排序取最小
e(i)活动a_i最早开始时间= ve(弧尾顶点)
l(i)活动a_i最迟开始时间= vl(弧头顶点) - 持续时间

若 e(i) = l(i)，则活动a_i是关键活动

第7章 查找

7.1 查找的基本概念

概念定义
查找在数据集合中寻找满足某种条件的数据元素的过程
查找表同一类型数据元素构成的集合
关键字数据元素中唯一标识该元素的某个数据项的值
查找成功找到满足条件的数据元素
平均查找长度(ASL)所有查找过程中关键字比较次数的平均值，$ASL = \sum_{i=1}^{n} P_i C_i$

7.2 顺序查找和折半查找

7.2.1 顺序查找

表类型查找成功ASL查找失败ASL时间复杂度
一般线性表(n+1)/2n+1O(n)
有序表(n+1)/2n/2 + n/(n+1)O(n)

优化：将"哨兵"放在0号位置，从后往前查找，省略越界判断。

7.2.2 折半查找（二分查找）

  • 适用条件：有序的顺序表（链表不行，因不能随机存取）
  • 算法：每次与中间元素比较，每次排除一半
  • 判定树：平衡二叉树
  • 时间复杂度：O(log₂n)
  • 查找成功ASL ≈ log₂(n+1) - 1
  • 查找失败ASL ≈ log₂(n+1)

7.2.3 分块查找（索引顺序查找）

  • 结构：索引表（有序）+ 块内（无序）
  • ASL = 索引查找ASL + 块内查找ASL
  • 若长度为n的表分为b块，每块s个记录：$ASL = \frac{b+1}{2} + \frac{s+1}{2} = \frac{s^2+2s+n}{2s}$

7.3 树形查找

7.3.1 二叉排序树（BST）

定义：左子树 < 根 < 右子树（递归定义）

操作说明
查找从根开始，小于→左子树，大于→右子树
插入查找失败的位置即为插入位置
删除三种情况：叶子（直接删）、单孩子（孩子替代）、双孩子（中序前驱/后继替代）
查找效率最好O(log₂n)（平衡时），最差O(n)（单枝树）

7.3.2 平衡二叉树（AVL）

  • 定义：|左子树高度 - 右子树高度| ≤ 1（平衡因子只取{0, 1, -1}）
  • 平衡因子 = 左子树高 - 右子树高

插入后的调整（4种旋转）：

情况操作
LL（左孩子的左子树插入）右单旋转
RR（右孩子的右子树插入）左单旋转
LR（左孩子的右子树插入）先左旋后右旋
RL（右孩子的左子树插入）先右旋后左旋

性质：

  • 深度为h的AVL树最少结点数：$N_h = N_{h-1} + N_{h-2} + 1$（类似斐波那契）
  • n个结点的AVL树最大深度约为 O(log₂n)

删除后的调整：删除后从被删结点向上检查平衡因子，发现不平衡则旋转调整

7.3.3 红黑树

定义（5条性质）：

  1. 每个结点是红色或黑色
  2. 根结点是黑色
  3. 叶结点（NIL）是黑色
  4. 红色结点的两个子结点都是黑色（无连续红）
  5. 从任一结点到其每个叶子的所有路径包含相同数量的黑色结点（黑高相等）

结论：

  • 从根到叶子的最长路径 ≤ 2×最短路径
  • n个内部结点的红黑树高度 ≤ 2log₂(n+1)

插入调整（3种情况）：

  • 父黑：无需调整
  • 父红：看叔叔颜色
  • 叔叔红：变色
  • 叔叔黑（LL/RR）：旋转+变色
  • 叔叔黑（LR/RL）：旋转两次+变色

7.4 B树和B+树

7.4.1 B树

m阶B树的特性：

  1. 每个结点至多有m棵子树，m-1个关键字
  2. 除根结点外，分支结点至少有⌈m/2⌉棵子树，⌈m/2⌉-1个关键字
  3. 若根不是终端结点，至少有2棵子树
  4. 所有叶结点在同一层（叶结点是失败结点，不带信息）
操作说明
查找类似BST的多路查找
插入插入终端结点，若溢出（关键字>m-1）则分裂：中间关键字升入父结点
删除非终端→找前驱/后继替代后删除终端；终端删除若不够则"借"兄弟或合并

B树的高度（n个关键字）：

  • $\log_m(n+1) \leq h \leq \log_{\lceil m/2 \rceil}((n+1)/2)+1$

7.4.2 B+树

与B树的区别：

特性B树B+树
n个关键字n棵子树✓✗（n个关键字只对应n棵子树）
每个结点关键字数⌈m/2⌉-1 ~ m-1⌈m/2⌉ ~ m
非叶结点含数据✓✗（仅索引）
叶结点链接✗✓（链表连接，支持顺序查找）
  • B+树所有关键字都在叶结点，非叶结点是索引
  • 支持范围查找（顺链表扫描）

7.5 散列（Hash）表

7.5.1 基本概念

  • 散列函数：把查找表中的关键字映射为对应地址的函数 Hash(key)=Addr
  • 冲突：不同关键字映射到同一地址
  • 装填因子α = 表中记录数 / 散列表长度（α越大越易冲突）

7.5.2 散列函数构造方法

方法说明适用
直接定址法H(key)=a×key+b关键字分布连续
除留余数法H(key)=key % p（p取不大于表长m的素数）最常用
数字分析法取关键字若干位关键字已知
平方取中法取关键字平方的中间几位关键字每位分布不均

7.5.3 处理冲突的方法

再散列法用第二个散列函数计算增量

二、拉链法（链接法）

  • 将所有同义词存储在一个线性链表中
  • 适用于经常插入删除的情况

第8章 排序

8.1 排序的基本概念

概念定义
排序重新排列表中元素，使按关键字有序
稳定性若排序前两个相等记录的前后顺序与排序后相同，则该算法稳定
内部排序排序期间元素全部在内存中
外部排序数据量大，部分数据需在外存

8.2 插入排序

8.2.1 直接插入排序

  • 思想：将待排序记录插入已排好序的子序列
  • 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
  • 空间复杂度：O(1)
  • 稳定性：稳定
  • 适用：基本有序、数据量小 → 效率极高

8.2.2 折半插入排序

  • 用折半查找确定插入位置，减少比较次数
  • 比较次数O(nlog₂n)，但移动次数不变，总时间仍O(n²)
  • 稳定性：稳定

8.2.3 希尔排序

  • 思想：将待排序列分成若干子序列，分别直接插入排序；逐步缩小子序列"增量"至1
  • 增量序列：一般取 d₁=n/2, d₂=d₁/2, ..., dₖ=1
  • 时间复杂度：约 O(n^1.3)（依赖于增量序列）
  • 空间复杂度：O(1)
  • 稳定性：不稳定（跳跃式移动）

8.3 交换排序

8.3.1 冒泡排序

  • 思想：两两比较，逆序则交换；每趟确定一个最大值
  • 优化：若一趟未发生交换，提前终止
  • 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
  • 稳定性：稳定

8.3.2 快速排序

  • 思想：分治——选枢轴(pivot)，划分为左右两部分（左≤枢轴≤右），递归
  • 划分算法：两个指针从两端向中间扫描
  • 时间复杂度：最好/平均O(nlog₂n)，最坏O(n²)（已有序且选最边元素为枢轴）
  • 空间复杂度：O(log₂n)（递归栈）
  • 稳定性：不稳定

优化策略：

  • 三数取中法选枢轴
  • 小数组用直接插入排序
  • 尾递归优化

8.4 选择排序

8.4.1 简单选择排序

  • 思想：每趟选出最小元素放到已排序列末尾
  • 时间复杂度：最好/最坏/平均 O(n²)
  • 空间复杂度：O(1)
  • 稳定性：不稳定（交换破坏稳定性）

8.4.2 堆排序

堆的定义（完全二叉树）：

  • 大根堆：$L(i) \geq L(2i) \text{ 且 } L(i) \geq L(2i+1)$（根最大）
  • 小根堆：$L(i) \leq L(2i) \text{ 且 } L(i) \leq L(2i+1)$（根最小）

操作：

  • 建堆：从⌊n/2⌋开始向前调整，时间复杂度O(n)
  • AdjustDown（向下调整/筛选）：
  • 大根堆：与左右孩子中较大者比较，小的下沉
  • 堆排序：反复将堆顶（最大/最小）与最后一个元素交换，对剩余元素重新调整

时空复杂度：

  • 建堆：O(n)
  • 每趟调整：O(log₂n)
  • 总体：O(nlog₂n)
  • 空间复杂度：O(1)
  • 稳定性：不稳定

堆的插入：放在最后，向上调整（AdjustUp）

8.5 归并排序、基数排序和计数排序

8.5.1 归并排序（Merge Sort）

  • 思想：将两个（或以上）有序表合并为一个有序表
  • 二路归并：
  1. 将序列分解为n个长度为1的有序子序列
  2. 两两归并，重复直到长度=n
  • 时间复杂度：O(nlog₂n)（最好/最坏/平均一致）
  • 空间复杂度：O(n)（需要辅助数组）
  • 稳定性：稳定

8.5.2 基数排序

  • 思想：基于关键字的各位大小排序，不基于比较
  • 最高位优先(MSD) vs 最低位优先(LSD)
  • 过程（LSD）：分配→收集，从低位到高位逐位排序
  • 时间复杂度：O(d(n+r))，d为位数，r为基数
  • 空间复杂度：O(r)（队列个数）
  • 稳定性：稳定

8.5.3 计数排序★（2024/2025新增考点）

  • 思想：统计每个元素出现的次数
  • 适用：数据范围有限（如0~k），值为整数
  • 时间复杂度：O(n+k)，k为数据范围
  • 空间复杂度：O(k)
  • 稳定性：稳定（从后往前填充可保证）

8.7 外部排序

8.7.1 基本概念

  • 数据量大无法全部调入内存 → 需要外存（通常指磁盘）
  • 外部排序 = 生成初始归并段 + 多路归并

8.7.2 外部排序的方法

  • 归并排序思想：将文件分成若干块读入内存内部排序后写回→形成初始归并段→多路归并
  • 总时间 = 内部排序时间 + 外存读写时间 + 内部归并时间
  • 总I/O次数 = 归并趟数 × 每次读写的块数 × 2

8.7.3 多路平衡归并与败者树

  • 败者树：增加归并路数k时减少比较次数的一种结构
  • k路归并每次选最小元素需比较 k-1 次
  • 使用败者树只需 log₂k 次
  • 败者树是完全二叉树，叶子存放各归并段当前元素

8.7.4 置换-选择排序

  • 目的：生成尽可能长的初始归并段，减少归并趟数
  • 算法：用最小堆，读入数据到堆满，输出堆顶后读入新数据，若新数据<已输出的且堆有空间→暂存；堆空时输出所有暂存数据作为新段开始

8.7.5 最佳归并树

  • 问题：如何安排归并顺序使I/O次数最少
  • 方法：类似哈夫曼树的构造（以段长为权值，构造k叉哈夫曼树）
  • 虚段：若 (初始归并段数-1)/(k-1) ≠ 0（有余数），需补充虚段
