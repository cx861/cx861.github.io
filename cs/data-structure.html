第1章 绪论

1.1 数据结构的基本概念

1.1.1 基本概念和术语

术语定义关键理解
数据信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理的符号的集合数据是计算机程序加工的原料
数据元素数据的基本单位，通常作为一个整体进行考虑和处理数据元素可由若干数据项组成，数据项是构成数据元素的不可分割的最小单位
数据对象具有相同性质的数据元素的集合，是数据的子集例如：整数数据对象是集合 N = {0, ±1, ±2, ...}
数据类型一个值的集合和定义在此集合上的一组操作的总称原子类型（int, char等）+ 结构类型（struct等）
抽象数据类型(ADT)指一个数学模型及定义在该模型上的一组操作，仅取决于逻辑特性，与其在计算机内部如何表示和实现无关通常用(数据对象, 数据关系, 基本操作集)三元组表示
数据结构相互之间存在一种或多种特定关系的数据元素的集合包括逻辑结构、存储结构和数据的运算

1.1.2 数据结构的三要素

一、数据的逻辑结构

逻辑结构是指数据元素之间的逻辑关系，与数据的存储无关。

逻辑结构特点常见例子
集合数据元素之间仅同属一个集合，没有其他关系-
线性结构数据元素之间是一对一的关系线性表、栈、队列、串
树形结构数据元素之间是一对多的关系树、二叉树
图状/网状结构数据元素之间是多对多的关系图

二、数据的存储结构（物理结构）

存储结构是指数据结构在计算机中的表示（映像）。

存储结构特点优点缺点
顺序存储逻辑上相邻的元素存储在物理位置上也相邻的存储单元中随机存取，存储密度大插入删除需移动大量元素
链式存储逻辑上相邻的元素在物理位置上不一定相邻，借助指针表示元素间逻辑关系插入删除方便，不需移动元素存储密度小，只能顺序存取
索引存储在存储元素的同时还建立附加的索引表检索速度快增加了索引表的存储空间
散列存储（哈希存储）根据元素的关键字直接计算出该元素的存储地址检索、增删速度快可能出现冲突，处理冲突增加开销

三、数据的运算

施加在数据上的运算包括运算的定义（逻辑结构）和运算的实现（存储结构）。

1.2 算法与算法评价

1.2.1 算法的基本概念

概念说明
算法定义对特定问题求解步骤的一种描述，是指令的有限序列
算法的5个特性① 有穷性：必须在有穷步之后结束；② 确定性：每一条指令必须有确切的含义；③ 可行性：可以通过已实现的基本运算执行有限次来实现；④ 输入：有零个或多个输入；⑤ 输出：有一个或多个输出
好算法标准正确性、可读性、健壮性、高效率与低存储量需求（时间复杂度低 + 空间复杂度低）

1.2.2 算法效率的度量

一、时间复杂度 T(n) = O(f(n))

  • 含义：算法中所有语句的频度之和 T(n) 的数量级
  • 分析规则：
  • 加法规则：T(n) = T₁(n) + T₂(n) = O(max(f(n), g(n)))
  • 乘法规则：T(n) = T₁(n) × T₂(n) = O(f(n) × g(n))
  • 常见时间复杂度比较（从小到大）： O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)
  • 三种时间复杂度分析：
  • 最好时间复杂度：在最理想情况下的时间复杂度
  • 最坏时间复杂度：在最坏情况下的时间复杂度
  • 平均时间复杂度：所有可能输入实例在等概率出现的情况下，算法的期望运行时间

二、空间复杂度 S(n) = O(g(n))

  • 算法所耗费的存储空间，包括存储算法本身、输入输出数据、以及算法运行过程中的临时占用存储空间
  • 算法原地工作：指算法所需的辅助空间为常量，即 O(1)

1.2.3 典型的时间复杂度分析

  1. 循环主体中的变量参与循环条件的判断
  • for(i=1; i<=n; i*=2) → O(log₂n)
  • for(i=1; i<=n; i++) for(j=1; j<=n; j++) → O(n²)
  1. 循环主体中的变量与循环条件无关（递归程序）
  • 递推公式法分析递归算法

第2章 线性表

2.1 线性表的定义和基本操作

2.1.1 线性表的定义

  • 定义：具有相同数据类型的 n(n≥0) 个数据元素的有限序列
  • 特点：
  • 表中元素个数有限
  • 表中元素具有逻辑上的顺序性
  • 表中元素都是数据元素，每个元素都是原子类型
  • 表中元素的数据类型相同，占据相同大小的存储空间
  • 表中元素具有抽象性，只讨论元素间的逻辑关系

2.1.2 线性表的基本操作

操作说明
InitList(&L)初始化表，构造一个空线性表
Length(L)求表长，返回L中数据元素个数
LocateElem(L, e)按值查找，在L中查找第一个值等于e的元素
GetElem(L, i)按位查找，获取L中第i个位置的元素值
ListInsert(&L, i, e)插入，在L的第i个位置插入新元素e
ListDelete(&L, i, &e)删除，删除L中第i个元素并用e返回其值
PrintList(L)输出，按前后顺序输出所有元素值
Empty(L)判空
DestroyList(&L)销毁

2.2 线性表的顺序表示（顺序表）

2.2.1 顺序表的定义

  • 用一组地址连续的存储单元依次存储线性表中的数据元素，使得逻辑上相邻的元素在物理位置上也相邻
  • 特点：逻辑顺序 = 物理顺序，可随机存取（O(1)时间复杂度访问任意元素）
  • 存储密度高（每个结点只存数据元素）

2.2.2 顺序表基本操作的实现

操作时间复杂度说明
插入（第i个位置）O(n)需要后移 n-i+1 个元素，平均移动 n/2
删除（第i个位置）O(n)需要前移 n-i 个元素，平均移动 (n-1)/2
按值查找O(n)平均比较 (n+1)/2 次
按位查找O(1)随机存取

2.3 线性表的链式表示（链表）

2.3.1 单链表的定义

  • 通过一组任意的存储单元来存储线性表中的数据元素
  • 每个结点包含数据域(data) 和指针域(next)
  • 头指针：指向第一个结点的指针
  • 头结点：在第一个元素结点之前附加的结点（数据域可不存信息），可简化操作

2.3.2 单链表基本操作的实现

操作时间复杂度关键点
头插法建立单链表O(n)每次插入在头部，读入顺序与生成顺序相反
尾插法建立单链表O(n)增加尾指针，读入顺序与生成顺序相同
按序号查找结点O(n)从第一个结点开始顺next域逐个向下搜索
按值查找结点O(n)同上
插入结点（前插）O(n) / O(1)已知前驱O(1)；未知前驱需先查找O(n)
删除结点O(n) / O(1)已知前驱O(1)；未知前驱需先查找O(n)
求表长O(n)需遍历

特殊技巧：

  • "前插"变"后插"再交换：在p结点前插入元素s → 先将s插入p之后，再交换p和s的数据域
  • 删除p结点（已知p）：将p的后继数据复制到p，然后删除p的后继

2.3.3 双链表

  • 每个结点包含两个指针：prior（指向前驱）和next（指向后继）
  • 插入操作需修改4个指针（s->next, s->prior, p->next, s->next->prior）
  • 删除操作需修改2个指针
  • 双链表的按位查找和按值查找与单链表相同
  • 优点：可双向遍历，插入删除更方便

2.3.4 循环链表

类型特点判空条件
循环单链表最后一个结点的指针指向头结点头结点的next = 头指针
循环双链表头结点的prior指向尾结点，尾结点的next指向头结点头结点的prior = 头指针 且 头结点的next = 头指针

2.3.5 静态链表

  • 借助数组来描述链式存储结构，结点也有data域和next域（游标/cur）
  • 需要预先分配连续空间
  • 以 next == -1 作为结束标志

2.3.6 顺序表与链表的比较

比较维度顺序表链表
存取方式顺序存取 + 随机存取仅顺序存取
逻辑/物理结构逻辑相邻 = 物理相邻逻辑相邻 ≠ 物理相邻
查找按值O(n)，按位O(1)按值O(n)，按位O(n)
插入/删除O(n)，需移动元素O(1)（已知位置时），只需修改指针
空间分配静态分配（溢出问题），存储密度=1动态分配，存储密度<1

选择策略：

  • 基于存储：难估计长度/规模时→链表；长度固定→顺序表
  • 基于运算：频繁按序号访问→顺序表；频繁插入删除→链表
  • 基于环境：语言环境支持→顺序表简单；不支持→链表

第3章 栈、队列和数组

3.1 栈

3.1.1 栈的基本概念

  • 定义：只允许在一端（栈顶）进行插入和删除操作的线性表，遵循后进先出(LIFO)原则
  • 栈顶(Top)：允许插入删除的一端
  • 栈底(Bottom)：不允许操作的一端
  • 空栈：不含任何元素的空表
  • 数学性质：n个不同元素进栈，出栈序列的个数为 卡特兰数 C(2n,n)/(n+1)

3.1.2 栈的顺序存储结构

实现要点说明
结构体data[MaxSize] + int top
栈空条件top == -1（初始时top=-1）
栈满条件top == MaxSize-1
进栈data[++top] = x
出栈x = data[top--]
栈长top + 1

共享栈：两个栈共享一个数组空间，栈底分别设在两端，栈顶向中间延伸。

  • 栈空：top0 = -1（左栈空），top1 = MaxSize（右栈空）
  • 栈满：top1 - top0 = 1

3.1.3 栈的链式存储结构

  • 优点：不存在栈满上溢问题
  • 通常采用单链表实现，所有操作在表头进行
  • 链栈的插入和删除操作对应单链表的头插法和头删法

3.2 队列

3.2.1 队列的基本概念

  • 定义：只允许在表的一端（队尾）插入，另一端（队头）删除的线性表，遵循先进先出(FIFO)原则
  • 队头(Front)：允许删除的一端
  • 队尾(Rear)：允许插入的一端

3.2.2 队列的顺序存储结构

循环队列：

实现方案队空条件队满条件
牺牲一个存储单元Q.front == Q.rear(Q.rear+1) % MaxSize == Q.front
增设size/tag成员size == 0 / tag == 0size == MaxSize / tag == 1
  • 元素个数：(Q.rear - Q.front + MaxSize) % MaxSize
  • 入队：Q.rear = (Q.rear + 1) % MaxSize; Q.data[Q.rear] = x;
  • 出队：x = Q.data[Q.front]; Q.front = (Q.front + 1) % MaxSize;

3.2.3 队列的链式存储结构

  • 链队：同时带有头指针和尾指针的单链表
  • 头指针指向队头结点，尾指针指向队尾结点
  • 出队时需要判断是否变为空队（若出队前仅一个结点，出队后尾指针也要置空）

3.2.4 双端队列

  • 允许在两端进行插入和删除操作的线性表
  • 输出受限的双端队列：一端允许插入删除，另一端只允许插入
  • 输入受限的双端队列：一端允许插入删除，另一端只允许删除

3.3 栈和队列的应用

3.3.1 栈在括号匹配中的应用

  • 扫描字符串，遇左括号入栈，遇右括号时：
  • 若栈空→不匹配
  • 若栈顶左括号与当前右括号匹配→出栈
  • 若不匹配→非法
  • 最后栈空则匹配成功

3.3.2 栈在表达式求值中的应用

表达式类型运算符位置示例
中缀表达式运算符在两个操作数之间a + b
前缀表达式（波兰式）运算符在操作数之前+ a b
后缀表达式（逆波兰式）运算符在操作数之后a b +

中缀→后缀（栈中存放运算符）：

  1. 操作数直接输出
  2. 运算符与栈顶比较优先级：高则入栈，低则弹栈直到遇左括号或优先级更低的运算符
  3. 左括号直接入栈，右括号弹出到左括号（括号不输出）
  4. 遍历完将栈中剩余运算符全部弹出

后缀表达式求值（栈中存放操作数）：

  • 操作数入栈，遇运算符则弹出两个操作数计算后压回

3.3.3 栈在递归中的应用

  • 递归调用的实现依赖系统栈，保存调用返回地址、实参、局部变量
  • 递归转非递归通常需要用户自己定义栈

3.3.4 队列在层次遍历中的应用

  • 二叉树的层次遍历
  • 图的广度优先搜索(BFS)

3.3.5 队列在计算机系统中的应用

  • 打印数据缓冲区（主机→打印机 速度不匹配）
  • CPU资源竞争（FCFS先来先服务）

3.4 数组和特殊矩阵

3.4.1 数组的定义

  • n个相同类型数据元素构成的有限序列
  • 数组是线性表的推广：一维数组是线性表，二维数组是其元素为一维数组的线性表

3.4.2 数组的存储结构

  • 按行优先存储（C/C++、Java等）：
  • LOC(a[i][j]) = LOC(a[0][0]) + (i×n+j)×L
  • 按列优先存储（Fortran等）：
  • LOC(a[i][j]) = LOC(a[0][0]) + (j×m+i)×L

3.4.3 特殊矩阵的压缩存储

矩阵类型压缩方式关键技术
对称矩阵只存下三角（或上三角）+对角线$a_{ij}$ 在下三角(i≥j)时存 $B[\frac{i(i-1)}{2}+j-1]$（下标从1开始）
三角矩阵下三角矩阵：存非零区域 + 一个共享常量与对称矩阵类似，但常数单独存储
三对角矩阵只存主对角线和两条次对角线（3n-2个元素）$a_{ij}$ 存 $B[2i+j-3]$（|i-j|≤1时）
稀疏矩阵三元组表 / 十字链表只存非零元素的行、列、值

压缩存储下标速查（按行优先、下标从1开始）：

矩阵存储区域一维下标k元素总数
对称矩阵下三角含主对角线$k=\frac{i(i-1)}{2}+j,\;i\ge j$$\frac{n(n+1)}{2}$
上三角矩阵上三角含主对角线 + 常量$k=\frac{(i-1)(2n-i+2)}{2}+(j-i+1),\;i\le j$$\frac{n(n+1)}{2}+1$
下三角矩阵下三角含主对角线 + 常量$k=\frac{i(i-1)}{2}+j,\;i\ge j$$\frac{n(n+1)}{2}+1$
三对角矩阵$|i-j|\le 1$$k=2i+j-2$（1-based）；$k=2i+j-3$（0-based）$3n-2$

稀疏矩阵三元组：每个非零元素用 $(row,col,value)$ 表示，适合非零元较少且随机访问不频繁的矩阵。

快速转置思想：先统计每一列非零元个数，再求每列在转置三元组表中的起始位置，最后一次扫描原三元组表即可完成转置，时间复杂度 $O(n+t)$（$t$ 为非零元个数）。

十字链表：每个非零结点同时处在所在行链表和列链表中，适合稀疏矩阵插入、删除和按行/按列遍历。

第4章 串

4.1 串的定义和实现

4.1.1 串的定义

  • 串：由零个或多个字符组成的有限序列
  • 空串 ∅：零个字符的串
  • 子串、主串：串中任意个连续字符组成的子序列
  • 空格串：由一个或多个空格组成的串（≠空串）

4.1.2 串的存储结构

存储方式特点
定长顺序存储预定最大长度，超过截断
堆分配存储动态分配，C语言的malloc/free
块链存储链表结点存放多个字符（块）

4.2 串的模式匹配

4.2.1 简单模式匹配（BF算法）

  • 主串S和模式串T，从S的第一个字符开始逐个比较
  • 匹配失败则回溯：i = i-j+2, j = 1
  • 时间复杂度：最坏O(mn)，最好O(n)

4.2.2 KMP算法

  • 核心思想：利用已匹配部分的信息，主串i不回溯
  • next数组：当模式串的第j个字符与主串失配时，将模式串跳到 next[j] 位置继续比较

next数组手工计算规则：

  • next[1] = 0
  • 对于j>1，next[j] = S的最长相等前后缀长度 + 1
  • 即：取模式串前 j-1 个字符构成的子串，找其最长相等的前后缀长度，+1

next / nextval手算流程

  1. 先确定采用 1-based 还是 0-based 写法，408手算题常见 1-based：$next[1]=0$。
  2. 求 $next[j]$ 时，只看模式串 $P[1..j-1]$ 的最长相等真前后缀长度，再加1。
  3. 求 $nextval[j]$ 时，若 $P[j]=P[next[j]]$，则 $nextval[j]=nextval[next[j]]$；否则 $nextval[j]=next[j]$。

5.2.1 二叉树的定义

  • 每个结点最多有两棵子树（度≤2），且有左右之分，不能颠倒

转换规则（孩子兄弟表示法）：

  • 树→二叉树：左孩子右兄弟
  • 森林→二叉树：先将每棵树转为二叉树，再将后一棵树的根作为前一棵树根的右子树
  • 二叉树→森林：断开右链得到多棵树根

核心规律：树（森林）转二叉树后，原树的叶子在二叉树中没有左孩子

5.5 树与二叉树的应用

5.5.1 哈夫曼树和哈夫曼编码

哈夫曼树的定义：

  • 路径长度：从根到该结点的路径上的边数
  • 带权路径长度 WPL：$\sum_{i=1}^{n} w_i \times l_i$（权值×路径长度之和）
  • 哈夫曼树：WPL最小的二叉树（最优二叉树）

哈夫曼树的构造（贪心算法）：

  1. 将n个结点看作n棵只有根的二叉树，构成森林F
  2. 在F中选取两棵根权值最小的树作为左右子树，构造新二叉树（新根权值=两子树权值之和）
  3. 从F中删除这两棵树，加入新树
  4. 重复直到F中仅剩一棵树

哈夫曼树特点：

  • 初始结点都是叶子，且权值越小离根越远
  • 没有度为1的结点（只有度为0和度为2的结点）
  • $n_0 = n_2 + 1$（叶子比分支结点多1个）
  • 结点总数为 $2n_0 - 1$

哈夫曼编码：

  • 前缀编码：任一字符的编码都不是另一字符编码的前缀
  • 哈夫曼编码是最优前缀编码
  • 构造：左分支标0，右分支标1（或相反）

5.5.2 并查集（Union-Find Set）

操作说明时间复杂度
Initial(S)初始化，每个元素自成单元素集合O(n)
Find(S, x)查找x所属集合的根（代表元）O(α(n))（优化后）

优化策略：

  • 按秩合并（Union by Rank）：总是将小树合并到大树上
  • 路径压缩（Path Compression）：查找时把路径上所有结点直接连到根

应用：

  • 判断图的连通性
  • Kruskal算法求最小生成树

6.3 图的遍历

6.3.1 广度优先搜索（BFS）

  • 算法思想：类似树的层次遍历，借助队列实现
  • 时间复杂度：邻接矩阵O(|V|²)，邻接表O(|V|+|E|)
  • 空间复杂度：O(|V|)（队列中最多|V|个顶点）
  • 应用：
  • 求解单源最短路径（无权图）
  • 广度优先生成树（BFS树）

6.3.2 深度优先搜索（DFS）

  • 算法思想：类似树的先根遍历，借助栈（递归）实现
  • 时间复杂度：同BFS
  • 空间复杂度：O(|V|)（递归栈深度）
  • 应用：
  • 深度优先生成树/森林
  • 判断连通性
  • 拓扑排序的逆序

BFS/DFS序列合法性判断：

  • BFS按层扩展，队列中先入队的顶点应先扩展；若某顶点的下一层结点跨层提前出现，则序列非法。
  • DFS沿一条路径尽量深入，退栈后才访问其他分支；判断时可画出搜索树并检查是否存在可继续深入却提前回溯。
  • 邻接点访问顺序不唯一，因此同一图可能有多个合法BFS/DFS序列。

6.3.3 图的连通性

  • 无向图：调用BFS/DFS次数 = 连通分量个数
  • 有向图：从某顶点出发不一定能访问所有顶点（可能存在非强连通）

6.4.1 最小生成树（MST）

定义：带权连通无向图中，各边权值之和最小的生成树

算法思想时间复杂度适用

关键：最小生成树可能不唯一，但权值之和唯一

6.4.2 最短路径

问题算法时间复杂度适用
单源最短路径DijkstraO(|V|²)边权≥0
各顶点间最短路径FloydO(|V|³)允许负权（无负环）

Dijkstra算法：

  • 每次从未标记顶点中选距离最小的，更新其邻接点距离
  • 不能处理负权边
  • 若要恢复路径，需维护 path[] 或 pre[] 数组，记录每个顶点当前最短路径上的前驱

Floyd算法（动态规划）：

  • $A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$
  • 最后得到的A矩阵存放最短路径长度
  • 路径矩阵 path[i][j] 可记录从 $i$ 到 $j$ 的中转点 $k$，用于递归输出完整路径

6.4.3 有向无环图(DAG)描述表达式

  • 用DAG表示表达式可以节省存储空间
  • 合并重复子表达式：相同子式不重复出现

6.4.4 拓扑排序（AOV网）

  • AOV网：用顶点表示活动，有向边表示活动间的优先关系
  • 拓扑排序：对AOV网构造一个顶点的线性序列
  • 算法：
  1. 从AOV网中选一个无前驱（入度为0）的顶点并输出
  2. 网中删除该顶点及其所有出边
  3. 重复直到不存在无前驱的顶点
  • 若最后有剩余顶点→存在回路/环
  • 时间复杂度：邻接表O(|V|+|E|)，邻接矩阵O(|V|²)
  • 逆拓扑排序用DFS实现更方便

6.4.5 关键路径（AOE网）

  • AOE网：用边表示活动，权值表示持续时间，顶点表示事件
  • 关键路径：从源点到汇点路径长度最长的路径
  • 关键活动：关键路径上的活动

四个关键量：

  • 算法：每次与中间元素比较，每次排除一半
  • 判定树：平衡二叉树
  • 时间复杂度：O(log₂n)
  • 查找成功ASL ≈ log₂(n+1) - 1
  • 查找失败ASL ≈ log₂(n+1)

7.2.3 分块查找（索引顺序查找）

  • 结构：索引表（有序）+ 块内（无序）
  • ASL = 索引查找ASL + 块内查找ASL
  • 若长度为n的表分为b块，每块s个记录：$ASL = \frac{b+1}{2} + \frac{s+1}{2} = \frac{s^2+2s+n}{2s}$

7.3 树形查找

7.3.1 二叉排序树（BST）

定义：左子树 < 根 < 右子树（递归定义）

操作说明
查找从根开始，小于→左子树，大于→右子树
插入查找失败的位置即为插入位置
删除三种情况：叶子（直接删）、单孩子（孩子替代）、双孩子（中序前驱/后继替代）
查找效率最好O(log₂n)（平衡时），最差O(n)（单枝树）

7.3.2 平衡二叉树（AVL）

  • 定义：|左子树高度 - 右子树高度| ≤ 1（平衡因子只取{0, 1, -1}）
  • 平衡因子 = 左子树高 - 右子树高

插入后的调整（4种旋转）：

情况操作
LL（左孩子的左子树插入）右单旋转
RR（右孩子的右子树插入）左单旋转
LR（左孩子的右子树插入）先左旋后右旋
RL（右孩子的左子树插入）先右旋后左旋

性质：

  • 深度为h的AVL树最少结点数：$N_h = N_{h-1} + N_{h-2} + 1$（类似斐波那契）
  • n个结点的AVL树最大深度约为 O(log₂n)

删除后的调整：删除后从被删结点向上检查平衡因子，发现不平衡则旋转调整

7.3.3 红黑树

定义（5条性质）：

  1. 每个结点是红色或黑色
  2. 根结点是黑色
  3. 叶结点（NIL）是黑色
  4. 红色结点的两个子结点都是黑色（无连续红）
  5. 从任一结点到其每个叶子的所有路径包含相同数量的黑色结点（黑高相等）

结论：

  • 从根到叶子的最长路径 ≤ 2×最短路径
  • n个内部结点的红黑树高度 ≤ 2log₂(n+1)

插入调整（3种情况）：

  • 父黑：无需调整
  • 父红：看叔叔颜色
  • 叔叔红：变色
  • 叔叔黑（LL/RR）：旋转+变色
  • 叔叔黑（LR/RL）：旋转两次+变色

7.4 B树和B+树

7.4.1 B树

m阶B树的特性：

  1. 每个结点至多有m棵子树，m-1个关键字

  3. 若根不是终端结点，至少有2棵子树

删除非终端→找前驱/后继替代后删除终端；终端删除若不够则"借"兄弟或合并

第8章 排序

8.1 排序的基本概念

概念定义
排序重新排列表中元素，使按关键字有序
稳定性若排序前两个相等记录的前后顺序与排序后相同，则该算法稳定
内部排序排序期间元素全部在内存中
外部排序数据量大，部分数据需在外存

8.2 插入排序

8.2.1 直接插入排序

  • 思想：将待排序记录插入已排好序的子序列
  • 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
  • 空间复杂度：O(1)
  • 稳定性：稳定
  • 适用：基本有序、数据量小 → 效率极高

8.2.2 折半插入排序

  • 用折半查找确定插入位置，减少比较次数
  • 比较次数O(nlog₂n)，但移动次数不变，总时间仍O(n²)
  • 稳定性：稳定

8.2.3 希尔排序

  • 思想：将待排序列分成若干子序列，分别直接插入排序；逐步缩小子序列"增量"至1
  • 增量序列：一般取 d₁=n/2, d₂=d₁/2, ..., dₖ=1
  • 时间复杂度：约 O(n^1.3)（依赖于增量序列）
  • 空间复杂度：O(1)
  • 稳定性：不稳定（跳跃式移动）

8.3 交换排序

8.3.1 冒泡排序

  • 思想：两两比较，逆序则交换；每趟确定一个最大值
  • 优化：若一趟未发生交换，提前终止
  • 时间复杂度：最好O(n)，最坏O(n²)，平均O(n²)
  • 稳定性：稳定

8.3.2 快速排序

  • 思想：分治——选枢轴(pivot)，划分为左右两部分（左≤枢轴≤右），递归
  • 划分算法：两个指针从两端向中间扫描
  • 时间复杂度：最好/平均O(nlog₂n)，最坏O(n²)（已有序且选最边元素为枢轴）
  • 空间复杂度：O(log₂n)（递归栈）
  • 稳定性：不稳定

优化策略：

  • 三数取中法选枢轴
  • 小数组用直接插入排序
  • 尾递归优化

8.4 选择排序

8.4.1 简单选择排序

  • 思想：每趟选出最小元素放到已排序列末尾
  • 时间复杂度：最好/最坏/平均 O(n²)
  • 空间复杂度：O(1)
  • 稳定性：不稳定（交换破坏稳定性）

8.4.2 堆排序

堆的定义（完全二叉树）：

  • 大根堆：$L(i) \geq L(2i) \text{ 且 } L(i) \geq L(2i+1)$（根最大）
  • 小根堆：$L(i) \leq L(2i) \text{ 且 } L(i) \leq L(2i+1)$（根最小）

操作：

  • 建堆：从⌊n/2⌋开始向前调整，时间复杂度O(n)
  • AdjustDown（向下调整/筛选）：
  • 大根堆：与左右孩子中较大者比较，小的下沉
  • 堆排序：反复将堆顶（最大/最小）与最后一个元素交换，对剩余元素重新调整

时空复杂度：

  • 建堆：O(n)
  • 每趟调整：O(log₂n)
  • 总体：O(nlog₂n)
  • 空间复杂度：O(1)
  • 稳定性：不稳定

堆的插入：放在最后，向上调整（AdjustUp）

8.5 归并排序、基数排序和计数排序

8.5.1 归并排序（Merge Sort）

  • 思想：将两个（或以上）有序表合并为一个有序表
  • 二路归并：
  1. 将序列分解为n个长度为1的有序子序列
  2. 两两归并，重复直到长度=n
  • 时间复杂度：O(nlog₂n)（最好/最坏/平均一致）
  • 空间复杂度：O(n)（需要辅助数组）
  • 稳定性：稳定

8.5.2 基数排序

  • 思想：基于关键字的各位大小排序，不基于比较
  • 最高位优先(MSD) vs 最低位优先(LSD)
  • 过程（LSD）：分配→收集，从低位到高位逐位排序
  • 时间复杂度：O(d(n+r))，d为位数，r为基数
  • 空间复杂度：O(r)（队列个数）
  • 稳定性：稳定

8.5.3 计数排序★（2024/2025新增考点）

  • 思想：统计每个元素出现的次数
  • 适用：数据范围有限（如0~k），值为整数
  • 时间复杂度：O(n+k)，k为数据范围
  • 空间复杂度：O(k)
  • 稳定性：稳定（从后往前填充可保证）

8.7 外部排序

8.7.1 基本概念

  • 数据量大无法全部调入内存 → 需要外存（通常指磁盘）
  • 外部排序 = 生成初始归并段 + 多路归并

8.7.2 外部排序的方法

  • 归并排序思想：将文件分成若干块读入内存内部排序后写回→形成初始归并段→多路归并
  • 总时间 = 内部排序时间 + 外存读写时间 + 内部归并时间
  • 总I/O次数 = 归并趟数 × 每次读写的块数 × 2

归并趟数：若有 $r$ 个初始归并段，进行 $k$ 路平衡归并，则归并趟数为 $\lceil \log_k r \rceil$。

I/O次数常用估算：每趟归并需要读入和写出全部记录各一次，因此总I/O次数约为 $2S\lceil \log_k r \rceil$，其中 $S$ 为文件块数或记录块数。

8.7.3 多路平衡归并与败者树

  • 败者树：增加归并路数k时减少比较次数的一种结构
  • k路归并每次选最小元素需比较 k-1 次
  • 使用败者树只需 log₂k 次
  • 败者树是完全二叉树，叶子存放各归并段当前元素
  • 败者树不减少外存I/O次数，主要减少内部比较次数

8.7.4 置换-选择排序

  • 目的：生成尽可能长的初始归并段，减少归并趟数
  • 算法：用最小堆，读入数据到堆满，输出堆顶后读入新数据，若新数据<已输出的且堆有空间→暂存；堆空时输出所有暂存数据作为新段开始

段切换规则：若新读入关键字小于当前归并段最后输出关键字，则该记录不能进入当前段，应被冻结到下一段；当前堆中可输出记录全部输出后，解冻被冻结记录并开始新段。

8.7.5 最佳归并树

  • 问题：如何安排归并顺序使I/O次数最少
  • 方法：类似哈夫曼树的构造（以段长为权值，构造k叉哈夫曼树）
  • 虚段：设初始归并段数为 $r$，若 $(r-1)\bmod(k-1)\neq 0$，需补 $d$ 个长度为0的虚段，使 $(r+d-1)\bmod(k-1)=0$

1. 复杂度与递归代价

先记条件：先明确基本操作、循环边界和规模变量；递归时间、递归栈空间分别计算。

数据结构 01｜循环 i 从 1 到 n，内层 j 从 i 到 n，每次执行一次加法。求总次数与时间阶。

展开推演、易错点与检查
  1. 第 i 轮有 n−i+1 次；总数为 n+(n−1)+…+1=n(n+1)/2。
  2. 最高次项是 n²/2，故为 Θ(n²)，不是把内层的变化下界忽略后直接写精确 n²。

易错原因：把上界 O(n²) 当作精确执行次数。

检查动作：用 n=1、2 分别代入，次数应为 1、3。

数据结构 02｜n 是 2 的幂，T(1)=1，T(n)=2T(n/2)+n。求精确表达式与递归栈阶。

展开推演、易错点与检查
  1. 每个非叶层总代价为 n，共 log₂n 层；叶节点 n 个，各耗时 1。
  2. T(n)=n log₂n+n，时间 Θ(n log n)。深度优先顺序执行两个递归分支且每层仅保存常量状态时，递归栈为 Θ(log n)。

易错原因：把递归树总节点数当成同时存活的栈帧数；额外数组空间还应另外计算。

检查动作：n=4 时 T=12；空间分析先画任一时刻的调用链。

闭卷自测与答案

问：循环次数 n(n+1)/2 与 O(n²) 是否同一类结论？答：前者为精确次数，后者为渐近上界；描述不同。

2. 链表操作与指针不变量

先记条件：带头结点的空表是 H.next 为空；头结点不作为数据结点参与反转。释放前先保存后继。

数据结构 03｜带头结点单链表 H→A→B→C，删除首个数据结点，写出安全操作。

展开推演、易错点与检查
  1. 先确认 H.next 非空；令 q=H.next，保存待删结点。
  2. 执行 H.next=q.next，链变为 H→B→C；最后释放 q。时间 O(1)。

易错原因：先释放 A 再读 A.next，造成失效访问；或把头结点 H 误删。

检查动作：空表不删；只有 A 时删后 H.next 应为空。

数据结构 04｜原地反转带头结点链表 H→1→2→3，给出指针步骤和复杂度。

展开推演、易错点与检查
  1. 初始化 prev=空，cur=H.next。每轮先 next=cur.next，再 cur.next=prev，最后 prev=cur，cur=next。
  2. 三轮已反转部分依次为 1→空、2→1→空、3→2→1→空；终止后 H.next=prev。
  3. 时间 O(n)，额外空间 O(1)；循环不变量：prev 指向已反转部分，cur 指向尚未处理部分。

易错原因：改 next 指针后才找原后继，使剩余链丢失。

检查动作：逐轮检查每个结点恰在已处理或未处理链中；空表、单结点也成立。

闭卷自测与答案

问：只反转局部链而不更新 H.next 会怎样？答：头结点仍指向原首结点，无法从 H 遍历完整新链。

3. 栈、循环队列与表达式

先记条件：循环队列采用 front 指向首元素、rear 指向下一空位，牺牲一个存储单元；后缀计算先弹右操作数。

数据结构 05｜循环数组容量 5，front=1、rear=4，牺牲一个单元。队长多少？再入队一次后是否满？

展开推演、易错点与检查
  1. 队长 (rear−front+5)%5=3。
  2. 入队写入下标 4 后 rear=(4+1)%5=0，队长变为 4；(rear+1)%5=1=front，队满。最大可存 4 个元素。

易错原因：把 rear=front 解释成满；该约定下它表示空。

检查动作：画 0～4 五个格子，把保留空位单独标出。

数据结构 06｜计算后缀表达式 3 4 2 * + 5 −，列出操作数栈。

展开推演、易错点与检查
  1. 读入 3、4、2，栈为 [3,4,2]；乘法弹出 2、4，压入 8，栈 [3,8]。
  2. 加法得到 [11]；读 5 得 [11,5]；减法是 11−5，结果 [6]。

易错原因：先弹出的 5 是右操作数，不能计算为 5−11。

检查动作：每个二元运算消耗两个数并压入一个；最终栈中恰有一个结果。

闭卷自测与答案

问：若改用计数器判断满，容量是否仍只能用 4？答：不必；可以用满 5，但空满判定规则必须随之改变。

4. 压缩存储与 KMP 前缀函数

先记条件：地址题先声明下标起点、存储顺序和元素字节数；KMP 的 π、next、nextval 定义不可混用。

数据结构 07｜4 阶下三角矩阵含主对角线，按行紧凑存储，零基下标。基址 1000，每元素 4 字节，求 A[3,1] 地址。

展开推演、易错点与检查
  1. 第 3 行前共有 1+2+3=6 个元素；本行前有 1 个，所以紧凑下标为 7。
  2. 地址为 1000+7×4=1028。总存储元素数为 4×5/2=10。

易错原因：把主对角线遗漏，或把零基下标直接套一基公式。

检查动作：A[0,0] 应落在基址；A[3,3] 应是最后一个元素，下标 9。

数据结构 08｜模式串 ababaca，π[i] 定义为前缀 s[0..i] 的最长真前后缀长度。求 π 数组。

展开推演、易错点与检查
  1. 逐项得到 [0,0,1,2,3,0,1]。例如 ababa 的最长真前后缀为 aba，长度 3。
  2. 处理下标 5 的 c：候选 j=3，比较 s[3]=b 失败，退到 π[2]=1；s[1]=b 仍失败，退到 π[0]=0，s[0]=a 仍失败，因此 π[5]=0。
  3. 最后一个 a 与 s[0] 相等，所以 π[6]=1。

易错原因：失配时 j 只减 1，或将 π 值当成另一套一基 next 下标。

检查动作：对每项验证 0≤π[i]≤i，并实际截取长度为 π[i] 的前缀、后缀比较。

闭卷自测与答案

问：KMP 失配是否需要把文本指针回退？答：标准实现只沿前缀函数回退模式状态，文本指针不回退。

5. 二叉树还原与 Huffman 代价

先记条件：先序与中序且结点标识互异才能唯一还原；Huffman 每次合并最小的两个权值，WPL 等于合并权值之和。

数据结构 09｜先序为 A B D E C F，中序为 D B E A C F，求后序。

展开推演、易错点与检查
  1. 先序首项 A 为根；中序分为左 D B E、右 C F。
  2. 左子树根 B，左右分别 D、E；右子树根 C，只有右孩子 F。
  3. 后序依次为 D E B、F C、A，即 D E B F C A。

易错原因：把中序中的左右范围按字符顺序猜测；未核对子树结点集合。

检查动作：把还原树再输出一次先序与中序，应与题设完全一致。

数据结构 10｜权值 2、3、7、9 构造二叉 Huffman 树，求 WPL。

展开推演、易错点与检查
  1. 合并 2+3=5；再合并 5+7=12；最后合并 9+12=21。
  2. WPL=5+12+21=38；按深度核算为 2×3+3×3+7×2+9×1=38。

易错原因：把根的权值 21 当作 WPL；或按原输入相邻而不是当前最小合并。

检查动作：用叶权乘深度与全部合并值求和两种方式交叉核对。

闭卷自测与答案

问：只有先序和后序能否一般唯一还原？答：不能；仅一个孩子时无法判断它是左孩子还是右孩子。

6. BST、AVL 与查找路径

先记条件：BST 的中序有序；删除双孩子结点可以使用中序后继；AVL 必须从插入点向上找首个失衡祖先。

数据结构 11｜依次插入 30、10、40、20、35 构造 BST。查 20 比较几次？用中序后继删除 30 后的根是什么？

展开推演、易错点与检查
  1. 树根 30，左孩子 10（右孩子 20），右孩子 40（左孩子 35）。
  2. 查 20 路径为 30→10→20，共 3 次关键字比较。
  3. 30 的后继是右子树最小结点 35；以 35 替代根并删除原叶 35，新树根 35，右孩子 40。

易错原因：把右孩子 40 直接认作后继；忽略它的左子树。

检查动作：删除后中序应为 10、20、35、40，保持严格递增。

数据结构 12｜向空 AVL 树插入 30、10、20、40、50，给出两次调整与最终结构。

展开推演、易错点与检查
  1. 插入 20 后，30 的左孩子 10 的右侧过高，属于 LR：先左旋 10，再右旋 30；得到根 20、左 10、右 30。
  2. 插入 40、50 后，首个失衡祖先为 30，属于 RR，对 30 左旋。
  3. 最终根 20，左孩子 10；右孩子 40，40 的左右孩子为 30、50。

易错原因：按新结点相对整棵树根的方向选旋转，而非相对首个失衡祖先。

检查动作：每个结点左右高度差至多 1；中序仍为 10、20、30、40、50。

闭卷自测与答案

问：AVL 与红黑树是否都要求每个结点左右子树高度差至多 1？答：只有 AVL 有此要求；红黑树依据颜色与黑高约束平衡。

7. 多路查找树与散列探测

先记条件：本组 m 阶 B 树指最多 m 个孩子、m−1 个关键字，根有例外；散列失败查找须计入遇到首个空位的探测。

数据结构 13｜5 阶 B 树非根结点最少多少关键字？向空树依次插入 1～5，采用溢出后分裂。

展开推演、易错点与检查
  1. 非根内部结点最少 ceil(5/2)=3 个孩子，故最少 2 个关键字；最多 4 个关键字。
  2. 插入 1～4 后根含 [1,2,3,4]；插入 5 后暂有 5 个关键字，提升中间的 3。
  3. 新根 [3]，两叶分别 [1,2]、[4,5]。根可仅含 1 个关键字。

易错原因：将阶数误认为最大关键字数；把非根最少关键字数限制套在根上。

检查动作：所有叶深度一致；提升的 3 不再留在 B 树叶中。B+ 树的叶层规则另论。

数据结构 14｜表长 7，h(k)=k mod 7，线性探测插入 10、17、24、31。成功 ASL 与查找 38 的探测次数是多少？

展开推演、易错点与检查
  1. 四个关键字初始地址都是 3，依次占据下标 3、4、5、6，成功比较次数分别 1、2、3、4。
  2. 等概率成功 ASL=(1+2+3+4)/4=2.5。
  3. 查 38 从 3 出发，检查 3、4、5、6 后在 0 发现空位，共 5 次探测，失败。

易错原因：失败查找只算已有元素的比较，不算确认终止的空位；或忘记回绕。

检查动作：探测序列按 (h+i)%7 写全；删除时不能随意清空冲突链中的位置。

闭卷自测与答案

问：B+ 树范围查询为何常用叶链？答：定位起点后沿有序叶链扫描，无需反复从根查找；具体阶数定义以题设为准。

8. 图遍历、拓扑与关键路径

先记条件：遍历结果依赖邻接次序；AOE 关键路径分析需要 DAG，最早、最迟事件时间不是顶点入度。

数据结构 15｜无向图边 AB、AC、BD、CD、CE，从 A 开始，邻接点按字母序访问。写 BFS、DFS 序列。

展开推演、易错点与检查
  1. BFS：A 出队发现 B、C；B 发现 D；C 发现 E，得到 A B C D E。入队时即标记已访问。
  2. DFS：A→B→D→C→E，得到 A B D C E；回退时跳过访问过的顶点。

易错原因：队列出队时才标记而造成重复入队；未声明邻接次序却声称序列唯一。

检查动作：每个顶点输出一次；不同次序可以合法，但本题必须遵守字母序。

数据结构 16｜AOE 边 A→B:3，A→C:2，B→D:2，C→D:4，C→E:3，D→F:2，E→F:4。求工期和关键路径。

展开推演、易错点与检查
  1. 按拓扑序 A B C D E F，最早事件 ve 为 A0、B3、C2、D6、E5、F9，工期 9。
  2. 反向算 vl：F9，D7，E5，B5，C2，A0；汇合点 ve 取最大，分叉点 vl 取最小。
  3. 活动 u→v 的最早开始为 ve[u]，最迟开始为 vl[v]−w；相等的活动为 A→C、C→E、E→F。关键路径 A C E F。

易错原因：正向汇合取最小，误做最短路；仅凭事件最早最迟相等就把相邻边都判关键。

检查动作：沿关键路径长度 2+3+4=9，并逐条验活动时差。

闭卷自测与答案

问：拓扑排序输出顶点数小于总数说明什么？答：存在有向环；不一定是图不连通，非连通 DAG 也能全部输出。

9. 最短路径与最小生成树

先记条件：非负边单源最短路可用 Dijkstra；MST 目标是总边权最小，不保证从某源出发的树上距离最短。

数据结构 17｜无向图 AD:1、AB:4、BC:2、CD:3、AC:5、BD:6。从 A 用 Dijkstra 求距离。

展开推演、易错点与检查
  1. 初始 d(A)=0，d(D)=1，d(B)=4，d(C)=5。确定 D 后，C 改为 1+3=4，B 的候选 7 不优于 4。
  2. B、C 同为 4，任取其一先确定均可；通过 BC 不会再降低距离。
  3. 最终按 A、B、C、D 排列为 0、4、4、1；可取最短路树 AD、DC、AB，总边权 8。

易错原因：用最小出边不断连树，却不维护从源的累计距离；遇负边仍套 Dijkstra。

检查动作：对每条边检查 d[v]≤d[u]+w；每个可达非源顶点有前驱实现其距离。

数据结构 18｜对上一题同一图用 Kruskal 求 MST，并比较 MST 中 A 到 B 的距离。

展开推演、易错点与检查
  1. 按权排序 AD1、BC2、CD3、AB4、AC5、BD6，前三条均不形成环，已经连通 4 个顶点。
  2. MST 权为 1+2+3=6；树中 A→D→C→B 长度为 1+3+2=6，而原图 AB 直接边长度为 4。
  3. 因此 MST 总权 6 小于该最短路树总权 8，但其中 A 到 B 并非原图最短路。

易错原因：将最短路树与最小生成树混用；认为 MST 不能含负权边。

检查动作：确认恰有 n−1 条边且连通无环，再单独检查所问的路径。

闭卷自测与答案

问：不连通无向图运行 Kruskal 得到什么？答：最小生成森林，不能宣称得到覆盖所有顶点的一棵生成树。

10. 内排序与外归并

先记条件：排序要区分时间、额外空间、稳定性；外排序的缓冲区须给输出留一块，磁盘 I/O 单位也要明确。

数据结构 19｜对 [7,2,6,3] 自底向上二路归并，列出各趟，并说明相等关键字如何保持稳定。

展开推演、易错点与检查
  1. 初始四个长度 1 的段；第一趟两两合并为 [2,7]、[3,6]。
  2. 第二趟合并为 [2,3,6,7]；比较相等时先取左段原记录，才能保持同键先后顺序。
  3. 本实现时间 Θ(n log n)、辅助数组 Θ(n)；不能把快速排序最坏 Θ(n²) 或堆排序不稳定混到归并结论中。

易错原因：只记算法名不检查相等时分支，导致实现破坏稳定性。

检查动作：用带标签的等键记录验证，如左段 2a 与右段 2b 必须输出 2a 在先。

数据结构 20｜已有 20 个初始有序段，共 1000 磁盘块，归并阶段共 5 块缓冲区。求归并趟数和读写块次数；最终结果写回磁盘。

展开推演、易错点与检查
  1. 留 1 块作输出，最多 4 路归并；段数依次 20→5→2→1，需要 3 趟。
  2. 每趟每块读一次写一次，共 2000 次块 I/O；归并阶段总计 6000。
  3. 若题目另计生成初始段且该阶段对全文件只读写一次，再加 2000，合计 8000；不能把这部分默认混入只问归并的答案。

易错原因：将 5 个缓冲全用于输入，或只计算读不计算写。

检查动作：先写段数递推，再明确是否计初始段生成、最后写出；本题两项均已说明。

闭卷自测与答案

问：若有 6 块缓冲，20 个初始段要几趟？答：最多 5 路，20→4→1，两趟；仍须保留输出缓冲。
