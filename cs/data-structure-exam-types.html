一、时间复杂度分析题

题型特征

  • 选择题给出代码段，要求分析时间复杂度
  • 综合题中作为子问题出现

核心解法

1. 单层循环

for (i=1; i<=n; i=i*2)         // O(log₂n)
for (i=1; i<=n; i=i+2)         // O(n)
for (i=n; i>0; i=i/2)          // O(log₂n)

2. 嵌套循环

for (i=1; i<=n; i++)           // 外层O(n)
  for (j=1; j<=n; j++)         // 内层O(n)
    ...                         // 总体O(n²)

for (i=1; i<=n; i++)           // 外层O(n)
  for (j=1; j<=i; j++)         // 内层平均O(n/2)
    ...                         // 总体O(n²)

3. 递归时间复杂度

  • 递推公式法：T(n) = aT(n/b) + f(n)
  • 主定理/递推展开法

涉及知识点：1.2节 算法效率度量

常考真题示例

  1. 分析 while (n > (x+1)*(x+1)) x = x+1; 的时间复杂度 → O(√n)
  2. 分析 int sum=0; for(i=1; i<n; i*=2) for(j=0; j<i; j++) sum++; → O(n)
  3. 分析递归 int f(int n) { if(n<=1) return 1; return n*f(n-1); } → O(n)

二、线性表操作题

题型特征

  • 顺序表/链表的基本操作与算法设计
  • 重点考察：插入、删除、逆置、合并、查找

高频题型

1. 链表逆置（必考）

原地逆置单链表：

// 头插法逆置——摘下结点依次插到头部
p = L->next; L->next = NULL;
while (p != NULL) {
    r = p->next;          // 暂存后继
    p->next = L->next;    // 插入到L之后
    L->next = p;
    p = r;                // 继续处理下一个
}

递归逆置：

LinkList Reverse(LinkList L) {
    if (L == NULL || L->next == NULL) return L;
    LinkList newHead = Reverse(L->next);
    L->next->next = L;    // 逆转指向
    L->next = NULL;
    return newHead;
}

涉及知识点：2.3节 单链表操作

2. 删除链表中特定值的结点

递归解法：

void Del_X(LinkList &L, ElemType x) {
    if (L == NULL) return;
    if (L->data == x) {    // 当前结点要删
        LNode *p = L;
        L = L->next;
        free(p);
        Del_X(L, x);       // 继续递归
    } else {
        Del_X(L->next, x); // 递归下一个
    }
}

涉及知识点：2.3节 单链表删除操作、递归

3. 两个有序链表合并

合并为递减链表（头插法）：

void MergeList(LinkList &La, LinkList &Lb) {
    LNode *pa = La->next, *pb = Lb->next, *r;
    La->next = NULL;  // La作为结果链表（头插法）
    while (pa && pb) {
        if (pa->data <= pb->data) { r = pa->next; pa->next = La->next; La->next = pa; pa = r; }
        else { r = pb->next; pb->next = La->next; La->next = pb; pb = r; }
    }
    // 处理剩余结点
    while (pa) { r = pa->next; pa->next = La->next; La->next = pa; pa = r; }
    while (pb) { r = pb->next; pb->next = La->next; La->next = pb; pb = r; }
}

涉及知识点：2.2节 顺序表、2.3节 链表合并

4. 寻找链表倒数第k个结点

// 双指针法：p先走k步，然后p和q同步走，p到末尾时q即为所求
LNode* FindKthToTail(LinkList L, int k) {
    LNode *p = L->next, *q = L->next;
    int count = 0;
    while (p && count < k) { p = p->next; count++; }
    if (count < k) return NULL;  // k超过表长
    while (p) { p = p->next; q = q->next; }
    return q;
}

涉及知识点：2.3节 单链表、双指针技巧

5. 顺序表删除所有值为x的元素

// O(n)解法：双指针（类似快排partition）
int Del_All_X(SqList &L, ElemType x) {
    int k = 0;  // 不等于x的元素个数
    for (int i = 0; i < L.length; i++)
        if (L.data[i] != x)
            L.data[k++] = L.data[i];
    L.length = k;
    return k;
}

涉及知识点：2.2节 顺序表删除

三、栈与队列应用题

题型特征

  • 合法出栈序列判断
  • 表达式转换与求值
  • 括号匹配
  • 栈/队列的算法设计

高频题型

1. 判断合法出栈序列（经典必考）

方法：模拟入栈出栈过程

  1. 按入栈序列依次入栈
  2. 每次入栈后，如果栈顶 = 当前待匹配的出栈元素，则出栈
  3. 最终栈空且出栈序列全部匹配 → 合法

卡特兰数：n个元素可能的出栈序列数 = C(2n,n)/(n+1)

例：入栈序列 1,2,3,4
合法出栈序列：4,3,2,1  ✓（全部入栈后依次出栈）
非法出栈序列：3,1,2,4  ✗（1在2之前出栈但1比2先入栈，且中间有3）

核心结论：在出栈序列中，若a>b，且a在b之前出栈，则a和b之间出栈的元素（大于b的）必须在b之前出栈

涉及知识点：3.1节 栈的基本概念

2. 中缀→后缀表达式转换

步骤：
1. 操作数直接输出
2. 运算符：
   - 栈空或(直接入栈
   - )弹出到(为止
   - 优先级 > 栈顶 → 入栈
   - 优先级 ≤ 栈顶 → 弹栈直到 > 栈顶或栈空
3. 遍历完弹出栈中剩余运算符

涉及知识点：3.3.2节 栈在表达式求值中的应用

3. 后缀表达式求值

步骤：
1. 操作数入栈
2. 遇运算符 → 弹出两个操作数 → 计算 → 结果入栈
3. 最终栈中唯一元素即为结果

涉及知识点：3.3.2节 后缀表达式求值

4. 循环队列操作

关键公式：

  • 队长：(Q.rear - Q.front + MaxSize) % MaxSize
  • 入队：Q.rear = (Q.rear + 1) % MaxSize
  • 出队：Q.front = (Q.front + 1) % MaxSize
  • 判空：Q.front == Q.rear
  • 判满（牺牲单元法）：(Q.rear + 1) % MaxSize == Q.front

涉及知识点：3.2.2节 循环队列

5. 共享栈边界判断

模型：两个栈共享一个数组 S[0..MaxSize-1]，栈0从左向右增长，栈1从右向左增长。

  • 初始：top0 = -1, top1 = MaxSize
  • 栈满：top0 + 1 == top1
  • 栈0入栈：S[++top0] = x
  • 栈1入栈：S[--top1] = x
  • 栈0空：top0 == -1；栈1空：top1 == MaxSize

易错点：共享栈只有整体满，没有“某一个栈固定容量已满”的说法。

涉及知识点：3.1节 栈的顺序存储

6. 双栈模拟队列

方案：两个栈S1（输入栈）和S2（输出栈）

  • 入队：push到S1
  • 出队：若S2非空，S2出栈；若S2空，将S1全部倒入S2再出栈
  • 均摊时间复杂度：O(1)

涉及知识点：3.1节 栈、3.2节 队列

补充：数组与特殊矩阵压缩存储题

题型特征

  • 给定矩阵元素下标，求压缩后一维数组下标
  • 给定一维下标，反推矩阵中的行列位置
  • 稀疏矩阵三元组与快速转置过程模拟
  • 判断三元组表、十字链表适用场景

高频题型

1. 对称矩阵压缩下标计算

下三角按行优先存储（下标从1开始）：

若 i >= j:
    k = i(i-1)/2 + j
若 i < j:
    利用对称性 a[i][j] = a[j][i]，转为 k = j(j-1)/2 + i

易错点：题目若数组下标从0开始，最后要整体减1。

2. 三对角矩阵压缩存储

条件：仅当 |i-j| <= 1 时元素可能非零。

  • 1-based常用公式：k = 2*i + j - 2
  • 0-based常用公式：k = 2*i + j - 3
  • 元素个数：3n - 2

涉及知识点：3.4节 数组和特殊矩阵

3. 稀疏矩阵快速转置

  1. 统计原矩阵每一列非零元素个数 num[col]
  2. 计算转置后三元组表中每一行的起始位置 cpot[col]
  3. 扫描原三元组表，将每个元素放入转置表对应位置

复杂度：时间O(n+t)，空间O(n)，其中t为非零元素个数。

四、串的模式匹配题

题型特征

  • 给定模式串求next数组/nextval数组（必考手工题）
  • KMP算法的匹配过程
  • 对比BF与KMP的优劣

高频题型

1. 手算next数组（核心）

方法：对模式串P，next[j] = P[1..j-1]的最长相等前后缀长度 + 1

P = "abaabc"
j=1: next[1]=0 （规定）
j=2: P[1]="a"，前后缀为∅ → next[2]=1
j=3: P[1..2]="ab"，前缀{a}，后缀{b}，无相等 → next[3]=1
j=4: P[1..3]="aba"，最长相等前后缀"a"长度1 → next[4]=2
j=5: P[1..4]="abaa"，最长相等前后缀"a"长度1 → next[5]=2
j=6: P[1..5]="abaab"，最长相等前后缀"ab"长度2 → next[6]=3

结果：next[1..6] = [0, 1, 1, 2, 2, 3]

2. 手算nextval数组（优化）

方法：在next基础上，若P[j] = P[next[j]]，则nextval[j] = nextval[next[j]]

P = "abaabc"
next = [0, 1, 1, 2, 2, 3]

j=1: nextval[1]=0
j=2: P[2]='b', P[1]='a', 不等 → nextval[2]=1
j=3: P[3]='a', P[1]='a', 相等 → nextval[3]=nextval[1]=0
j=4: P[4]='a', P[2]='b', 不等 → nextval[4]=2
j=5: P[5]='b', P[2]='b', 相等 → nextval[5]=nextval[2]=1
j=6: P[6]='c', P[3]='a', 不等 → nextval[6]=3

结果：nextval = [0, 1, 0, 2, 1, 3]

涉及知识点：4.2节 KMP算法

3. KMP匹配过程模拟

给出了主串S和模式串T，按照next数组模拟匹配过程，当失配时i不动、j跳转到next[j]。

涉及知识点：4.2.2节 KMP算法原理

五、二叉树遍历与构造题

题型特征

  • 给定遍历序列，构造/还原二叉树（必考）
  • 二叉树的遍历算法设计
  • 线索二叉树的构造与遍历

高频题型

1. 由遍历序列构造二叉树（核心必考）

能唯一确定二叉树的序列组合：

  • ✅ 先序 + 中序
  • ✅ 后序 + 中序
  • ✅ 层次 + 中序
  • ❌ 先序 + 后序（不唯一，除非是满二叉树）

方法（以先序+中序为例）：

  1. 先序第一个元素是根
  2. 在中序中找到根位置，左侧为左子树中序，右侧为右子树中序
  3. 根据中序划分出的左右子树长度，在先序中分割左右子树先序
  4. 递归构造

涉及知识点：5.3.1节 由遍历序列构造二叉树

2. 二叉树的非递归遍历

中序非递归（借助栈）：

void InOrder(BiTree T) {
    InitStack(S); BiTree p = T;
    while (p || !IsEmpty(S)) {
        if (p) { Push(S, p); p = p->lchild; }  // 一路向左
        else {
            Pop(S, p); visit(p);                 // 访问根
            p = p->rchild;                       // 转向右子树
        }
    }
}

后序非递归（最复杂，需标记）：

  • 每个结点两次入栈，或使用标记flag

涉及知识点：5.3.1节 二叉树遍历

3. 线索二叉树的构造与遍历

中序线索化（递归）：

void InThread(ThreadTree &p, ThreadTree &pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);    // 线索化左子树
        if (p->lchild == NULL) {     // 建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre && pre->rchild == NULL) { // 建立后继线索
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;
        InThread(p->rchild, pre);    // 线索化右子树
    }
}

中序线索二叉树遍历（找后继）：

  • rtag=1 → rchild就是后继
  • rtag=0 → 右子树的最左下结点

涉及知识点：5.3.2节 线索二叉树

4. 树/森林与二叉树的转换

树→二叉树：左孩子右兄弟

森林→二叉树：各种树单独转二叉树后，依次作为右子树连接

关键结论：

  • 树的先根遍历 = 对应二叉树的先序遍历
  • 树的后根遍历 = 对应二叉树的中序遍历

涉及知识点：5.4节 树、森林

六、哈夫曼树/编码题

题型特征

  • 给定权值序列，构造哈夫曼树
  • 计算WPL
  • 哈夫曼编码与前缀码判断

高频题型

1. 构造哈夫曼树并计算WPL

步骤：

  1. 将n个权值看作n棵只有根结点的二叉树
  2. 选取两棵根权值最小的树作为左右子树
  3. 新树根权值 = 两子树根权值之和
  4. 重复直到只剩一棵树
例：权值 {2,3,4,7,8,9}
┌─选择2和3 → 新结点5
├─选择4和5 → 新结点9
├─选择7和8 → 新结点15
├─选择9和9 → 新结点18
└─选择15和18 → 新结点33

WPL = 2×4 + 3×4 + 4×3 + 7×2 + 8×2 + 9×2 = 8+12+12+14+16+18 = 80

涉及知识点：5.5.1节 哈夫曼树

2. 哈夫曼编码

  • 左分支标0，右分支标1
  • 哈夫曼编码是最优前缀编码
  • 不同哈夫曼树的编码可能不同，但WPL相同

涉及知识点：5.5.1节 哈夫曼编码

七、图的算法题

题型特征

  • 图的基本概念与性质判断
  • 图的遍历（BFS/DFS）
  • 最小生成树（Prim/Kruskal）
  • 最短路径（Dijkstra/Floyd）手工模拟
  • 拓扑排序与关键路径计算

高频题型

1. 图的性质判断题

常考结论：

命题真假
n个顶点的连通图至少n-1条边✓
有向完全图有n(n-1)条弧✓
图的所有顶点的度之和 = 边数的2倍✓（无向图）
连通分量是极大连通子图✓
DFS生成树的高度等于图的顶点数✗
对任意图，从某顶点出发可一次BFS/DFS访问所有顶点✗（不连通则不行）

涉及知识点：6.1节 图的基本概念

2. 图存储结构与复杂度判断

操作邻接矩阵邻接表常考结论
判断边(u,v)是否存在O(1)O(degree(u))矩阵适合频繁判边
枚举u的邻接点O(|V|)O(degree(u))邻接表适合稀疏图遍历
求无向图顶点度O(|V|)O(degree(u))邻接表直接数边表结点
求有向图入度O(|V|)O(|V|+|E|)普通邻接表求入度要扫全图
空间复杂度O(|V|²)O(|V|+|E|)稠密图选矩阵，稀疏图选邻接表

涉及知识点：6.2节 图的存储结构

3. 最小生成树手工构造（必考）

Prim算法：

  • 从任一顶点出发，每次选择当前连通部分到未连通部分的最小权边
  • 可借助表格手工模拟

Kruskal算法：

  • 按边权从小到大排序，不形成回路则加入
  • 用并查集判断回路

注意：

  • 最小生成树可能不唯一，如果所有边权不等则唯一
  • Prim适用于稠密图，Kruskal适用于稀疏图

涉及知识点：6.4.1节 最小生成树

4. 最短路径手工计算

Dijkstra算法表格法（单源最短路径）：

步骤v₁(0)v₂(∞)v₃(∞)v₄(∞)已选
初始0∞∞∞{1}
选1025∞{1}
选20247{1,2}
选30246{1,2,3}
选40246{1,2,3,4}

Floyd算法：

  • $A^{(k)}[i][j] = \min(A^{(k-1)}[i][j], A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$
  • 手工迭代更新矩阵

涉及知识点：6.4.2节 最短路径

5. 拓扑排序

算法（邻接表）：

  1. 计算所有顶点入度，入度为0的顶点入栈
  2. 栈非空：出栈输出，将该顶点所有邻接点入度-1，入度变为0则入栈
  3. 最终输出顶点数 < |V| → 存在回路

DFS逆拓扑排序：DFS退出时输出顶点

涉及知识点：6.4.4节 拓扑排序

6. 关键路径计算（AOE网）

步骤：

  1. 正向拓扑排序求 ve(k)（所有事件最早发生时间）
    • ve(源点) = 0
    • ve(k) = max{ ve(j) + weight(j,k) }
  2. 逆向拓扑排序求 vl(k)（所有事件最迟发生时间）
    • vl(汇点) = ve(汇点)
    • vl(k) = min{ vl(j) - weight(k,j) }
  3. 对每条活动：e(i) = ve(弧尾), l(i) = vl(弧头) - 持续时间
  4. e(i) = l(i) 的活动为关键活动

涉及知识点：6.4.5节 关键路径

  • B树/B+树操作

  • 红黑树性质判断

高频题型

1. 折半查找判定树与ASL

判定树：折半查找的过程构成一棵平衡二叉判定树

ASL计算：

  • 成功ASL = (1×2⁰ + 2×2¹ + 3×2² + ... + h×结点数) / n
  • 失败ASL = (各失败结点所在层数之和) / (n+1)

涉及知识点：7.2.2节 折半查找

2. 二叉排序树（BST）构造与删除

构造：依次按BST规则插入

删除三种情况：

情况处理方法
叶子结点直接删除
只有左/右孩子用孩子代替
有左右孩子用直接前驱或后继替代（中序序列中）

涉及知识点：7.3.1节 二叉排序树

3. 平衡二叉树（AVL）插入调整

旋转识别（从失衡结点向下看两步）：

情况特征操作
LL在A的左孩子(L)的左子树(L)插入A右单旋转
RR在A的右孩子(R)的右子树(R)插入A左单旋转
LR在A的左孩子(L)的右子树(R)插入先左旋后右旋
RL在A的右孩子(R)的左子树(L)插入先右旋后左旋

涉及知识点：7.3.2节 平衡二叉树

4. B树操作（必考）

插入导致分裂：

  • 结点关键字达到m时（满），中间关键字升入父结点，原结点分裂

删除导致合并：

  • 非终端结点→用前驱/后继替换后删除终端
  • 终端结点删除后不够⌈m/2⌉-1：
  • 兄弟够借→旋转借关键字
  • 兄弟不够→合并

涉及知识点：7.4.1节 B树

5. B树与B+树对比题

比较点B树B+树
关键字与子树n个关键字对应n+1棵子树n个关键字通常对应n棵子树
数据记录位置可在非叶结点和叶结点全部在叶结点，非叶结点只作索引
顺序/范围查找不天然连续叶结点链表支持范围查找
查找路径命中非叶结点即可成功通常必须查到叶结点

易错点：B+树非叶结点中的关键字是索引副本，不代表该记录只存于非叶结点。

涉及知识点：7.4.2节 B+树

6. 散列表ASL计算（核心）

给定散列函数和冲突处理方法，计算ASL：

例：H(key)=key%7，线性探测法，关键字{8,15,23,36}

关键字H(key)冲突？最终位置探测次数
81无11
151有22
232有32
361有44

查找成功ASL = (1+2+2+4)/4 = 2.25

查找失败ASL：对每个散列地址0..6，计算查找到空位所需的探测次数

涉及知识点：7.5节 散列表

7. 红黑树性质判断题

常考点：

  • 根结点是黑色 ✓
  • 红色结点不能连续 ✓
  • 黑高相等 ✓
  • 从根到叶的最长路径 ≤ 2×最短路径 ✓
  • 红黑树插入最多旋转2次 ✓
  • 红黑树删除最多旋转3次 ✓

涉及知识点：7.3.3节 红黑树

题型特征

高频题型

1. 快速排序手动模拟

涉及知识点：8.3.2节 快速排序

2. 堆排序建堆与调整

建堆（大根堆）：

  • 从 ⌊n/2⌋ 开始向前调整（向下调整/筛选）
例：数组 {4,10,3,5,1,2}
建堆过程：
从n/2=3开始：
  arr[3]=3，左右孩子2,? → 无需调整（孩子比根小）
  arr[2]=10，左右孩子5,1 → 无需调整（最大）
  arr[1]=4，左右孩子10,3 → 与10交换 → {10,4,3,5,1,2}
  再调整arr[2]=4，孩子5,1 → 与5交换 → {10,5,3,4,1,2}
结果：大根堆 {10,5,3,4,1,2}

堆排序：反复交换堆顶和末尾→调整

涉及知识点：8.4.2节 堆排序

3. 排序结果的推理性判断

示例题：已知序列经过一趟排序后的结果，判断是什么排序算法

一趟后特征可能算法
第一个/最后一个元素归位（最大/最小）直接选择排序/冒泡排序
枢轴归位，左小右大快速排序

相邻有序段归并排序

涉及知识点：8.6节 排序算法比较

4. 排序算法选择策略

场景推荐算法原因
n较小（<50）直接插入/简单选择简单且常数小
基本有序直接插入/冒泡接近O(n)
n较大快排/堆排/归并O(nlog₂n)
n很大且关键字位数少基数排序O(dn)
要求稳定归并/基数/冒泡/直接插入稳定性
空间受限堆排/快排空间O(1)/O(log₂n)
数据随机分布快排平均最优

涉及知识点：8.6.2节 排序算法应用

十、外部排序题

题型特征

  • 归并趟数/I/O次数计算
  • 败者树与最佳归并树
  • 置换-选择排序原理

高频题型

1. 外部排序总时间/I/O次数计算

  • 归并趟数 = ⌈log_k(r)⌉（r为初始归并段数，k为归并路数）
  • 总I/O次数 = 2 × 记录总数 × 归并趟数（每趟读+写）

涉及知识点：8.7.2节 外部排序方法

2. 最佳归并树（哈夫曼树思想）

  • 以段长为权值构造k叉哈夫曼树
  • 若需补虚段：设初始段数为 r，若 (r-1) % (k-1) != 0，补 d 个权值为0的虚段，使 (r+d-1) % (k-1) == 0

涉及知识点：8.7.5节 最佳归并树

3. 败者树

  • 叶子存放k个归并段的当前记录
  • 内部结点存放"失败者"（较大者）
  • 冠军（最小者）从根输出
  • 每次调整只需比较 ⌈log₂k⌉ 次

涉及知识点：8.7.3节 败者树

十一、综合算法设计题

题型特征

408大题（42题或近年的综合题）通常考察算法设计能力，要求在给定条件下设计高效算法。

经典题型

1. 寻找主元素（众数问题）

问题：找出数组中出现次数 > n/2 的元素

解法：摩尔投票法，时间O(n)，空间O(1)

int Majority(int A[], int n) {
    int candidate = A[0], count = 1;
    for (int i = 1; i < n; i++) {
        if (A[i] == candidate) count++;
        else {
            if (count > 0) count--;
            else { candidate = A[i]; count = 1; }
        }
    }
    // 验证
    count = 0;
    for (int i = 0; i < n; i++) if (A[i] == candidate) count++;
    return count > n/2 ? candidate : -1;
}

涉及知识点：线性表、数组、计数

2. 求两个有序序列的中位数

问题：两个等长有序序列，求合并后的中位数

最优解法：二分思想，时间O(log₂n)

涉及知识点：折半查找、分治

3. 链表公共结点

问题：求两个单链表的第一个公共结点

解法：先求长度差，长链表先走差值步，然后同步走找相同结点

涉及知识点：2.3节 单链表

4. 二叉树最近公共祖先

BiTree LowestCommonAncestor(BiTree root, BiTree p, BiTree q) {
    if (root == NULL || root == p || root == q) return root;
    BiTree left = LowestCommonAncestor(root->lchild, p, q);
    BiTree right = LowestCommonAncestor(root->rchild, p, q);
    if (left && right) return root;   // 分居两侧
    return left ? left : right;       // 一侧或都不在
}

涉及知识点：5.3节 二叉树遍历、递归

算法设计常用模板

模板适用题型核心套路
双指针顺序表删除、两个有序序列合并、划分区间一个指针扫描，一个指针维护结果区间
快慢指针链表中点、倒数第k个结点、判环快指针先走或每次走两步，慢指针定位答案

栈/队列辅助非递归遍历、层次遍历、括号匹配、迷宫搜索栈处理回溯，队列处理按层扩展

5. 树递归返回值设计

// 例：求二叉树高度
int Height(BiTree T) {
    if (T == NULL) return 0;
    int lh = Height(T->lchild);
    int rh = Height(T->rchild);
    return max(lh, rh) + 1;
}

写法要点：先写空树返回值，再写左右子树递归，最后合并左右结果。

6. 图遍历算法设计

void DFS(Graph G, int v) {
    visited[v] = true;
    visit(v);
    for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w]) DFS(G, w);
}

写法要点：题目若要求判断路径或连通性，通常只需在 DFS/BFS 中维护 visited[]、前驱数组或计数器。

十二、选择题高频陷阱

陷阱正确理解
"二叉树是度为2的树"❌ 二叉树可以为空，度为2的树至少3个结点
"顺序表插入的平均移动次数是n/2"❌ 插入平均移动 n/2（应为(n)/2），删除平均移动 (n-1)/2
"栈和队列都是线性结构"✓
"折半查找适用于有序链表"❌ 链表无法随机存取
"最小生成树一定唯一"❌ 边权相同时不唯一
"DFS和BFS的时间复杂度不同"❌ 相同（邻接矩阵O(|V|²)，邻接表O(|V|+|E|)）
"拓扑排序序列唯一"❌ 通常不唯一
"关键路径唯一"❌ 可能有多个
"归并排序的空间复杂度是O(1)"❌ 需要O(n)辅助空间
"基数排序是基于比较的排序"❌ 不是，基于关键字位
"快速排序在所有情况下都是最快的"❌ 最坏O(n²)，数据有序时退化
"对于有向图，从某顶点出发的DFS能遍历全部顶点"❌ 非强连通时不能
"B+树的所有关键字都出现在叶结点，非叶结点也是"❌ 非叶结点关键字是索引副本
