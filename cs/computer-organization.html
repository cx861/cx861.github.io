第1章 计算机系统概述

1.2 计算机系统层次结构

1.2.1 计算机系统的组成

  • 完整计算机系统 = 硬件（物理装置）+ 软件（程序、数据、文档）
  • 软/硬件功能边界划分原则：使用频繁且硬件实现成本低的功能 → 由硬件实现

1.2.2 计算机硬件

一、冯·诺依曼机的基本思想 ⭐（2019考点）

冯·诺依曼在研究EDVAC机时提出"存储程序"思想，五大特点：

序号特点说明
1存储程序工作方式程序和数据预先存入主存，自动连续取指执行
2五大部件运算器、控制器、存储器、输入设备、输出设备
3指令和数据同等存放以相同形式存放，仅凭内容无法区分
4二进制编码指令和数据均采用二进制表示
5指令=操作码+地址码操作码指明操作类型，地址码指出操作数地址

二、计算机的功能部件

部件组成功能
CPU（中央处理器）数据通路（ALU+通用寄存器组）+ 控制单元执行指令的核心部件
ALU（算术逻辑单元）—完成所有算术与逻辑运算
控制单元(CU)—取指、译码、生成控制信号
存储器内存（主存+Cache）+ 外存（磁盘/SSD/光盘/磁带）存放程序和数据
外部设备+I/O接口物理功能部件+设备控制器实现输入/输出操作
总线处理器总线、存储器总线、I/O总线各部件间传输信息的公共通路

三、典型多总线结构

1.2.3 计算机软件

分类定义示例
系统软件保障系统高效正确运行的基础软件操作系统(OS)、DBMS、语言处理程序、标准库
应用软件解决特定应用领域问题的程序科学计算、工程设计、信息处理软件

软/硬件逻辑功能等价性：

  • 某一特定功能既可用硬件实现，也可用软件实现
  • 在相同规范下逻辑功能等价，但硬件实现效率远高于软件
  • 例：浮点运算可用专用硬件或软件子程序模拟

1.2.6 计算机系统的工作原理

一、"存储程序"工作方式

程序执行 = 周而复始的"取指—译码—执行"循环：

根据PC取指令 → 指令译码，PC←PC+1 → 取操作数并执行 → 送结果 → 循环
  • 程序计数器(PC)：存放下一条指令地址
  • 顺序指令：PC ← PC + 指令长度
  • 跳转指令：PC ← 指令中指定的目标地址

二、从源程序到可执行文件 ⭐（2022考点）

hello.c(文本) → [预处理器cpp] → hello.i(文本) 
    → [编译器cc1] → hello.s(汇编文本)
    → [汇编器as] → hello.o(可重定位目标文件,二进制)
    → [链接器ld] → hello(可执行目标文件,二进制)
阶段输入输出处理内容
预处理hello.chello.i处理#include/#define等预处理指令
编译hello.ihello.s翻译为汇编语言
汇编hello.shello.o转换为机器语言指令
链接hello.o + 库函数hello(可执行)解析外部符号引用

1.3.1 主要性能指标

一、运算速度相关指标

指标定义公式考点年份
吞吐量单位时间内处理请求的数量—2010
响应时间用户发出请求到系统返回结果的总时间= CPU时间 + 等待时间(I/O等)2010
CPU时钟周期CPU工作的最小时间单位= 1/主频2019
主频CPU内部主时钟的频率= 1/时钟周期2013
CPI执行一条指令所需的平均时钟周期数CPI = 总时钟周期数/指令条数2023
IPS每秒执行指令数IPS = 主频/CPI2023
CPU执行时间运行一个程序所花费的时间= (指令条数×CPI)/主频2012-2023高频
MIPS每秒百万条指令= 主频/(CPI×10⁶)2012、2013
MFLOPS/GFLOPS/TFLOPS等每秒浮点运算次数—2011、2021

CPU执行时间三要素（关键公式）：

CPU执行时间 = CPU时钟周期数 / 主频 = (指令条数 × CPI) / 主频

性能优化分析：

  • 三要素（指令条数、CPI、主频）之间存在制约关系
  • CISC：指令条数少 → CPI高、主频受限
  • RISC：指令条数多 → CPI低、主频可更高

MIPS的局限性：

  • 不同机器指令集不同，指令功能强度不等
  • 不能直接用于跨架构性能比较

FLOPS系列（浮点运算指标）：

单位含义数量级
MFLOPS百万次/秒10⁶
GFLOPS十亿次/秒10⁹
TFLOPS万亿次/秒10¹²
PFLOPS千万亿次/秒10¹⁵
EFLOPS百亿亿次/秒10¹⁸
ZFLOPS十万亿亿次/秒10²¹

注意：存储容量（K=1024）vs 速率频率（k=1000），上下文判断。

二、基准程序(Benchmarks)

  • 专门用于性能评测的典型程序
  • 局限性：可能被针对性优化，评测结果失真
  • 应结合多种评测手段综合判断

1.4 本章小结 - 常见问题和易混淆知识点

问题答案要点
主频高=性能好？❌ 不一定。还取决于微架构、流水线、Cache、IPC等因素
翻译程序 vs 编译程序 vs 解释程序 vs 汇编程序翻译程序是总称；编译程序=高级语言→低级语言；解释程序=逐条翻译执行；汇编程序=汇编→机器语言
透明性计算机中=不可见/无法感知（与日常相反！）。如IR、MAR、MDR对所有程序员透明
体系结构 vs 组成体系结构=程序员可见属性（指令集等）；组成=具体硬件实现（微架构等）

第2章 数据的表示和运算

2.1 数制与编码

2.1.1 进位计数制及其相互转换

一、采用二进制的原因 ⭐（2018考点）

  1. 二进制只有两个状态，硬件实现成本低
  2. 二进制编码/计数/运算规则简单，可用逻辑门电路高效实现

二、常用进位计数制

进制基数数码特点
二进制(B)20,1计算机内部使用
八进制(O)80~73位二进制=1位八进制
十进制(D)100~9日常生活
十六进制(H)160~9, A~F4位二进制=1位十六进制

三、进制转换

转换类型方法关键规则
二→八/十六分组替换小数点分界，整数向左/小数向右分组，不足补0
任意进制→十进制按权展开相加各位数码×位权(基数幂次) 之和
十进制→任意进制基数乘除法整数：除基取余（倒序）；小数：乘基取整（正序）

关键结论 ⭐（2021、2022考点）：

  • 并非所有十进制小数都能用有限位二进制精确表示
  • 能被有限位二进制精确表示的十进制小数 ⇔ 可表示为 k/2ⁿ 形式
  • 例如：0.3 = 3/10（10含质因数5），无法精确表示为二进制

2.1.2 定点数的编码表示

一、真值和机器数

  • 真值：带正负号的数值（如+15、-8）
  • 机器数：符号被数字化的表示（0表示正、1表示负）

二、定点表示

  • 定点小数：小数点位于符号位之后、数值最高位之前
  • 定点整数：小数点位于数值最低位之后
  • 机器内部无实际小数点，仅人为约定位置

三、四种编码对比 ⭐⭐⭐

特性原码补码反码移码
正数表示符号0+绝对值与原码相同与原码相同符号1+绝对值
负数表示符号1+绝对值绝对值取反+1绝对值按位取反真值+偏置值
+0/-0有(+0和-0)唯一(全0)有(+0和-0)唯一(1,00..0)
n+1位整数范围-(2ⁿ-1)~2ⁿ-1-2ⁿ~2ⁿ-1-(2ⁿ-1)~2ⁿ-1-2ⁿ~2ⁿ-1
加减法复杂统一为加法复杂—
主要用途浮点尾数现代计算机标准中间过渡(极少用)浮点阶码

补码关键特性 ⭐（2010-2024高频）：

  • [+0]补=[-0]补=0,00...0（全0）
  • [-1]补=1,11...1（全1）
  • 最大正整数：[2ⁿ-1]补=0,11...1
  • 最小负整数：[-2ⁿ]补=1,00...0
  • 补码比原码多表示一个最小负数(-2ⁿ)

补码与真值转换（2020、2023考点）：

  • 真值→补码(负数)：符号位取1，其余位"按位取反，末位加1"
  • 补码→真值(负数)：同上法，符号位不变

变形补码（双符号位）：

  • 00表示正，11表示负
  • 左符为真正符号位，右符用于判断溢出

移码特点（用于IEEE 754浮点阶码）：

  • [x]移 = 2ⁿ + x（偏置值通常取2ⁿ）
  • 移码全0→真值最小；移码全1→真值最大
  • 保持真值大小顺序：移码越大，真值越大
  • 补码↔移码：仅符号位相反

四种编码比较大小 ⭐（2015考点）：

  • 正数：原码=反码=补码，直接比较数值位
  • 负数补码/反码比较：数值部分越小，绝对值越大（负得越多）

2.1.3 整数的表示

类型表示范围（n位）特点
无符号整数0～2ⁿ-1所有位用于表示数值
有符号整数(补码)-2ⁿ⁻¹～2ⁿ⁻¹-1现代计算机统一采用补码

补码优势：

  1. 零的表示唯一
  2. 符号位可与数值位一同参与运算
  3. 表示范围更大（多一个最小负数）

2.1.4 C语言中的整数类型及类型转换 ⭐⭐

一、常见整型类型

类型通常位宽
char8位
short16位
int32位
long32或64位

二、类型转换三种情形 ⭐（2011-2024高频考点）

转换方向操作规则风险
长→短位截断保留低位，丢弃高位可能改变数值，隐蔽性强
相同字长重新解释位模式不变，仅改变解释方式有符号↔无符号语义不同
短→长（有符号）符号扩展高位重复填充符号位无风险
短→长（无符号）零扩展高位补0无风险

符号扩展 vs 零扩展（2012、2021、2024考点）：

  • 有符号数扩展 → 符号扩展（高位补符号位）
  • 无符号数扩展 → 零扩展（高位补0）

2.2 运算方法和运算电路

2.2.1 基本运算部件

一、加法器

类型结构特点
半加器不考虑低位进位仅能处理两个1位二进制数
全加器考虑低位进位处理两个加数+进位输入
串行进位加法器n个全加器级联简单但延迟大（O(n)）
超前进位加法器(CLA)并行产生进位速度快但电路复杂
进位选择加法器分段并行折中方案

二、ALU（算术逻辑单元）

  • ALU核心功能：算术运算（加减乘除）+ 逻辑运算（与或非移位）
  • ALU是数据通路的核心部件，输出结果和标志位（ZF/OF/CF/SF等）

2.2.2 补码加减运算

一、补码加法

[x+y]补 = [x]补 + [y]补  (mod 2^(n+1))

二、补码减法

[x-y]补 = [x]补 + [-y]补

其中[-y]补 = 将[y]补连同符号位一起取反，末位加1

三、溢出判断 ⭐

判断方法判断条件
单符号位法加数与被加数符号相同，但结果符号不同 → 溢出
双符号位法（变形补码）双符号位结果：01→正溢出，10→负溢出
进位法符号位进位Cin ≠ 最高数值位进位Cout → 溢出

四、标志位

标志位含义生成条件
ZF（零标志）结果为0结果全0
SF（符号标志）结果为负结果最高位=1
OF（溢出标志）带符号数溢出双符号位异或
CF（进位/借位标志）无符号数溢出最高位产生进位或借位

2.3 浮点数的表示与运算

2.3.1 IEEE 754标准浮点数 ⭐⭐⭐

一、浮点数格式

格式符号位阶码位数尾数位数总位数偏置值
单精度(float)182332127
双精度(double)11152641023
  • 浮点数真值 = (-1)^S × 1.M × 2^(E-Bias)
  • 阶码E用移码表示，便于浮点数比较
  • 尾数M用原码表示，隐藏最高位1（规格化数隐含"1."）

二、规格化数

类型阶码尾数
规格化数1~254(单精度)任意
非规格化数0非0
特殊值全1(255)用于表示±∞和NaN

三、IEEE 754特殊值

数值阶码尾数
+0全0全0
-0全0全0（符号位=1）
+∞全1全0
-∞全1全0（符号位=1）
NaN全1非0

2.3.2 浮点数的加减运算

步骤：

  1. 对阶：小阶向大阶看齐，尾数右移
  2. 尾数求和：按定点加减法运算
  3. 规格化：左规（尾数左移）或右规（尾数右移）
  4. 舍入处理：0舍1入、恒置1等
  5. 溢出判断：阶码是否上溢/下溢

常见舍入方法：

方法规则
0舍1入多余位最高位为1则进1
恒置1法无论多余位，末位恒置为1
截断法直接丢弃多余位

2.3.3 C语言中的浮点数类型

类型IEEE 754对应位数有效数字
float单精度32位约6-7位十进制
double双精度64位约15-16位十进制

float/double → int 转换规则：

  • 截断小数部分，仅保留整数部分
  • 可能溢出（浮点数范围远超整数）

第3章 存储系统

3.1 存储器概述

3.1.1 存储器的分类

分类依据类型特点
按存储介质半导体存储器、磁表面存储器、光存储器—
按存取方式RAM（随机存取）、SAM（顺序存取）、DAM（直接存取）—
按信息可保存性易失性（RAM）、非易失性（ROM/Flash/磁盘）—
按在系统中的作用主存、辅存、Cache、控制存储器—

3.1.2 存储器的层次结构

    CPU寄存器  ← 最快、最小、最贵
       ↓
    Cache(SRAM)  ← 高速缓存
       ↓
    主存(DRAM)   ← 内存
       ↓
    磁盘/SSD     ← 外存（辅存）
       ↓
    光盘/磁带    ← 海量备份

层次结构的设计基础：程序的局部性原理

  • 时间局部性：最近访问的信息很可能再次被访问
  • 空间局部性：被访问信息附近的信息很可能被访问

3.2 主存储器

3.2.1 SRAM与DRAM ⭐

特性SRAM（静态RAM）DRAM（动态RAM）

DRAM刷新（2015考点）：

  • 刷新原因：电容漏电
  • 刷新周期：一般为2ms、4ms或64ms
  • 刷新方式：集中刷新、分散刷新、异步刷新
  • 刷新按行进行，读出行数据再写回

3.2.2 ROM（只读存储器）

类型特点可编程性

3.2.3 主存与CPU的连接

一、主存容量扩展

扩展方式连接方法容量变化
字扩展增加地址线，片选信号选择芯片扩大存储单元数量
位扩展数据线并联，各存储芯片同时工作增加每个单元的位数

二、存储器地址分配

  • 片选信号(CS)选择存储芯片
  • 地址线分高位地址（用于片选译码）和低位地址（芯片内部寻址）

3.2.4 多模块存储器 ⭐

一、单体多字存储器

  • 一个存储体，但每次可并行读出多个存储字

二、多体并行存储器 ⭐

编址方式地址分配规则特点
高位交叉编址（顺序）高log₂m位选体，低位体内地址一个体连续，顺序访问无冲突
低位交叉编址（交叉）低log₂m位选体，高位体内地址连续地址分布在不同体，可实现流水线并行访问

低位交叉编址的流水线访问：

  • 连续地址访问时，各模块轮流工作
  • 可在一个存取周期内启动多次总线传输
  • 提升存储器带宽

3.3 主存与Cache的映射 ⭐⭐⭐

3.3.1 Cache的基本工作原理

一、Cache命中过程

  • CPU给出主存地址 → 判断数据是否在Cache中
  • 命中(Hit)：直接从Cache读取
  • 缺失(Miss)：从主存读取块并加载到Cache

二、Cache性能指标

指标定义公式
命中率HCPU访存命中Cache的概率H = 命中次数/总访问次数
平均访问时间Tₐ考虑命中和缺失的平均时间Tₐ = H×T꜀ + (1-H)×Tₘ
Cache-主存系统效率—e = T꜀/Tₐ

3.3.2 Cache地址映射方式 ⭐⭐⭐

一、三种映射方式对比

特性直接映射全相联映射组相联映射
映射规则主存块只能映射到固定Cache行主存块可映射到任意Cache行主存块可映射到固定组内任意行
主存地址划分标记+行号+块内地址标记+块内地址标记+组号+块内地址
比较电路简单（1路比较）复杂（全路同时比较）折中（组内全相联比较）
命中率较低（冲突多）最高较高
实现复杂度最简单最复杂适中
典型应用大容量Cache小容量TLB当前主流Cache

二、地址映射计算

直接映射：

Cache行号 = (主存块号) mod (Cache总行数)
主存地址 = {标记(tag), Cache行号(index), 块内地址(offset)}

组相联映射（n路组相联）：

Cache组号 = (主存块号) mod (Cache组数)
每组有 n 行（即n路），组内全相联

3.3.3 Cache替换算法

算法规则实现难度命中率
随机算法(RAND)随机选择替换块最简单较低
先进先出(FIFO)替换最早装入的块较简单较低
近期最少使用(LRU)替换最久未使用的块较复杂（需计数）较高
最不经常使用(LFU)替换访问次数最少的块复杂较高
随机+LRU近似如时钟算法等折中较好

3.3.4 Cache写策略 ⭐

一、写命中策略

策略操作优点缺点
写直达(Write Through)同时写入Cache和主存数据一致性好，简单写操作慢，总线流量大
写回(Write Back)仅写入Cache，替换时写回主存写操作快，总线流量小数据一致性问题，需脏位

二、写缺失策略（写不命中）

策略操作说明
写分配(Write Allocate)先将块从主存加载到Cache，再写入通常配合写回法
非写分配(No-Write Allocate)直接写入主存，不加载到Cache通常配合写直达法

3.4 虚拟存储器 ⭐⭐

3.4.1 虚拟存储器的基本概念

  • 虚拟存储器：将主存和辅存统一编址，形成逻辑上统一的地址空间
  • 虚拟地址(逻辑地址) → 物理地址 的转换
  • 页/段是虚拟存储器的基本单位

3.4.2 页式虚拟存储器

一、基本概念

概念说明
页(Page)虚拟地址空间等分成的固定大小块
页框(Page Frame)主存空间等分成的与页大小相同的块
页表记录虚拟页→物理页框映射关系的表
页表项包含物理页框号、有效位、访问位、脏位等

二、地址转换：

虚拟地址 = {虚页号, 页内偏移}
物理地址 = {物理页框号, 页内偏移}

三、快表(TLB) ⭐（2016-2021高频考点）

概念说明
TLB(快表)页表项的Cache，由高速SRAM实现
慢表(Page)主存中的完整页表
TLB工作原理与Cache类似，采用全相联或组相联映射
TLB表项虚页号(tag) + 物理页框号 + 控制位(有效位、脏位等)

CPU访存的三种缺失 ⭐（2010考点）：

缺失类型说明关系
TLB缺失虚页号不在TLB中—
Cache缺失主存块不在Cache中—
Page缺失(缺页)页面不在主存中缺页→TLB必缺失，Cache也必缺失

3.4.3 段式虚拟存储器

  • 按程序的逻辑结构（代码段、数据段等）划分
  • 段表记录：段号→段基址、段长、访问权限等
  • 优点：便于共享和保护
  • 缺点：段长不等，内存碎片问题

3.4.4 段页式虚拟存储器

  • 结合段式和页式：程序按逻辑分段，每段再分页
  • 地址转换：段号→段表→页表起始地址→页号→物理地址
  • 兼具段式的逻辑清晰和页式的内存利用高效

4.2.1 数据寻址方式

寻址方式有效地址EA操作数特点访存次数

第5章 中央处理器

5.1 CPU的功能和基本结构

5.1.1 CPU的功能

功能说明
指令控制控制指令执行顺序（取指→译码→执行）
操作控制产生控制信号，驱动各部件协同工作
时间控制通过时钟信号协调各操作时序
数据加工通过ALU对数据进行算术和逻辑运算
中断处理检测并响应异常和中断请求

5.1.2 CPU的基本结构

CPU = 数据通路 + 控制单元

数据通路组成：

  • ALU（算术逻辑单元）
  • 通用寄存器组（GPRs）
  • 多路选择器、内部总线

控制单元组成：

  • 程序计数器(PC)
  • 指令寄存器(IR)
  • 指令译码器(ID)
  • 控制信号生成部件(CU)

5.1.3 CPU中的寄存器 ⭐

分类包含寄存器说明
用户可见寄存器通用寄存器组(GPRs)、PC、PSW/FLAGS程序可直接访问
用户不可见寄存器IR、MAR、MDR、指令译码器、微指令寄存器内部使用，程序不可直接访问
程序员可读不可写条件码/标志寄存器中的状态位反映运算结果状态

关键寄存器功能：

寄存器全称功能
PC程序计数器存放下条指令地址
IR指令寄存器存放当前执行的指令
MAR存储器地址寄存器存放访存地址
MDR存储器数据寄存器存放访存数据
PSW/FLAGS程序状态字存放标志位（ZF/OF/CF/SF等）
SP堆栈指针指向栈顶
ACC累加器暂存ALU运算结果

5.2 指令执行过程

5.2.1 指令执行的一般流程

经典三步循环：取指 → 译码 → 执行

完整流程：

  1. 取指(IF)：PC→MAR→主存→MDR→IR
  2. 译码(ID)：IR→指令译码器→控制信号
  3. 取操作数(OF)：根据寻址方式获取操作数
  4. 执行(EX)：ALU运算或访存操作
  5. 写回(WB)：结果写入寄存器或存储器

PC更新规则：

  • 顺序执行：PC ← PC + 指令长度
  • 转移指令：PC ← 转移目标地址

5.2.2 指令执行中的数据通路

基本数据通路结构：

  • 单总线结构：所有部件共享一条内部总线，结构简单但速度慢
  • 双总线结构：两条内部总线，可并行传输
  • 三总线结构：三条内部总线，速度最快但成本最高

5.3 控制器的功能和工作原理 ⭐⭐

5.3.1 硬布线控制器（组合逻辑控制器）

特性说明
实现方式由组合逻辑电路（门电路）直接生成控制信号
输入指令操作码（来自IR）、时序信号、状态标志
输出各功能部件的控制信号
优点速度快，适合RISC
缺点设计复杂，不易修改/扩展

5.3.2 微程序控制器 ⭐

一、基本概念

概念说明
微命令控制部件完成一个基本操作的控制信号
微操作由微命令控制完成的基本操作
微指令一组微命令的组合，完成一步操作
微程序实现一条机器指令的微指令序列
控制存储器(CM)存放微程序的存储器（通常为ROM）

二、微程序控制器的结构

IR(操作码) → 微地址形成部件 → CM(控制存储器) → 微指令寄存器 → 译码 → 控制信号
  • 每条机器指令对应一段微程序
  • 取指周期的微程序通常是公共的

三、微指令格式

格式特点
水平型微指令一条微指令可并行控制多个微操作，速度快，位宽大

四、微地址形成方式

方式规则

5.4 异常和中断机制 ⭐⭐

5.4.1 基本概念

概念说明
异常(内中断)CPU内部产生（如除0、溢出、缺页、非法指令）
中断(外中断)来自CPU外部（如I/O设备请求、时钟中断）

5.4.2 异常和中断的分类

分类类型示例
故障(Fault)可恢复的异常缺页异常
陷阱(Trap)有意设置的异常系统调用(INT 80H)
终止(Abort)不可恢复的异常硬件故障

  2. 保存断点（PC/PSW）
  3. 识别中断源，获取中断向量
  4. 转入中断服务程序
  5. 恢复现场，开中断，返回断点

5.5 指令流水线 ⭐⭐⭐

5.5.1 指令流水线的基本概念

五段流水线示例：

IF(取指) → ID(译码) → EX(执行) → MEM(访存) → WB(写回)

流水线性能指标：

指标定义公式
吞吐率(TP)单位时间完成的任务数TP = n/Tₖ
加速比(S)非流水与流水的时间比S = T非流水/T流水
效率(E)流水线设备的利用率E = n/(k+n-1)

其中 n=指令数，k=流水段数

5.5.2 流水线的三类冒险(冲突) ⭐⭐⭐

一、结构冒险（资源冲突）

多个指令同时争用同一硬件资源。如：取指和访存同时访问存储器。

解决方法：

  • 指令Cache和数据Cache分离（哈佛结构）
  • 增加硬件资源（如增加ALU数量）

二、数据冒险（数据相关） ⭐⭐⭐

后续指令需要使用前面指令的结果，但结果尚未产生。

类型说明解决方式
RAW(写后读)前条写，后条读同一寄存器转发/旁路(Forwarding)
WAR(读后写)前条读，后条写同一寄存器寄存器重命名
WAW(写后写)前后条写同一寄存器寄存器重命名

数据冒险解决方法：

  1. 转发/旁路(Forwarding/Bypassing)：将ALU结果直接前递到后续指令的输入端
  2. 阻塞/停顿(Stall/Bubble)：插入气泡（NOP）等待数据就绪
  3. 编译器调度：重排指令顺序避免冲突

三、控制冒险（控制相关）

转移指令导致流水线中后续指令的PC值不确定。

解决方法：

  1. 阻塞：等待转移结果确定
  2. 静态分支预测：编译时确定预测方向
  3. 动态分支预测：运行时根据历史信息预测（如BTB、BHT）
  4. 延迟分支：在转移指令后安排一条必定执行的指令

5.5.3 超标量和动态流水线

概念说明
超标量(Superscalar)每个时钟周期可发射多条指令，有多个功能部件并行
超流水线进一步细分流水段，提高时钟频率

方式特点优点缺点

独立编址（I/O映射I/O）I/O端口独立编址，需专用I/O指令不占用存储空间，地址译码简单指令功能弱

7.2 I/O控制方式 ⭐⭐⭐

7.2.1 四种I/O控制方式对比

方式CPU参与度数据传送单位适用场景优缺点
程序查询CPU全程参与字/字节低速设备简单但CPU利用率极低
程序中断CPU响应中断时参与字/字节中低速设备提高CPU利用率，但仍需CPU干预每次传送
DMACPU仅在启动/结束时参与块(Block)高速块设备（磁盘）CPU利用率高，需DMA控制器
通道(IOP)通道处理器管理I/O块/多块大型机系统功能最强的I/O方式

7.2.2 程序查询方式

  • CPU循环检测I/O设备状态寄存器
  • 设备就绪→传送数据；未就绪→继续查询
  • 缺点：CPU和I/O串行工作，"踏步等待"严重浪费CPU

7.2.3 程序中断方式 ⭐

一、中断的基本概念

概念说明
中断源引起中断的事件或设备
中断请求中断源向CPU发出的请求信号
中断响应CPU暂停当前程序，转向中断服务
中断服务程序处理中断事件的程序
中断返回中断处理完毕后返回原程序

二、中断判优（优先级）

方式说明
软件查询CPU按优先级顺序查询各中断源
硬件链式优先权菊花链，位置越近CPU优先级越高
中断控制器如8259A集中管理多个中断请求

三、多重中断与中断嵌套

  • 高优先级中断可打断低优先级中断的处理
  • 需要开中断/关中断指令配合

四、中断向量与向量中断 ⭐

概念说明
中断类型号标识中断源的编号
中断向量中断服务程序的入口地址
中断向量表存放所有中断向量的表格
向量地址中断向量在表中的位置 = 中断类型号 × 表项长度
向量中断自动识别中断源并快速转移至对应服务程序的方式

7.2.4 DMA方式 ⭐⭐

一、DMA方式的特点

特性说明
主存和设备之间直接传送不经CPU中转
CPU仅在开始和结束时干预传送过程由DMA控制器管理
块传送一次传送一批数据
总线使用权DMA传送时，DMA控制器接管总线

二、DMA控制器组成

部件功能
主存地址寄存器(MAR)存放传送数据的主存地址
字计数器(WC)记录剩余传送字数
控制/状态寄存器(CSR)存放控制命令和设备状态
数据缓冲寄存器(DR)暂存传送的数据

三、DMA传送过程

  1. CPU初始化DMA控制器（传送方向、主存首地址、字数）
  2. I/O设备请求DMA传送
  3. DMA控制器向CPU请求总线（HRQ）
  4. CPU响应，让出总线（HLDA）
  5. DMA控制器接管总线，执行数据传送
  6. 传送完毕，DMA控制器向CPU发中断

四、DMA与CPU访问主存的冲突解决

方式说明
暂停CPU访存（周期窃取/挪用）DMA传送时CPU暂停访存，简单但影响CPU
周期窃取（挪用）CPU不访存时DMA趁机传送
交替访存CPU和DMA分时交替使用总线

五、DMA与程序中断的区别

区别DMA程序中断
传送单位数据块单字/字节
CPU干预仅开始和结束时每次数据传送
适用速度高速设备低速设备
对CPU影响CPU可继续执行被打断执行中断服务
