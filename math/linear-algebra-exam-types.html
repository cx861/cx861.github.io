第一章 行列式 —— 常考题型

题型1：行列式概念与性质题

难度：★★☆☆☆ | 题型：选择题/填空题

涉及知识点：

  • n阶行列式的定义（不同行不同列）
  • 排列与逆序数
  • 行列式的7条性质

典型考法：

  1. 判断行列式中某项的符号（利用逆序数）
  2. 利用性质判断行列式的值（如某两行相同→值为0）
  3. 给出含0较多的行列式，利用定义直接写出值

解法：

解法1：逆序数法 —— 对于n阶行列式的项 a1j1·a2j2·...·anjn，
       符号 = (-1)^τ(j1j2...jn)，先确定列标排列，计算逆序数

解法2：性质法 —— 观察行列式特征：
       · 两行相同 → 值为0
       · 两行成比例 → 值为0
       · 某行全为0 → 值为0
       · 上三角 → 对角线元素乘积

例题：求四阶行列式中含有因子 a23 且带负号的项。

解析：设该项为 a1j1·a23·a3j3·a4j4，(j1,j3,j4) 是 (1,2,4) 的排列。枚举6种排列，计算逆序数。如 τ(124) = 0（偶排列），τ(142) = 1（奇排列），τ(214) = 1（奇排列），τ(241) = 2（偶排列），τ(412) = 2（偶排列），τ(421) = 3（奇排列）。带负号需奇排列(1,1,3个逆序)，即 τ = 1 or 3。答案为 a12·a23·a31·a44 和 a14·a23·a32·a41。

题型2：数字型行列式计算

难度：★★★☆☆ | 题型：填空题/解答题

涉及知识点：

  • 行列式性质（倍加变换）
  • 按行（列）展开定理
  • 上/下三角行列式
  • 范德蒙行列式

典型考法：直接计算给定的3~5阶行列式

解法框架：

步骤1：观察 —— 行列式是否具有特殊结构（对称、各行和相等、范德蒙等）
步骤2：化简 —— 利用倍加变换（性质5）将某行（列）化为含较多0的形式
步骤3：展开/三角化 —— 
        · 若某行含较多0：按该行展开（降阶法）
        · 否则：继续倍加变换，化为上三角
步骤4：计算 —— 三角行列式 = 对角线元素乘积

核心技巧：

  • 各行（列）和相等：将所有列加到第一列，提取公因子
  • 爪型行列式：从第二行起，每行减去第一行
  • 三对角行列式：建立递推关系 $D_n = aD_{n-1} + bD_{n-2}$
方法适用条件操作要点
各行和相等每行元素之和相同各列加到第1列→提公因子→化三角
加边法不易直接化简添加一行 $(1,0,\cdots,0)$，添加一列 $(1,a,\cdots,a)^T$
递推法有递推结构的行列式建立 $D_n$ 与 $D_{n-1}, D_{n-2}$ 的关系
数学归纳法范德蒙等先猜公式再证明

题型3：含参数行列式计算

难度：★★★☆☆ | 题型：解答题

涉及知识点：

  • 行列式展开
  • 因式分解
  • 特征多项式形式

典型考法：

  1. 计算含参数 λ 的行列式 $|\lambda E - A|$
  2. 因式分解求行列式的零点

解法：

步骤1：写出 $|\lambda E - A|$
步骤2：利用行列式性质化简（不必严格三角化，可保留参数）
步骤3：利用行列式展开求特征多项式 $f(\lambda) = |\lambda E - A|$
步骤4：因式分解得各特征值

题型4：抽象行列式计算

难度：★★★★☆ | 题型：填空题/选择题/解答题

涉及知识点：

  • 矩阵运算与行列式的关系
  • 伴随矩阵性质 $|A^*| = |A|^{n-1}$
  • $|AB| = |A||B|$
  • $|kA| = k^n|A|$
  • $|A^{-1}| = 1/|A|$

典型考法：已知 $|A|$ 的值，求 $|A^*|, |A^{-1}|, |3A^T|, |A^*B|$ 等表达式的值。

核心公式速查：

表达式结果条件
$|A^T|$$|A|$恒成立
$|kA|$$k^n|A|$A为n阶方阵
$|A^{-1}|$$1/|A|$A可逆
$|A^*|$$|A|^{n-1}$A为n阶方阵(n≥2)
$|AB|$$|A|\cdot|B|$A和B为同阶方阵
$|A+B|$≠ $|A|+|B|$一般不相等！

易错警示：

  • $|A+B| \neq |A| + |B|$（常见陷阱）
  • $|kA| = k^n|A|$，不要漏了幂次n
  • $|A| = 0 \iff A$ 不可逆 $\iff r(A) < n \iff Ax = 0$ 有非零解

题型5：克拉默法则应用

难度：★★★☆☆ | 题型：解答题

涉及知识点：

  • 克拉默法则的使用条件（系数矩阵为方阵且 $|A| \neq 0$）
  • 齐次方程组有非零解条件（$|A| = 0$）

典型考法：

  1. 利用克拉默法则解方程组（n较小的情况）
  2. 判断齐次方程组何时有非零解
  3. 利用克拉默法则的几何应用（如求直线方程）

解法：

非齐次情况($|A| \neq 0$, n个方程n个未知量)：
  x_i = |A_i| / |A|，其中|A_i|是将第i列替换为常数项列

齐次情况：
  有非零解 ⇔ |A| = 0 ⇔ r(A) < n
  仅有零解 ⇔ |A| ≠ 0 ⇔ r(A) = n

第二章 矩阵 —— 常考题型

题型6：矩阵基本运算

难度：★★☆☆☆ | 题型：选择题/填空题

涉及知识点：

  • 矩阵乘法（不满足交换律！）
  • 矩阵转置 $(AB)^T = B^T A^T$
  • 方阵的幂
  • 对称矩阵与反对称矩阵

典型考法：

  1. 计算 $A^n$（对角阵或特殊矩阵）
  2. 判断矩阵运算的正确性（如 $(A+B)^2 = A^2 + AB + BA + B^2 \neq A^2 + 2AB + B^2$）
  3. 矩阵乘法的维度匹配问题

重点公式：

  • 对角阵的幂：$\Lambda^n = \text{diag}(\lambda_1^n, \lambda_2^n, \cdots, \lambda_n^n)$
  • $(A \pm B)^2 = A^2 \pm AB \pm BA + B^2$（一般不简化）
  • $(A + B)(A - B) = A^2 - AB + BA - B^2$
  • 只有当 $AB = BA$ 时，$(A+B)^2 = A^2 + 2AB + B^2$ 成立

题型7：求逆矩阵

难度：★★★☆☆ | 题型：填空题/解答题

涉及知识点：

  • 可逆的充要条件
  • 伴随矩阵法求逆
  • 初等变换法求逆
  • 分块矩阵求逆

典型考法：

  1. 给定具体矩阵，求其逆矩阵
  2. 利用伴随矩阵求逆（二阶矩阵特别简单）
  3. 分块对角阵的逆

解法对比：

方法适用场景公式/步骤
伴随矩阵法2阶或3阶$A^{-1} = \frac{1}{|A|}A^*$；二阶：$\begin{pmatrix} a & b \\ c & d \end{pmatrix}^{-1} = \frac{1}{ad-bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$
初等变换法一般情况$(A \mid E) \xrightarrow{\text{行变换}} (E \mid A^{-1})$
分块对角法分块对角阵$A^{-1} = \text{diag}(A_1^{-1}, A_2^{-1}, \cdots)$
定义法抽象矩阵找B使 $AB = BA = E$

二阶矩阵求逆（必背）：

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \quad A^{-1} = \frac{1}{ad-bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$$

题型8：伴随矩阵相关

难度：★★★☆☆ | 题型：选择/填空/解答

涉及知识点：

  • 伴随矩阵定义（代数余子式转置）
  • $AA^* = A^*A = |A|E$
  • $A^*$ 与 $A^{-1}$ 的关系

典型考法：

  1. 已知 $|A|$ 和n，求 $|A^*|$ 或 $(A^*)^*$
  2. 判断 $A^*$ 的可逆性
  3. 利用伴随矩阵求逆或解矩阵方程

核心公式：

  • $A^* = |A|A^{-1}$（A可逆）
  • $|A^*| = |A|^{n-1}$
  • $(A^*)^* = |A|^{n-2}A$（$n \geq 3$）
  • $(kA)^* = k^{n-1}A^*$
  • $(AB)^* = B^*A^*$

题型9：初等变换与初等矩阵

难度：★★★☆☆ | 题型：选择题/填空题

涉及知识点：

  • 三种初等变换及对应的初等矩阵
  • 左乘→行变换；右乘→列变换
  • 初等变换不改变矩阵的秩

典型考法：

  1. 已知初等变换过程，写出对应的初等矩阵乘积
  2. 利用初等变换化简矩阵
  3. 用初等变换法求逆矩阵

核心记忆：

初等矩阵与变换对应关系（左乘）：
  E(i,j)  →  互换i,j两行
  E(i(k)) →  第i行乘以k
  E(i,j(k)) → 第j行的k倍加到第i行

初等矩阵的逆：
  E(i,j)^{-1} = E(i,j)
  E(i(k))^{-1} = E(i, 1/k)
  E(i,j(k))^{-1} = E(i,j(-k))

题型10：求矩阵的秩

难度：★★★☆☆ | 题型：填空题/解答题

涉及知识点：

  • 秩的定义（非零子式最高阶数）
  • 初等变换不改变秩
  • 秩的性质与不等式

典型考法：

  1. 给定具体矩阵，求其秩
  2. 含参数矩阵，讨论参数取何值时秩为多少
  3. 利用秩的性质判断命题正确性

求解步骤：

步骤1：利用初等行变换将矩阵化为行阶梯形
步骤2：数非零行的行数，即为秩
步骤3：含参数时，需对参数分类讨论

秩的不等式（常考点）：

  • $r(A_{m \times n}) \leq \min(m, n)$
  • $r(AB) \leq \min(r(A), r(B))$
  • $r(A + B) \leq r(A) + r(B)$
  • 若A可逆，则 $r(AB) = r(B)$
  • $r(A) + r(B) - n \leq r(AB)$（Sylvester）

题型11：解矩阵方程

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 矩阵方程的化简
  • 逆矩阵的求解
  • 矩阵乘法顺序

典型考法：

  1. 解 $AX = B$ 型方程
  2. 解 $XA = B$ 型方程
  3. 解 $AXB = C$ 型方程

解法框架：

类型1：AX = B
  → 若A可逆，则 X = A^{-1}B
  → 可以用 (A ∣ B) 行变换→ (E ∣ X)

类型2：XA = B
  → 若A可逆，则 X = BA^{-1}
  → 对 (A^T ∣ B^T) 做行变换

类型3：AXB = C
  → X = A^{-1}CB^{-1}（A和B都可逆时）

关键注意点：
  · 先判断系数矩阵是否可逆（计算行列式）
  · 左乘逆矩阵与右乘逆矩阵的方向不同！
  · 矩阵乘法不满足交换律，不能随意挪位置

题型12：分块矩阵运算

难度：★★★☆☆ | 题型：填空题/选择题

涉及知识点：

  • 分块矩阵的乘法
  • 分块对角阵
  • 分块矩阵的行列式

核心公式：

  • $\begin{vmatrix} A & O \\ O & B \end{vmatrix} = |A|\cdot|B|$
  • $\begin{vmatrix} A & C \\ O & B \end{vmatrix} = |A|\cdot|B|$
  • $\begin{vmatrix} O & A \\ B & O \end{vmatrix} = (-1)^{mn}|A|\cdot|B|$

第三章 向量 —— 常考题型

题型13：线性相关性判定

难度：★★★★☆ | 题型：选择题/解答题/证明题

涉及知识点：

  • 线性相关与线性无关的定义
  • 向量组秩与线性相关性的关系
  • 用矩阵秩判定线性相关性

判定方法汇总：

方法判定条件
定义法设 $k_1\alpha_1 + \cdots + k_m\alpha_m = 0$，判断是否只有零解
秩法以向量为列构成矩阵A，若 $r(A) = m$ 则无关，$r(A) < m$ 则相关
行列式法(方阵)若 $m = n$，$|A| \neq 0$ 则无关，$|A| = 0$ 则相关
维数法m > n（向量个数 > 维数）→ 必相关

典型考法：

  1. 判断具体向量组是否线性相关
  2. 已知部分向量无关，讨论添加向量后的相关性
  3. 用向量组间线性表示关系判定相关性

重要定理（选择题高频）：

  • 若 $\alpha_1,\cdots,\alpha_r$ 线性无关，且可由 $\beta_1,\cdots,\beta_s$ 表示，则 $r \leq s$
  • 若向量组(I)可由向量组(II)表示且 $r(I) > r(II)$，则(I)一定线性相关
  • m个n维向量当 $m > n$ 时必线性相关

题型14：求极大线性无关组

难度：★★★☆☆ | 题型：解答题

涉及知识点：

  • 极大线性无关组的定义
  • 用初等行变换求极大无关组
  • 其余向量用无关组线性表示

解法步骤：

步骤1：以向量为列构成矩阵A
步骤2：对A进行初等行变换，化为行阶梯形或行最简形
步骤3：主元所在的列对应的原向量即为极大线性无关组
步骤4：若有要求，将其他向量用极大无关组线性表示（利用行最简形的系数）

题型15：向量组的秩

难度：★★★☆☆ | 题型：填空题/解答题

涉及知识点：

  • 向量组的秩 = 矩阵的秩
  • 等价的充要条件
  • 三秩相等

典型考法：

  1. 求向量组的秩
  2. 判断两向量组是否等价
  3. 已知向量组秩，求参数

向量组等价判定：

$$\alpha_1,\cdots,\alpha_m \text{ 与 } \beta_1,\cdots,\beta_s \text{ 等价} \iff r(\alpha_1,\cdots,\alpha_m) = r(\beta_1,\cdots,\beta_s) = r(\alpha_1,\cdots,\alpha_m, \beta_1,\cdots,\beta_s)$$

三秩相等定理（核心！）：

$$r(A) = \text{行秩} = \text{列秩}$$

题型16：线性表示问题

难度：★★★☆☆ | 题型：解答题

涉及知识点：

  • 线性组合与线性表示的定义
  • 用方程组求解线性表示系数

典型考法：

  1. 判断 $\beta$ 能否由 $\alpha_1,\cdots,\alpha_m$ 线性表示
  2. 若可以，求出表示系数
  3. 表示法是否唯一

解法：

判定：$\beta$ 可由 $\alpha_1,\cdots,\alpha_m$ 表示
  ⇔ 方程组 x1α1 + ··· + xmαm = β 有解
  ⇔ r(α1,...,αm) = r(α1,...,αm, β)

唯一表示 ⇔ 有解且 r = m（α_i 线性无关时表示法唯一）
无穷表示 ⇔ 有解且 r < m

题型17：施密特正交化与正交矩阵

难度：★★★☆☆ | 题型：解答题

涉及知识点：

  • 施密特正交化公式
  • 标准正交基
  • 正交矩阵的定义和判定

施密特正交化步骤（必熟练）：

输入：线性无关组 α1, α2, α3
过程：
  β1 = α1
  β2 = α2 - [(α2,β1)/(β1,β1)]·β1
  β3 = α3 - [(α3,β1)/(β1,β1)]·β1 - [(α3,β2)/(β2,β2)]·β2
单位化：
  e1 = β1/||β1||, e2 = β2/||β2||, e3 = β3/||β3||
输出：标准正交基 {e1, e2, e3}

正交矩阵判定：A是正交矩阵 ⇔ $A^TA = E$ ⇔ A的列向量组是标准正交向量组 ⇔ $A^{-1} = A^T$

第四章 线性方程组 —— 常考题型

题型18：解的判定

难度：★★★☆☆ | 题型：选择题/解答题

涉及知识点：

  • 有解条件（系数矩阵秩 = 增广矩阵秩）
  • 唯一解/无穷解/无解的判定

判定流程图：

          ┌── r(A) = r(A,b) = n → 唯一解
Ax = b ──┤ ┌── r(A) = r(A,b) < n → 无穷多解
          └─┤
            └── r(A) < r(A,b) → 无解

齐次方程组：

Ax = 0 ──┬── r(A) = n → 仅有零解
          └── r(A) < n → 有非零解（无穷多解）

含参数方程组的讨论：

步骤1：列出增广矩阵 (A ∣ b)
步骤2：行变换化为行阶梯形
步骤3：根据参数取值分类讨论r(A)和r(A,b)的关系
步骤4：对每种情况给出解的情况

题型19：求基础解系与通解

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 基础解系的概念
  • 齐次方程组通解
  • 非齐次方程组通解结构

齐次方程组求基础解系：

步骤1：对A进行行变换，化为行最简形
步骤2：确定自由未知量（共 n-r 个）
步骤3：依次令自由未知量为：
  (1,0,...,0)^T, (0,1,...,0)^T, ..., (0,...,0,1)^T
  解出对应的基础解系 ξ1, ξ2, ..., ξ_{n-r}
步骤4：通解为 x = k1·ξ1 + k2·ξ2 + ... + k_{n-r}·ξ_{n-r}

非齐次方程组求通解：

步骤1：对增广矩阵 (A ∣ b) 行变换，判定是否有解
步骤2：若有解，求出一个特解 η*
步骤3：求对应齐次方程组的基础解系 ξ1,...,ξ_{n-r}
步骤4：通解 = η* + k1·ξ1 + ... + k_{n-r}·ξ_{n-r}

题型20：含参数线性方程组

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 含参数的秩讨论
  • 分类讨论解的情况
  • 求参数满足的条件

典型考法：

  1. 讨论参数a取何值时方程组有解、无解、唯一解、无穷解
  2. 已知方程组有非零解，求参数
  3. 已知方程组解满足某条件，求参数

分类讨论框架：

1. 对含参增广矩阵行变换
2. 找出使矩阵"质变"的临界参数值（如某元素为0/非0）
3. 对各参数区间分别讨论 r(A) 与 r(A,b)
4. 给出各情况下的解

题型21：公共解与同解问题

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 公共解的求法
  • 同解的判定条件
  • 联立方程组

公共解的求法：

方法1（联立法）：解联立方程组
  [A]       [0]
  [B] x  =  [0]
  通解即为公共解

方法2（通解代入法）：将Ax=0的通解代入Bx=0中，求满足条件的解

方法3：分别求通解，令其相等求公共解

同解条件：两齐次方程组同解 ⇔ 行向量组等价 ⇔ $r(A) = r(B) = r\begin{pmatrix} A \\ B \end{pmatrix}$

第五章 特征值与特征向量 —— 常考题型

题型22：求特征值与特征向量

难度：★★★☆☆ | 题型：填空题/解答题

涉及知识点：

  • 特征方程 $|\lambda E - A| = 0$
  • 特征向量的求解（解方程组）

标准求解步骤：

步骤1：计算特征多项式 f(λ) = |λE - A|
步骤2：解 f(λ) = 0，得特征值 λ1, λ2, ..., λn
步骤3：对每个 λi，解 (λiE - A)x = 0，得特征向量

快速求特征值技巧：

  • 观察矩阵是否可以写成特殊形式（如每行和为常数c → λ = c）
  • 利用 $\sum \lambda_i = \text{tr}(A)$ 和 $\prod \lambda_i = |A|$ 验算
  • 上/下三角阵的特征值即主对角元素

题型23：相似矩阵的判定

难度：★★★★☆ | 题型：选择题/解答题

涉及知识点：

  • 相似的定义
  • 相似的必要条件
  • 相似与特征值的关系

判定方法：

充分条件：特征值相同 + 都可对角化 → 相似
必要条件（不满足任一条件则不相似）：
  · 特征值必须相同
  · 行列式必须相同
  · 迹必须相同
  · 秩必须相同

常见陷阱：

  • 特征值相同不一定是相似矩阵！（还需判断是否可对角化）
  • 若特征值相同，但对某个特征值，特征向量的维数不同，则不相似

题型24：矩阵对角化

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 可对角化的充要条件
  • 对角化的步骤
  • 利用对角化求 $A^n$

对角化步骤：

步骤1：求所有特征值 λ1, λ2, ..., λn
步骤2：对每个λi求一个极大线性无关的特征向量组
步骤3：检查是否有n个线性无关的特征向量
步骤4：以特征向量为列构造矩阵P
步骤5：P^{-1}AP = diag(λ1, λ2, ..., λn)

可对角化判定：

  • ✅ 有n个不同特征值 → 可对角化
  • ✅ 实对称矩阵 → 必可对角化
  • ❌ 对k重特征值，若 r(λE-A) > n-k → 不可对角化

利用对角化求 $A^n$：

$$A^n = P \Lambda^n P^{-1} = P \begin{pmatrix} \lambda_1^n & & \\ & \ddots & \\ & & \lambda_n^n \end{pmatrix} P^{-1}$$

题型25：实对称矩阵的对角化

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 实对称矩阵的特征值都是实数
  • 不同特征值对应的特征向量正交
  • 正交对角化

正交对角化步骤：

步骤1：求特征值
步骤2：对每个特征值求特征向量
步骤3：对属于同一特征值的特征向量施密特正交化
步骤4：将所有特征向量单位化
步骤5：以单位正交向量为列构造正交矩阵Q
步骤6：Q^T AQ = Q^{-1} AQ = diag(λ1, ..., λn)

与一般对角化的区别：实对称矩阵可以使用正交矩阵Q对角化！

第六章 二次型 —— 常考题型

题型26：写出二次型的矩阵

难度：★★☆☆☆ | 题型：填空题

涉及知识点：

  • 二次型矩阵必须是对称矩阵
  • 交叉项系数的分配

规则：

$$f = \sum_{i=1}^n a_{ii}x_i^2 + 2\sum_{i

示例：$f = x_1^2 + 4x_1x_2 + 2x_2^2$ → $A = \begin{pmatrix} 1 & 2 \\ 2 & 2 \end{pmatrix}$（交叉项系数拆成 $2+2=4$）

题型27：化二次型为标准形

难度：★★★★☆ | 题型：解答题

涉及知识点：

  • 正交变换法
  • 配方法
  • 合同变换法

方法一：正交变换法（必考）

步骤1：写出二次型的矩阵A（对称矩阵）
步骤2：求A的特征值 λ1, λ2, ..., λn
步骤3：求对应的标准正交特征向量
步骤4：构造正交矩阵Q
步骤5：正交变换 x = Qy → f = λ1 y1² + λ2 y2² + ... + λn yn²

方法二：配方法

步骤1：若含平方项 xi²：
  · 所有含xi的项配方，写为 (xi + ...)² 的形式
  · 对剩余项重复此步骤

步骤2：若不含任何平方项（仅有交叉项）：
  · 令 x1 = y1 + y2, x2 = y1 - y2（将交叉项化为平方项之差）
  · 再配方

最终得到 f = d1 z1² + d2 z2² + ... + dn zn²

题型28：二次型正定性判定

难度：★★★★☆ | 题型：选择题/解答题

涉及知识点：

  • 正定的定义
  • 正定的充要条件
  • 顺序主子式

正定判定方法：

方法判定条件
定义法$\forall x \neq 0, x^TAx > 0$
特征值法所有特征值 > 0
顺序主子式法所有顺序主子式 > 0
惯性指数法正惯性指数 p = n
合同判定法A合同于E

顺序主子式法（最常用）：

A正定 ⇔ 
  a11 > 0
  |a11  a12| > 0
  |a21  a22|
  ......
  |A| > 0

含参数正定问题：

步骤1：写出A的各阶顺序主子式
步骤2：令每个主子式 > 0
步骤3：解不等式组，得参数取值范围

题型29：合同矩阵的判定

难度：★★★☆☆ | 题型：选择题

涉及知识点：

  • 合同的定义 $B = C^TAC$
  • 合同的充要条件

判定方法：

A与B合同 ⇔ A与B有相同的正惯性指数和负惯性指数
         ⇔ A与B的秩相同且符号差相同

实对称矩阵A与B合同 ⇔ 正惯性指数相同且负惯性指数相同

注意与相似的区别：

  • 相似 → 特征值相同
  • 合同 → 正负惯性指数相同（特征值可不同，但正负号个数相同）

题型30：二次型的最值问题与几何应用

难度：★★★☆☆ | 题型：选择/填空

涉及知识点：

  • 瑞利商 $R(x) = \frac{x^TAx}{x^Tx}$
  • 最大/最小特征值与二次型最值

核心结论：

$$\lambda_{\min} \leq \frac{x^T A x}{x^T x} \leq \lambda_{\max}$$

其中 $\lambda_{\min}$ 和 $\lambda_{\max}$ 为A的最小和最大特征值（A为实对称矩阵）。

题型32：伴随矩阵秩分类

难度：★★★★☆ | 题型：选择题/填空题

A 的秩A* 的秩常见结论
$r(A)=n$$r(A^*)=n$A 与 A* 均可逆
$r(A)=n-1$$r(A^*)=1$A* 非零，且每列均为 $Ax=0$ 的解
$r(A)<n-1$$r(A^*)=0$$A^*=O$

易错：$A^*=|A|A^{-1}$ 只适合 A 可逆；A 不可逆时必须用秩分类。

题型33：矩阵多项式与高次幂

难度：★★★★☆ | 题型：填空题/解答题

  1. 对角化法：若 $A=P\Lambda P^{-1}$，则 $A^n=P\Lambda^nP^{-1}$，$f(A)=P f(\Lambda)P^{-1}$。
  2. Cayley-Hamilton 降幂：由特征方程 $p(\lambda)=0$ 得 $p(A)=O$，把高次幂化成低次幂。
  3. 特征向量法：若 $A\alpha=\lambda\alpha$，则 $f(A)\alpha=f(\lambda)\alpha$。

典型例题：已知 $A^2-3A+2E=O$，求 $A^n$ 或 $A^{-1}$；已知 A 可对角化，求 $A^{2026}$。

题型34：可对角化重根判定

难度：★★★★☆ | 题型：选择题/解答题

判定核心：对每个 k 重特征值 $\lambda$，必须有 $n-r(\lambda E-A)=k$，即几何重数等于代数重数。

情况结论
有 n 个互不相同的特征值必可对角化
实对称矩阵必可正交对角化
存在重特征值必须检查对应特征向量个数
某个 k 重特征值只有少于 k 个线性无关特征向量不可对角化

易错：特征值个数少于 n 并不一定不可对角化，关键看重根对应的特征向量个数。

题型35：等价/相似/合同辨析

难度：★★★★☆ | 题型：选择题/填空题

关系形式不变量常见判断
等价$B=PAQ$秩同型矩阵秩相同即等价
相似$B=P^{-1}AP$特征值、特征多项式、迹、行列式、秩特征值相同不一定相似
合同$B=C^TAC$秩、正负惯性指数、正定性实对称矩阵看惯性指数

速记：等价看秩，相似看特征，合同看惯性。
