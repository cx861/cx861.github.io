第1章 随机事件与概率

1.1 随机事件

随机试验 $E$ 的特征

  • 可以在相同条件下重复进行
  • 试验结果不止一个，且能事先明确所有可能结果
  • 试验前不能确定会出现哪个结果

样本空间 $\Omega$：随机试验所有可能结果组成的集合

随机事件：样本空间的子集，简称事件

事件的关系与运算

关系/运算符号含义
包含$A \subset B$$A$ 发生则 $B$ 一定发生
相等$A = B$$A \subset B$ 且 $B \subset A$
和（并）$A \cup B$$A, B$ 至少一个发生
积（交）$A \cap B$ 或 $AB$$A, B$ 同时发生
差$A - B$$A$ 发生且 $B$ 不发生
互斥（不相容）$AB = \varnothing$$A, B$ 不能同时发生
对立（逆）$A \cup B = \Omega, AB = \varnothing$$B = \overline{A}$
完备事件组$A_1 \cup \cdots \cup A_n = \Omega$，且 $A_iA_j = \varnothing(i\neq j)$两两互斥且覆盖全空间

运算律

  • 交换律：$A \cup B = B \cup A,\; AB = BA$
  • 结合律：$(A \cup B) \cup C = A \cup (B \cup C),\; (AB)C = A(BC)$
  • 分配律：$(A \cup B)C = AC \cup BC$
  • 德·摩根律：$\overline{A \cup B} = \overline{A}\,\overline{B},\;\overline{AB} = \overline{A} \cup \overline{B}$

1.2 概率的定义与性质

概率的公理化定义（柯尔莫哥洛夫）

设 $\Omega$ 为样本空间，$\mathcal{F}$ 为事件域，$P(\cdot)$ 为定义在 $\mathcal{F}$ 上的实值函数，若满足：

  1. 非负性：$P(A) \geq 0,\;\forall A \in \mathcal{F}$
  2. 规范性：$P(\Omega) = 1$
  3. 可列可加性：若 $A_1, A_2, \ldots$ 两两互斥，则 $P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$

则称 $P(A)$ 为事件 $A$ 的概率。

概率的基本性质

  1. $P(\varnothing) = 0$
  2. 有限可加性：若 $A_1,\ldots,A_n$ 两两互斥，则 $P\left(\bigcup_{i=1}^n A_i\right) = \sum_{i=1}^n P(A_i)$
  3. 单调性与减法公式：若 $A \subset B$，则 $P(B-A) = P(B) - P(A)$ 且 $P(A) \leq P(B)$
  4. 有界性：$0 \leq P(A) \leq 1$
  5. 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
  • 推广：$P(A \cup B \cup C) = P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$
  1. 求逆公式：$P(\overline{A}) = 1 - P(A)$

1.3 古典概型与几何概型

古典概型（等可能有限样本空间）

$$P(A) = \frac{|A|}{|\Omega|} = \frac{\text{事件}A\text{包含的样本点数}}{\text{样本点总数}}$$

适用条件：① $\Omega$ 有限；② 每个样本点等可能

几何概型（等可能无限样本空间）

$$P(A) = \frac{A\text{的几何度量（长度/面积/体积）}}{\Omega\text{的几何度量}}$$

1.4 条件概率

定义：设 $P(B) > 0$，则在事件 $B$ 发生的条件下事件 $A$ 发生的条件概率为

$$P(A|B) = \frac{P(AB)}{P(B)}$$

乘法公式

  • $P(AB) = P(A)P(B|A),\;P(A)>0$
  • $P(AB) = P(B)P(A|B),\;P(B)>0$
  • 推广：$P(ABC) = P(A)P(B|A)P(C|AB)$

全概率公式

设 $B_1,B_2,\ldots,B_n$ 是 $\Omega$ 的一个完备事件组，且 $P(B_i) > 0$，则对任意事件 $A$：

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$

贝叶斯公式（逆概率公式）

设 $B_1,\ldots,B_n$ 是 $\Omega$ 的一个完备事件组，$P(A)>0$，则

$$P(B_j|A) = \frac{P(B_j)P(A|B_j)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)}$$

1.5 事件的独立性

两个事件的独立性

定义：若 $P(AB) = P(A)P(B)$，则称 $A, B$ 相互独立

等价条件（$P(A)>0,\;P(B)>0$ 时）：

  • $P(B|A) = P(B)$（或 $P(A|B)=P(A)$）

三个事件的独立性

$A,B,C$ 相互独立 $\iff$

$$\begin{cases} P(AB) = P(A)P(B)\\ P(AC) = P(A)P(C)\\ P(BC) = P(B)P(C)\\ P(ABC) = P(A)P(B)P(C) \end{cases}$$

$n$ 个事件的相互独立性

任意 $k$ 个事件（$2 \leq k \leq n$）的交的概率等于各事件概率的乘积

重要结论

  • $A$ 与 $B$ 独立 $\iff$ $A$ 与 $\overline{B}$ 独立 $\iff$ $\overline{A}$ 与 $B$ 独立 $\iff$ $\overline{A}$ 与 $\overline{B}$ 独立
  • 若 $A_1,\ldots,A_n$ 相互独立，则 $P\left(\bigcup_{i=1}^n A_i\right) = 1 - \prod_{i=1}^n [1-P(A_i)]$

1.6 伯努利试验

伯努利试验：只有两种可能结果（$A$ 发生 / $A$ 不发生）的试验

$n$ 重伯努利试验：独立重复进行 $n$ 次伯努利试验

二项分布的概率：$P(\text{恰好}k\text{次}A) = \mathrm{C}_n^k p^k (1-p)^{n-k}$，其中 $p = P(A)$

第2章 随机变量及其分布

2.1 随机变量

定义：设 $\Omega$ 为样本空间，若对任意 $\omega \in \Omega$ 都有唯一的实数 $X(\omega)$ 与之对应，则称 $X = X(\omega)$ 为随机变量。

随机变量的分布函数

$$F(x) = P(X \leq x),\quad x \in \mathbb{R}$$

分布函数的性质

  1. 单调非减：若 $x_1 < x_2$，则 $F(x_1) \leq F(x_2)$
  2. 右连续性：$F(x^+) = F(x)$
  3. 规范性：$F(-\infty) = 0,\;F(+\infty) = 1$

2.2 离散型随机变量

定义：若随机变量 $X$ 的可能取值为有限个或可列个，则称 $X$ 为离散型随机变量。

分布律（概率分布）

$$P(X = x_k) = p_k,\quad k=1,2,\ldots$$

满足：$p_k \geq 0,\;\sum_k p_k = 1$

2.3 连续型随机变量

定义：若存在非负可积函数 $f(x)$，使得对任意 $x$ 有 $F(x) = \int_{-\infty}^{x} f(t)dt$，则称 $X$ 为连续型随机变量，$f(x)$ 为概率密度函数。

概率密度的性质

  1. $f(x) \geq 0$
  2. $\int_{-\infty}^{+\infty} f(x)dx = 1$
  3. $P(a < X \leq b) = \int_a^b f(x)dx$
  4. 在 $f(x)$ 的连续点处：$f(x) = F'(x)$

2.4 随机变量函数的分布

离散型：若 $Y = g(X)$，$X$ 的分布律为 $P(X=x_k)=p_k$，则 $P(Y = y_j) = \sum_{x_k: g(x_k)=y_j} p_k$

连续型（分布函数法）

求 $Y = g(X)$ 的分布：

  1. 写出 $F_Y(y) = P(Y \leq y) = P(g(X) \leq y) = \int_{g(x) \leq y} f_X(x)dx$
  2. 对 $F_Y(y)$ 求导得 $f_Y(y)$

单调函数公式法（ $g$ 严格单调可导时）

若 $y = g(x)$ 严格单调，反函数 $x = h(y)$ 存在，则

$$f_Y(y) = f_X(h(y)) \cdot |h'(y)|$$

非单调可导变换公式

若方程 $y=g(x)$ 在 $f_X(x)>0$ 的范围内有有限个根 $x_1,\ldots,x_m$，且 $g'(x_i)\neq 0$，则

$$f_Y(y)=\sum_{i=1}^{m}\frac{f_X(x_i)}{|g'(x_i)|}$$

典型如 $Y=X^2$，要同时考虑 $x=\sqrt{y}$ 与 $x=-\sqrt{y}$ 两个分支，并先确定 $y$ 的取值范围。

正态变量的线性函数：若 $X \sim N(\mu,\sigma^2)$，则 $aX+b \sim N(a\mu+b, a^2\sigma^2)$

第3章 多维随机变量及其分布

3.1 二维随机变量

联合分布函数

$$F(x,y) = P(X \leq x, Y \leq y)$$

联合分布函数的性质

  1. 关于 $x,y$ 分别单调非减、右连续
  2. $F(-\infty,y) = F(x,-\infty) = 0,\;F(+\infty,+\infty) = 1$
  3. 矩形不等式：$F(b,d) - F(a,d) - F(b,c) + F(a,c) \geq 0$（其中 $a

3.2 二维离散型随机变量

联合分布律

$$P(X=x_i, Y=y_j) = p_{ij},\quad \sum_i\sum_j p_{ij} = 1,\;p_{ij}\geq 0$$

边缘分布律

$$P(X=x_i) = \sum_j p_{ij} = p_{i\cdot},\quad P(Y=y_j) = \sum_i p_{ij} = p_{\cdot j}$$

条件分布律

$$P(X=x_i|Y=y_j) = \frac{p_{ij}}{p_{\cdot j}}\;(p_{\cdot j}>0),\quad P(Y=y_j|X=x_i) = \frac{p_{ij}}{p_{i\cdot}}\;(p_{i\cdot}>0)$$

3.3 二维连续型随机变量

联合概率密度：$f(x,y) \geq 0,\;\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} f(x,y)dxdy = 1$

边缘概率密度

$$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)dy,\quad f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)dx$$

条件概率密度（ $f_Y(y)>0$ 时）

$$f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)},\quad f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$$

二维均匀分布：$f(x,y)=\dfrac{1}{S_D},\;(x,y)\in D$（$S_D$ 为区域 $D$ 的面积）

二维正态分布：$(X,Y)\sim N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)$

$$f(x,y)=\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\exp\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2}-2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2}+\frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right\}$$

3.4 随机变量的独立性

定义：$X,Y$ 相互独立 $\iff$ $F(x,y) = F_X(x)F_Y(y),\;\forall x,y$

  • 离散型：$X,Y$ 独立 $\iff$ $p_{ij} = p_{i\cdot} \cdot p_{\cdot j},\;\forall i,j$
  • 连续型：$X,Y$ 独立 $\iff$ $f(x,y) = f_X(x)f_Y(y),\;\forall x,y$

二维正态分布的独立性：$X,Y$ 相互独立 $\iff$ $\rho = 0$

3.5 二维随机变量函数的分布

二维变换与 Jacobian

设 $U=g_1(X,Y),\;V=g_2(X,Y)$，反变换为 $x=x(u,v),\;y=y(u,v)$，且一一可微，则

$$f_{U,V}(u,v)=f_{X,Y}(x(u,v),y(u,v))\left|\frac{\partial(x,y)}{\partial(u,v)}\right|$$

其中 $\left|\dfrac{\partial(x,y)}{\partial(u,v)}\right|$ 为反变换的 Jacobian 绝对值。若变换不是一一对应，需要按不同分支分别求和。

和的分布（卷积公式）

$$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f(x,z-x)dx = \int_{-\infty}^{+\infty} f(z-y,y)dy$$

若 $X,Y$ 独立：$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x)dx$（连续型）

$$P(Z=k) = \sum_{i=0}^{k} P(X=i)P(Y=k-i)\quad\text{（离散型）}$$

积与商的分布（独立连续型常用）

  • $Z=XY$：$f_Z(z)=\int_{-\infty}^{+\infty} f_X(x)f_Y\left(\dfrac{z}{x}\right)\dfrac{1}{|x|}dx$
  • $Z=\dfrac{X}{Y}$：$f_Z(z)=\int_{-\infty}^{+\infty} |y|f_X(zy)f_Y(y)dy$

极值分布

  • $M = \max(X,Y)$：$F_M(z) = F_X(z)F_Y(z)$
  • $N = \min(X,Y)$：$F_N(z) = 1 - [1-F_X(z)][1-F_Y(z)]$

顺序统计量（独立同分布样本 $X_1,\ldots,X_n$，分布函数为 $F$，密度为 $f$）

  • 最大值 $X_{(n)}$：$F_{X_{(n)}}(x)=[F(x)]^n$
  • 最小值 $X_{(1)}$：$F_{X_{(1)}}(x)=1-[1-F(x)]^n$
  • 第 $k$ 顺序统计量密度：$f_{X_{(k)}}(x)=\dfrac{n!}{(k-1)!(n-k)!}[F(x)]^{k-1}[1-F(x)]^{n-k}f(x)$

独立正态变量的和：若 $X \sim N(\mu_1,\sigma_1^2),\;Y \sim N(\mu_2,\sigma_2^2)$ 且独立，则

$$X+Y \sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)$$

$X^2$ 的分布（卡方分布）

若 $X \sim N(0,1)$，则 $X^2 \sim \chi^2(1)$（自由度为1的卡方分布）

第4章 随机变量的数字特征

4.1 数学期望

离散型：$E(X) = \sum_{k} x_k p_k$（要求级数绝对收敛）

连续型：$E(X) = \int_{-\infty}^{+\infty} x f(x)dx$（要求积分绝对收敛）

随机变量函数的期望

  • 一维：$E[g(X)] = \sum_k g(x_k)p_k$（离散）；$E[g(X)] = \int_{-\infty}^{+\infty} g(x)f(x)dx$（连续）
  • 二维：$E[g(X,Y)] = \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} g(x,y)f(x,y)dxdy$

期望的性质

  1. $E(C) = C$
  2. $E(aX+b) = aE(X) + b$
  3. $E(X+Y) = E(X) + E(Y)$（不要求独立性）
  4. 若 $X,Y$ 独立，则 $E(XY) = E(X)E(Y)$

条件期望与全期望公式

  • 离散型：$E(Y|X=x_i)=\sum_j y_jP(Y=y_j|X=x_i)$
  • 连续型：$E(Y|X=x)=\int_{-\infty}^{+\infty} yf_{Y|X}(y|x)dy$
  • 全期望公式：$E(Y)=E[E(Y|X)]$

4.2 方差

定义：$\mathrm{Var}(X) = D(X) = E[(X-E(X))^2] = E(X^2) - [E(X)]^2$

方差的性质

  1. $D(C) = 0$
  2. $D(aX+b) = a^2 D(X)$
  3. 若 $X,Y$ 独立，则 $D(X\pm Y) = D(X) + D(Y)$
  4. $D(X) = 0 \iff P(X = E(X)) = 1$（常数）

全方差公式

$$D(Y)=E[D(Y|X)]+D[E(Y|X)]$$

先按条件 $X$ 分层计算，再汇总，常用于“先抽环境/类型，再产生观测值”的两阶段模型。

重要不等式

  • 切比雪夫不等式：$P(|X-E(X)| \geq \varepsilon) \leq \dfrac{D(X)}{\varepsilon^2}$

等价形式：$P(|X-E(X)| < \varepsilon) \geq 1 - \dfrac{D(X)}{\varepsilon^2}$

4.3 协方差与相关系数

协方差

$$\mathrm{Cov}(X,Y) = E[(X-E(X))(Y-E(Y))] = E(XY) - E(X)E(Y)$$

相关系数

$$\rho_{XY} = \frac{\mathrm{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$

性质

  1. $\mathrm{Cov}(X,Y) = \mathrm{Cov}(Y,X)$
  2. $\mathrm{Cov}(aX+b, cY+d) = ac\cdot\mathrm{Cov}(X,Y)$
  3. $\mathrm{Cov}(X_1+X_2, Y) = \mathrm{Cov}(X_1,Y) + \mathrm{Cov}(X_2,Y)$
  4. $|\rho_{XY}| \leq 1$
  5. $|\rho_{XY}| = 1 \iff$ 存在常数 $a,b$ 使得 $P(Y = aX+b) = 1$
  6. $\rho_{XY} = 0$（$X,Y$ 不相关）$\iff \mathrm{Cov}(X,Y)=0 \iff E(XY)=E(X)E(Y) \iff D(X+Y)=D(X)+D(Y)$

独立 $\Rightarrow$ 不相关；不相关 $\nRightarrow$ 独立

反例：令 $X\sim U(-1,1)$，$Y=X^2$，则 $E(XY)=E(X^3)=0$ 且 $E(X)=0$，所以 $X,Y$ 不相关，但 $Y$ 由 $X$ 决定，显然不独立。

特殊结论：二维正态分布中，独立 $\iff$ 不相关 $\iff \rho=0$。

4.4 矩、协方差矩阵

原点矩：$k$ 阶原点矩 $\alpha_k = E(X^k)$

中心矩：$k$ 阶中心矩 $\beta_k = E[(X-E(X))^k]$

混合矩：$\mathrm{Cov}(X,Y) = E[(X-E(X))(Y-E(Y))]$ 是 $1+1$ 阶混合中心矩

协方差矩阵（随机向量 $(X_1,\ldots,X_n)^T$）

$$C = \begin{pmatrix} D(X_1) & \mathrm{Cov}(X_1,X_2) & \cdots & \mathrm{Cov}(X_1,X_n)\\ \mathrm{Cov}(X_2,X_1) & D(X_2) & \cdots & \mathrm{Cov}(X_2,X_n)\\ \vdots & \vdots & \ddots & \vdots\\ \mathrm{Cov}(X_n,X_1) & \mathrm{Cov}(X_n,X_2) & \cdots & D(X_n) \end{pmatrix}$$

协方差矩阵是对称非负定矩阵。

第5章 大数定律与中心极限定理

5.1 大数定律

依概率收敛：设 $X_n, X$ 为随机变量，若 $\forall \varepsilon > 0$，$\lim\limits_{n\to\infty} P(|X_n - X| \geq \varepsilon) = 0$，则称 $X_n$ 依概率收敛于 $X$，记作 $X_n \xrightarrow{P} X$。

切比雪夫大数定律

设 $X_1,X_2,\ldots$ 相互独立，$D(X_i) \leq C$（方差一致有界），则

$$\frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{P} \frac{1}{n}\sum_{i=1}^{n} E(X_i)$$

伯努利大数定律

设 $n_A$ 为 $n$ 次独立重复试验中 $A$ 发生的次数，$p = P(A)$，则

$$\frac{n_A}{n} \xrightarrow{P} p$$

辛钦大数定律

设 $X_1,X_2,\ldots$ 独立同分布，$E(X_i) = \mu$，则

$$\frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{P} \mu$$

（注：不要求方差存在，只要求期望存在）

5.2 中心极限定理

列维-林德伯格中心极限定理（独立同分布情形）

设 $X_1,X_2,\ldots$ 独立同分布，$E(X_i)=\mu$，$D(X_i)=\sigma^2>0$，则

$$\frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{d} N(0,1)$$

即：当 $n$ 充分大时，$\sum_{i=1}^{n} X_i$ 近似服从 $N(n\mu, n\sigma^2)$。

棣莫弗-拉普拉斯中心极限定理（二项分布情形）

设 $X \sim B(n,p)$，则

$$\frac{X - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0,1)$$

即：当 $n$ 充分大时，$B(n,p)$ 可用 $N(np, np(1-p))$ 近似。

中心极限定理的应用

  • 用正态分布近似计算二项分布的概率（ $n$ 较大时）
  • 独立同分布随机变量和的概率计算

连续性修正

用正态分布近似离散型二项分布时，端点可作 $0.5$ 修正：

$$P(a\leq X\leq b)\approx \Phi\left(\frac{b+0.5-np}{\sqrt{np(1-p)}}\right)-\Phi\left(\frac{a-0.5-np}{\sqrt{np(1-p)}}\right)$$

若求 $P(X\leq b)$，通常修正为 $P(X< b+0.5)$；若求 $P(X\geq a)$，通常修正为 $P(X> a-0.5)$。

第6章 数理统计的基本概念

6.1 总体与样本

总体：研究对象的某项数量指标 $X$ 的取值全体（视为随机变量）

样本：从总体中抽取的 $n$ 个个体，对应的随机变量 $X_1,X_2,\ldots,X_n$ 称为简单随机样本，若：

  1. $X_1,\ldots,X_n$ 与 $X$ 同分布
  2. $X_1,\ldots,X_n$ 相互独立

样本观测值：$x_1,x_2,\ldots,x_n$（小写表示具体数值）

6.2 统计量

定义：设 $X_1,\ldots,X_n$ 为样本，$g(X_1,\ldots,X_n)$ 为连续函数，且不含未知参数，则称 $g(X_1,\ldots,X_n)$ 为统计量。

常用统计量

  • 样本均值：$\overline{X} = \dfrac{1}{n}\sum_{i=1}^{n} X_i$
  • 样本方差：$S^2 = \dfrac{1}{n-1}\sum_{i=1}^{n} (X_i - \overline{X})^2$
  • 样本标准差：$S = \sqrt{S^2}$
  • 样本 $k$ 阶原点矩：$A_k = \dfrac{1}{n}\sum_{i=1}^{n} X_i^k$
  • 样本 $k$ 阶中心矩：$B_k = \dfrac{1}{n}\sum_{i=1}^{n} (X_i - \overline{X})^k$

6.3 三大分布

$\chi^2$ 分布

设 $X_1,\ldots,X_n \sim N(0,1)$ 且独立，则 $\sum_{i=1}^{n} X_i^2 \sim \chi^2(n)$（$n$ 为自由度）

性质：

  • 可加性：若 $X\sim\chi^2(n_1),\;Y\sim\chi^2(n_2)$ 独立，则 $X+Y\sim\chi^2(n_1+n_2)$
  • $E[\chi^2(n)] = n,\;D[\chi^2(n)] = 2n$

$t$ 分布

设 $X \sim N(0,1),\;Y \sim \chi^2(n)$ 且独立，则 $T = \dfrac{X}{\sqrt{Y/n}} \sim t(n)$

性质：

  • $t$ 分布的概率密度是偶函数，关于 $x=0$ 对称
  • $n \to \infty$ 时，$t(n)$ 趋近于 $N(0,1)$
  • $E[T] = 0\;(n>1),\;D[T] = \dfrac{n}{n-2}\;(n>2)$

$F$ 分布

设 $X \sim \chi^2(n_1),\;Y \sim \chi^2(n_2)$ 且独立，则 $F = \dfrac{X/n_1}{Y/n_2} \sim F(n_1,n_2)$

性质：

  • 若 $F \sim F(n_1,n_2)$，则 $\dfrac{1}{F} \sim F(n_2,n_1)$
  • $F_{1-\alpha}(n_1,n_2) = \dfrac{1}{F_{\alpha}(n_2,n_1)}$

6.4 正态总体的抽样分布

单个正态总体 $N(\mu,\sigma^2)$

  1. $\overline{X} \sim N\left(\mu, \dfrac{\sigma^2}{n}\right)$，即 $\dfrac{\overline{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$
  2. $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，且 $\overline{X}$ 与 $S^2$ 相互独立
  3. $\dfrac{\overline{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$

两个正态总体 $N(\mu_1,\sigma_1^2),\;N(\mu_2,\sigma_2^2)$

设 $\overline{X},\overline{Y},S_1^2,S_2^2$ 分别为两个样本的样本均值和样本方差，$n_1,n_2$ 为样本量。

  1. $\overline{X} - \overline{Y} \sim N\left(\mu_1-\mu_2, \dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2}\right)$
  2. $\sigma_1^2 = \sigma_2^2 = \sigma^2$ 时：
$$\frac{(\overline{X}-\overline{Y})-(\mu_1-\mu_2)}{S_w\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}} \sim t(n_1+n_2-2)$$

其中 $S_w^2 = \dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$

  1. $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$

第7章 参数估计

7.1 点估计

矩估计法

用样本矩估计总体矩：令

$$\begin{cases} A_1 = \alpha_1(\theta_1,\ldots,\theta_k)\\ \cdots\\ A_k = \alpha_k(\theta_1,\ldots,\theta_k) \end{cases}$$

解出 $\hat{\theta}_1,\ldots,\hat{\theta}_k$ 即为矩估计量。

最大似然估计法（MLE）

  1. 写出似然函数 $L(\theta) = \prod_{i=1}^{n} f(x_i;\theta)$（连续）或 $L(\theta) = \prod_{i=1}^{n} p(x_i;\theta)$（离散）
  2. 取对数：$\ln L(\theta) = \sum_{i=1}^{n} \ln f(x_i;\theta)$
  3. 令 $\dfrac{\partial \ln L(\theta)}{\partial \theta_j} = 0$，解方程组得 $\hat{\theta}_j$
  4. 若导数方程无解，则 $\hat{\theta}$ 在参数空间边界取得（此时用单调性分析）

MLE 边界与支持集含参数问题

  • 若密度/分布律的取值范围含未知参数，必须先把样本约束写入似然函数，例如 $I(\theta\geq X_{(n)})$ 或 $I(\theta\leq X_{(1)})$。
  • 均匀分布、指数截断型分布常在边界取最大值，不能只对 $\ln L$ 求导。
  • 先确定参数空间，再比较内部驻点与边界点的似然值。

7.2 估计量的评价标准

无偏性：$E(\hat{\theta}) = \theta$，则称 $\hat{\theta}$ 为 $\theta$ 的无偏估计量

  • $\overline{X}$ 是 $\mu$ 的无偏估计
  • $S^2 = \dfrac{1}{n-1}\sum(X_i-\overline{X})^2$ 是 $\sigma^2$ 的无偏估计
  • 注意：$\dfrac{1}{n}\sum(X_i-\overline{X})^2$ 不是 $\sigma^2$ 的无偏估计（有偏，偏小）

有效性：设 $\hat{\theta}_1,\hat{\theta}_2$ 均为 $\theta$ 的无偏估计，若 $D(\hat{\theta}_1) < D(\hat{\theta}_2)$，则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 更有效。

一致性（相合性）：若 $\hat{\theta}_n \xrightarrow{P} \theta$（当 $n \to \infty$），则称 $\hat{\theta}_n$ 为 $\theta$ 的一致估计量。

7.3 区间估计

置信区间：设 $\theta$ 为未知参数，若对任意 $\alpha \in (0,1)$，存在统计量 $\hat{\theta}_1,\hat{\theta}_2$ 使得

$$P(\hat{\theta}_1 < \theta < \hat{\theta}_2) = 1-\alpha$$

则称 $(\hat{\theta}_1, \hat{\theta}_2)$ 为 $\theta$ 的置信水平为 $1-\alpha$ 的置信区间。

第8章 假设检验

8.1 假设检验的基本概念

基本思想：先对总体参数提出一个假设 $H_0$（原假设），然后抽取样本，根据样本信息判断是否有足够证据拒绝 $H_0$。

两类错误

  • 第一类错误（弃真）：$H_0$ 为真时拒绝 $H_0$，概率记为 $\alpha$（显著性水平）
  • 第二类错误（取伪）：$H_0$ 为假时不拒绝 $H_0$，概率记为 $\beta$

显著性检验：只控制第一类错误的检验（通常取 $\alpha=0.05$ 或 $0.01$）

检验步骤

  1. 提出原假设 $H_0$ 和备择假设 $H_1$
  2. 选取合适的检验统计量，确定其分布
  3. 给定显著性水平 $\alpha$，确定拒绝域
  4. 根据样本计算统计量的值，作出判断

检验选型与拒绝域方向

检验目标条件统计量拒绝域方向
$\mu=\mu_0$$\sigma$ 已知$Z$$H_1:\mu>\mu_0$ 右尾；$H_1:\mu<\mu_0$ 左尾；$\neq$ 双尾
$\mu=\mu_0$$\sigma$ 未知，正态总体$t$方向由 $H_1$ 决定
$\sigma^2=\sigma_0^2$正态总体$\chi^2$大于用右尾，小于用左尾，不等用双尾

$\sigma_1^2=\sigma_2^2$两个正态总体$F$方差比大于用右尾，不等用双尾

$p$ 值：在 $H_0$ 成立时，观察到当前样本结果或更极端结果的概率。若 $p\leq\alpha$，则拒绝 $H_0$；若 $p>\alpha$，则不拒绝 $H_0$。

8.2 单个正态总体的假设检验

检验 $\mu$（$\sigma^2$ 已知）— $Z$ 检验

  • $H_0: \mu = \mu_0$，$H_1: \mu \neq \mu_0$（双侧）
  • 检验统计量：$Z = \dfrac{\overline{X} - \mu_0}{\sigma/\sqrt{n}} \sim N(0,1)$
  • 拒绝域：$|Z| > z_{\alpha/2}$

检验 $\mu$（$\sigma^2$ 未知）— $t$ 检验

  • 检验统计量：$T = \dfrac{\overline{X} - \mu_0}{S/\sqrt{n}} \sim t(n-1)$
  • 拒绝域（双侧）：$|T| > t_{\alpha/2}(n-1)$

检验 $\sigma^2$（$\mu$ 未知）— $\chi^2$ 检验

  • 检验统计量：$\chi^2 = \dfrac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$
  • 拒绝域（双侧）：$\chi^2 > \chi^2_{\alpha/2}(n-1)$ 或 $\chi^2 < \chi^2_{1-\alpha/2}(n-1)$

8.3 两个正态总体的假设检验

检验 $\mu_1 = \mu_2$（$\sigma_1^2=\sigma_2^2$ 未知）— 两样本 $t$ 检验

  • 检验统计量：$T = \dfrac{(\overline{X}-\overline{Y})-(\mu_1-\mu_2)}{S_w\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}} \sim t(n_1+n_2-2)$
  • 拒绝域（双侧）：$|T| > t_{\alpha/2}(n_1+n_2-2)$

检验 $\sigma_1^2 = \sigma_2^2$（$\mu_1,\mu_2$ 未知）— $F$ 检验

  • 检验统计量：$F = \dfrac{S_1^2}{S_2^2} \sim F(n_1-1,n_2-1)$
  • 拒绝域（双侧）：$F > F_{\alpha/2}(n_1-1,n_2-1)$ 或 $F < F_{1-\alpha/2}(n_1-1,n_2-1)$

8.4 置信区间与假设检验的对偶关系

对偶原理：

  • 若 $\mu_0$ 落在 $\mu$ 的 $1-\alpha$ 置信区间内，则不拒绝 $H_0: \mu = \mu_0$（显著性水平 $\alpha$）
  • 若 $\mu_0$ 不在 $\mu$ 的 $1-\alpha$ 置信区间内，则拒绝 $H_0: \mu = \mu_0$

即：对同一模型和同一显著性水平的双侧检验，置信区间等于所有未被拒绝的参数假设值的集合；样本空间中的不拒绝域与参数空间中的区间不是同一个集合。

附录：建模条件与综合自测

以下为补充整理与自编例题，适合学完对应章节后闭卷自测。

一、先区分互斥、独立与不相关

若 $P(A),P(B)>0$ 且互斥，则 $P(AB)=0\ne P(A)P(B)$，所以不独立。独立变量在二阶矩存在时不相关；反向推论需要额外条件，例如二者服从联合二维正态分布。仅知道两个边缘分布都正态仍不够。

二、例题：贝叶斯公式的分母怎么列

题目：两台机器甲、乙分别生产总量的 $60\%$、$40\%$，不合格率分别为 $1\%$、$3\%$。随机抽到不合格品，来自乙的概率是多少？

  1. 设 $D$ 为不合格，$B$ 为乙生产；机器来源构成样本空间的划分。
  2. $P(D)=0.6\times0.01+0.4\times0.03=0.018$。
  3. $P(B\mid D)=0.4\times0.03/0.018=2/3$。

易错：$P(D\mid B)=0.03$ 与 $P(B\mid D)$ 的条件方向相反。

三、例题：联合密度先确定支持域

已知 $f(x,y)=c$，$0<x<y<1$，其余为零。支持域是面积为 $1/2$ 的三角形，归一化得 $c=2$。对固定 $x$，$y$ 的范围是 $(x,1)$，所以 $f_X(x)=2(1-x)$（$0<x<1$）；对固定 $y$，$x$ 的范围是 $(0,y)$，所以 $f_Y(y)=2y$（$0<y<1$）。

于是 $E(X)=\int_0^1 2x(1-x)\,dx=1/3$。虽然边缘支持区间都是 $(0,1)$，但联合支持域不是矩形，且在 $x>y$ 处联合密度为零而边缘密度乘积为正，故不独立。

四、统计推断的条件清单

  • 区分总体方差已知与未知；正态总体、方差未知时，$T=(\bar X-\mu)/(S/\sqrt n)\sim t(n-1)$，其中 $S^2=\sum(X_i-\bar X)^2/(n-1)$，样本独立同分布。
  • 独立正态两样本且总体方差相等时，才能直接使用合并方差的两样本 $t$ 统计量。
  • 最大似然估计先写参数空间与支持集，再比较驻点、边界和单调性，不能只解导数等于零。
  • “未拒绝原假设”表示证据不足，不能写成“证明原假设正确”；置信度是区间构造方法在重复抽样中的覆盖率。

自测：独立同分布样本来自 $U(0,\theta)$（$\theta>0$）。采用 $0\le x\le\theta$ 的密度版本时，似然为 $\theta^{-n}\mathbf1_{\{\theta\ge X_{(n)}\}}$，在可行域单调递减，最大似然估计为 $\hat\theta=X_{(n)}$，不是某个内部驻点。

概念核对：MIT 概率统计阅读资料（条件概率、联合分布与推断）。例题为自编。

事件、条件概率与贝叶斯

核心知识：条件概率分母是已知条件的概率；全概率先找互斥完备划分，贝叶斯是由结果反推来源。

条件与边界：$P(A\mid B)$ 要求 $P(B)>0$；正概率互斥事件不独立。独立不是“不相交”。

基础题（自编）

$P(A)=0.4,P(B)=0.5,P(A\cup B)=0.7$，判断独立性和互斥性。

查看完整解析

加法公式给 $P(AB)=0.4+0.5-0.7=0.2$，恰等于 $P(A)P(B)$，所以独立；交集概率非零，故不互斥。

综合题（自编）

甲来源占20%、次品率5%，乙占80%、次品率1%。已知抽到次品，来自甲的概率是多少？

查看完整解析

设 $D$ 为次品，$P(D)=0.2(0.05)+0.8(0.01)=0.018$。$P(\text{甲}\mid D)=0.01/0.018=5/9$，不是5%。先验来源比例小，但条件次品率高，后验需同时考虑两因素。

反例与易错：掷一枚公平骰子，事件“点数1”和“点数2”互斥，却不独立，因交集0而概率乘积 $1/36$。

闭卷自测：交换条件方向时只交换符号、不改分母可以吗？

不可以，条件样本空间改变，须用联合概率和对应分母重算。

分布函数、原子概率与函数分布

核心知识：分布函数右连续且单调不减；跳跃大小是点概率。变量变换先求值域和单调区间，必要时用分布函数法处理多个原像。

条件与边界：$P(X=a)=F(a)-F(a-)$，不能在跳跃点直接把 $F(a)$ 视为点概率；密度只描述连续部分。

基础题（自编）

$F(x)=0$（$x<0$），$F(x)=1/4$（$0\le x<1$），$F(x)=1-\frac34e^{-(x-1)}$（$x\ge1$）。求 $P(X=0),P(X=1),P(X>2)$。

查看完整解析

0处跳跃 $1/4$，故 $P(X=0)=1/4$。1处左右极限均为 $1/4$，故 $P(X=1)=0$。尾概率 $1-F(2)=3/(4e)$。这是离散原子和连续部分混合的分布。

综合题（自编）

$X\sim U(-1,2)$，令 $Y=X^2$，求分布函数。

查看完整解析

$0\le Y<4$。$0\le y<1$ 时事件 $-\sqrt y\le X\le\sqrt y$ 的长度 $2\sqrt y$，所以 $F_Y=2\sqrt y/3$；$1\le y<4$ 时左边截到支持端点 $-1$，长度 $1+\sqrt y$，故 $F_Y=(1+\sqrt y)/3$。$y<0$ 时0，$y\ge4$ 时1。两段在1处都为 $2/3$。

反例与易错：$Y=X^2$ 在跨过0的支持区间上不单调，只取正平方根会漏概率。

闭卷自测：连续型变量在某点密度为2，该点概率就是2吗？

不是，连续型变量的单点概率仍为0，密度不是点概率。

联合密度、条件密度与卷积

核心知识：先画联合支持域，固定一个变量读取另一个变量范围；独立时联合密度几乎处处等于边缘密度乘积。和的密度可用卷积。

条件与边界：条件密度分母为正；卷积公式的积分区间要同时满足两个密度的支持条件。

基础题（自编）

$f_{X,Y}(x,y)=2$（$0<x<y<1$），求 $f_Y(y)$、$f_{X\mid Y}(x\mid y)$ 和 $E(X\mid Y=y)$。

查看完整解析

固定 $y\in(0,1)$，$x$ 从0到 $y$，故 $f_Y(y)=2y$。条件密度 $2/(2y)=1/y$（$0<x<y$），即 $U(0,y)$，条件均值 $y/2$；其他处条件密度为0。

综合题（自编）

独立 $X,Y\sim U(0,1)$，求 $Z=X+Y$ 的密度。

查看完整解析

卷积为 $\int f_X(x)f_Y(z-x)dx$。需 $0<x<1$ 且 $z-1<x<z$；$0<z<1$ 时交集长度 $z$，$1\le z<2$ 时长度 $2-z$，其他处0。两段面积各 $1/2$，总积分1。

反例与易错：三角形支持域中的变量通常不能仅凭边缘区间相同就当成独立；须检查联合密度或事件概率。

闭卷自测：卷积一定从0积到1吗？

不一定，范围是两个支持条件的交集，可能随 $z$ 改变而分段。

数字特征、协方差与相关性

核心知识：期望线性不要求独立；方差展开保留协方差。独立且二阶矩有限则不相关，反向一般不成立；联合正态才可用不相关推出独立。

条件与边界：$$\operatorname{Var}(aX+bY)=a^2D(X)+b^2D(Y)+2ab\operatorname{Cov}(X,Y)$$，不要漏交叉项。

基础题（自编）

已知 $$D(X)=4,D(Y)=9,\operatorname{Cov}(X,Y)=-3$$，求 $D(X+2Y)$ 与相关系数。

查看完整解析

$D(X+2Y)=4+4(9)+4(-3)=28$。相关系数 $\rho=-3/(2\cdot3)=-1/2$。协方差是负数时仍需连同系数符号一起代入。

综合题（自编）

$X\sim U(-1,1),Y=X^2$，求协方差并判断独立性。

查看完整解析

$E(X)=0,E(Y)=1/3,E(XY)=E(X^3)=0$，故协方差0。事件 $A=\{X>1/2\}$、$B=\{Y<1/4\}$ 分别概率 $1/4,1/2$，但交集空，$P(AB)=0\ne1/8$，所以不独立。

反例与易错：两个边缘分布均为正态并不保证联合二维正态，不能省略“联合”二字。

闭卷自测：计算 $E(X+Y)$ 前必须先证明独立吗？

期望存在时不必，线性性本身足够。

大数定律、切比雪夫与中心极限定理

核心知识：大数定律描述样本均值的概率收敛，中心极限定理描述标准化和的近似分布；切比雪夫给概率界，正态近似给近似值。

条件与边界：独立同分布且有限非零方差是常用中心极限定理条件；标准化均值用 $\sigma/\sqrt n$，和用 $\sigma\sqrt n$。

基础题（自编）

独立同分布样本有均值2、方差4，$n=100$。用切比雪夫不等式给出 $P(|\bar X-2|<0.5)$ 的下界。

查看完整解析

$D(\bar X)=4/100$，故 $$P(|\bar X-2|\ge0.5)\le(4/100)/0.25=0.16$$。补事件概率至少 $0.84$。这是保证下界，不是精确概率。

综合题（自编）

$S\sim B(100,1/2)$，用带连续性修正的正态近似求 $P(40\le S\le60)$。给 $\Phi(2.1)=0.9821$。

查看完整解析

均值50、标准差5。离散整数区间近似为连续区间 $[39.5,60.5]$，标准化得 $[-2.1,2.1]$，故概率近似 $2\Phi(2.1)-1=0.9642$。不修正会得到另一近似值，须标清所用口径。

反例与易错：“样本量大”不会把总体本身变成正态；中心极限定理针对标准化和或均值。

闭卷自测：切比雪夫下界0.84是否表示真实概率恰为0.84？

不是，它只保证不低于这个界。

正态样本与抽样分布

核心知识：对独立正态样本，$\bar X$ 与无偏样本方差 $S^2$ 独立，$(n-1)S^2/\sigma^2\sim\chi^2(n-1)$；用 $S$ 标准化均值得 $t$ 分布。

条件与边界：$S^2=\sum(X_i-\bar X)^2/(n-1)$；这里的精确抽样分布依赖总体正态，不能无条件搬到任意总体。

基础题（自编）

$n=10$、总体方差4，样本独立同分布。求 $E(\bar X),D(\bar X),E(S^2)$。

查看完整解析

$E(\bar X)=\mu,D(\bar X)=4/10=0.4$。按分母 $n-1$ 定义的 $S^2$ 无偏，故 $E(S^2)=4$。这些矩结论不需要正态，但下一题的精确分布需要。

综合题（自编）

$X_1,\ldots,X_8$ 来自 $N(\mu,\sigma^2)$。求 $Q=\sum(X_i-\bar X)^2/\sigma^2$ 的分布、期望、方差，以及 $\sqrt8(\bar X-\mu)/S$ 的分布。

查看完整解析

$Q=7S^2/\sigma^2\sim\chi^2(7)$，故 $E(Q)=7,D(Q)=14$。由于均值与样本方差独立，$\sqrt8(\bar X-\mu)/S\sim t(7)$。自由度损失1源于估计了样本均值。

反例与易错：分母为 $n$ 的样本二阶中心矩，其期望为 $(n-1)\sigma^2/n$，不是无偏样本方差。

闭卷自测：把总体均值已知当作未知估计时，平方和自由度为何可能变化？

围绕已知真均值的标准化平方和为 $\chi^2(n)$；围绕样本均值则为 $\chi^2(n-1)$。

参数估计：边界、无偏性与区间

核心知识：矩估计把总体矩与样本矩对应；最大似然在参数可行域内取最大值。无偏性是期望等于参数；置信区间须从枢轴量解不等式。

条件与边界：参数空间、支持集和边界都写入似然。以下分位数记为累计概率分位数 $P(T\le t_q)=q$，与上侧分位点记法区分。

基础题（自编）

独立伯努利样本共 $n$ 次、成功 $k$ 次，参数 $p\in[0,1]$。求最大似然估计，含 $k=0,n$。

查看完整解析

似然 $L(p)=p^k(1-p)^{n-k}$。$0<k<n$ 时对数导数 $k/p-(n-k)/(1-p)=0$，得 $p=k/n$，二阶导为负；$k=0$ 时 $(1-p)^n$ 在0最大，$k=n$ 时 $p^n$ 在1最大。统一为 $\hat p=k/n$。

综合题（自编）

样本来自 $U(0,\theta)$（取密度版本 $0\le x\le\theta$），求矩估计、MLE 及 MLE 的无偏修正。

查看完整解析

$E(X)=\theta/2$，故矩估计 $2\bar X$。令 $M=X_{(n)}$，似然为 $$\theta^{-n}\mathbf1_{\{\theta\ge M\}}$$，在可行域递减，MLE 为 $M$。$P(M\le m)=(m/\theta)^n$，积分得 $E(M)=n\theta/(n+1)$，故 $(n+1)M/n$ 无偏。

反例与易错：MLE 不一定无偏，上题最大次序统计量就是有偏估计；无偏也不能单独说明估计精度最好。

闭卷自测：正态总体方差未知时，均值双侧区间宽度中的标准误是什么？

$S/\sqrt n$，不是 $S^2/n$；再乘 $t_{1-\alpha/2}(n-1)$。

区间与检验：自由度、方向和结论

核心知识：先写原假设与备择再选统计量和拒绝域。正态均值已知方差用 $Z$，未知用 $t$；方差检验用 $\chi^2$，双总体方差比较用 $F$ 并核对独立正态条件。

条件与边界：本节分位数为累计概率分位数。双侧区间的对偶对应同一模型、同一显著性水平的双侧检验，不能直接套到单侧。

基础题（自编）

正态总体方差未知，$n=9,\bar x=5,S=1.5$。给 $t_{0.975}(8)=2.306$，求均值95%双侧区间。

查看完整解析

由 $$(\bar X-\mu)/(S/\sqrt n)\sim t(8)$$，区间为 $5\pm2.306(1.5/3)=5\pm1.153$，即 $[3.847,6.153]$。自由度8，标准误0.5。

综合题（自编）

正态总体方差已知为4，$n=25,\bar x=10.8$。检验 $H_0:\mu=10$ 对 $H_1:\mu>10$，$\alpha=0.05$，给 $z_{0.95}=1.645$。

查看完整解析

在 $H_0$ 下，$Z=(10.8-10)/(2/\sqrt{25})=2$。这是右侧检验，拒绝域 $Z>1.645$，所以拒绝 $H_0$，样本提供均值大于10的统计证据。不能误用双侧临界值或把结论写成无条件确定的事实。

反例与易错：$p=0.08>\alpha=0.05$ 时只能不拒绝原假设，不等于证明其正确，也不是“原假设正确的概率为8%”。

闭卷自测：方差未知的两样本合并方差 $t$ 检验还需要什么？

独立正态样本且两总体方差相等；自由度为 $n_1+n_2-2$，不能省略等方差前提。
