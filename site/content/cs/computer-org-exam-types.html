一、计算机性能指标计算题 ⭐⭐⭐

题型特征

  • 给出主频、CPI、指令条数等参数，计算CPU执行时间、MIPS、MFLOPS等
  • 选择题或综合题，408统考每年必考
  • 2022、2023、2024连续考查CPU执行时间与平均CPI计算

核心公式

CPU执行时间 = CPU时钟周期数 / 主频 = (指令条数 × CPI) / 主频
MIPS = 主频 / (CPI × 10⁶)
CPI = Σ(各类指令CPI × 所占比例)    ← 加权平均
程序执行总时间 = (总指令条数 × 平均CPI) / 主频

解题模板

Step 1：确定平均CPI（加权平均）

CPI_avg = Σ(CPI_i × 比例_i)

Step 2：代入CPU执行时间公式

T = (指令条数 × CPI_avg) / 主频

Step 3：注意单位换算

  • 主频：GHz = 10⁹Hz，MHz = 10⁶Hz
  • 时间：ns = 10⁻⁹s，μs = 10⁻⁶s，ms = 10⁻³s
  • MIPS：结果 = 主频(MHz) / CPI

涉及知识点：1.3节 计算机性能指标

常考真题示例

1.【2013统考真题】 某计算机主频1.2GHz，4类指令比例及CPI如下，求MIPS。

类型ABCD
比例50%20%10%20%
CPI2345

解：CPI = 2×0.5+3×0.2+4×0.1+5×0.2=3，MIPS=1200/3=400

2.【2023统考真题】 主频1.5GHz，指令条数5×10⁵，平均CPI=1.2，求执行速度(GIPS)和CPU时间。

解：IPS=1.5G/1.2=1.25GIPS，CPU时间=5×10⁵×1.2/1.5×10⁹=0.4ms

3.【2017统考真题】 比较M1(1.5GHz, CPI=2)与M2(1.2GHz, CPI=1)运行程序P的时间比。

解：时间比 = (2/1.5)/(1/1.2) = 1.6（M1时间是M2的1.6倍）

二、定点数编码与表示范围题 ⭐⭐⭐

题型特征

  • 给定机器数编码，判断真值、表示范围
  • 补码、移码与真值的相互转换
  • 给定若干个0和1组成的位串，求某种编码下的最大/最小值
  • 选择题为主，高频考点

核心解法

1. 四种编码对比记忆

编码n+1位整数范围+0/-0转换要点
原码-(2ⁿ-1)~2ⁿ-1有±0负数：符号1+绝对值
反码-(2ⁿ-1)~2ⁿ-1有±0负数：按位取反
补码-2ⁿ~2ⁿ-1唯一0负数：取反+1
移码-2ⁿ~2ⁿ-1唯一0=真值+2ⁿ

2. 补码快速解题技巧

负数补码判断大小（2015考点）：

  • 负数补码：数值部分越小，绝对值越大（越负）
  • 找最小负数 → 符号位1 + 数值位尽量小(min=全0)
  • 找最大负数 → 符号位1 + 数值位尽量大(max=全1)

补码转真值（2020、2023考点）：

若符号位=0 → 真值为正，直接读数值
若符号位=1 → 真值为负，数值"取反+1"得绝对值

涉及知识点：2.1.2节 定点数的编码表示

常考真题示例

1.【2015统考真题】 由3个"1"和5个"0"组成的8位二进制补码，最小整数是？

解：补码最小负数符号位必为1，剩余2个1放在数值最低位使数值最小→10000011→按位取反+1得绝对值11111101=125→真值-125

2.【2022统考真题】 32位补码所能表示的整数范围？

解：-2³¹ ~ 2³¹-1，选B

3.【2021统考真题】 已知x,y,z的机器数FFFDH,FFDFH,7FFCH，判断大小关系。

解：按补码规则：有符号时FFDFH

三、C语言类型转换题 ⭐⭐⭐

题型特征

  • 给定C语言代码片段，判断变量的最终值
  • 涉及short↔int转换、signed↔unsigned转换
  • 2011-2024连续考查，几乎每年1题
  • 纯选择题

核心解法

三种转换规则：

场景规则位变化值变化
长→短截断高位高位丢弃可能变化（隐蔽！）
同字长重新解释不变有符号↔无符号语义不同
短→长(有符号)符号扩展高位补符号位不变
短→长(无符号)零扩展高位补0不变

解题三步走：

  1. 写出源数据的二进制位模式（补码形式）
  2. 根据转换规则得到目标位模式
  3. 按目标类型解读位模式

涉及知识点：2.1.4节 C语言中的整数类型及类型转换

常考真题示例

1.【2016统考真题】

short si = -32767;
unsigned short usi = si;

求usi的值。

解：si=-32767的补码=0x8001（16位），同字长转换不改变位模式，usi按无符号解读=32769

2.【2019统考真题】

unsigned short usi = 65535;
short si = usi;

求si的值。

解：usi=65535=0xFFFF，同字长→si按有符号补码解读，全1=-1，选A(-1)

3.【2024统考真题】

short si = -32767;
unsigned int ui = si;

求ui的值。

解：si=-32767=0x8001(16位)→扩展为32位0xFFFF8001(符号扩展)→按无符号解读=2³²-32767

四、IEEE 754浮点数题 ⭐⭐⭐

题型特征

  • 十进制数↔IEEE 754单/双精度格式的相互转换
  • 浮点数加减运算（对阶、规格化、舍入）
  • 选择题+综合题均出现
  • 408统考必考重点

核心解法

1. 十进制→IEEE 754格式

步骤：

  1. 将十进制数转为二进制（规格化：±1.M×2^E）
  2. 符号位S：正为0，负为1
  3. 阶码e = E + 偏置值（单精度127，双精度1023），写为8位/11位
  4. 尾数M：去掉隐含的"1."，右补0凑满23/52位

2. 浮点数加减步骤

① 对阶：小阶向大阶看齐，尾数右移
② 尾数求和：定点加减法
③ 规格化：左规（尾数左移）或右规（尾数右移）
④ 舍入：0舍1入等
⑤ 溢出判断：阶码上溢/下溢

3. IEEE 754特殊值识别

值阶码尾数
0全0全0
±∞全1全0
NaN全1非0

涉及知识点：2.3节 浮点数的表示与运算

常考真题示例

1. 将-12.625转换为IEEE 754单精度浮点数。

解：12.625=1100.101=1.100101×2³，S=1，e=3+127=130=10000010，M=100101000...0

→ 1 10000010 10010100000000000000000

2. 浮点数加减中对阶操作时，遵循的规则是"小阶向大阶看齐"，原因是减少精度损失。

补充：定点运算与标志位题 ⭐⭐

题型特征

  • 给定补码加减结果，判断是否溢出
  • 判断OF、CF、ZF、SF等标志位
  • 区分算术移位、逻辑移位，以及补码乘除中的符号扩展
  • 选择题高频，偶尔结合ALU数据通路考查

核心解法

1. 补码溢出判断

方法判断规则适用
符号位法同号相加结果异号则溢出；异号相加不溢出带符号补码加法
进位法符号位进位与最高数值位进位不同则OF=1硬件标志位判断
双符号位法00/11正常，01正溢出，10负溢出变形补码

2. 标志位速查

标志位含义看什么
OF带符号数溢出同号加异号结果，或符号位进位异或
CF无符号数进位/借位最高位是否产生进位或借位
ZF结果为0结果所有位是否全0
SF结果符号结果最高位

3. 移位与乘除易错点

  • 逻辑右移高位补0；算术右移高位补符号位。
  • 左移可能改变符号并造成溢出，不能简单等同于乘2。
  • 补码乘除运算中，右移通常为算术右移，注意符号扩展。

涉及知识点：2.2节 运算方法和运算电路

五、Cache映射与计算题 ⭐⭐⭐

题型特征

  • 根据主存容量、Cache容量、块大小等参数，计算地址划分（tag/index/offset位数）
  • 三种映射方式（直接、全相联、组相联）的地址分析和命中率比较
  • Cache替换算法（LRU）的模拟判断
  • 选择题和综合题均有出现
  • 近几年高频考点（2016-2024）

核心解法

1. 地址划分计算

直接映射：

主存地址 = {标记(tag), Cache行号(index), 块内地址(offset)}
offset位数 = log₂(块大小)
index位数  = log₂(Cache行数)
tag位数    = 主存地址总位数 - offset位数 - index位数

n路组相联映射：

组数 = Cache行数 / n
index位数 = log₂(组数)
主存地址 = {标记(tag), 组号(index), 块内地址(offset)}

全相联映射：

主存地址 = {标记(tag), 块内地址(offset)}
tag位数 = 主存地址总位数 - offset位数

2. LRU替换算法模拟

对每组（或整个Cache）中的块，记录最近使用顺序：

  • 最近访问的块 → 排到最前
  • 需要替换时 → 替换排在最后的块（最久未用）

3. Cache性能计算

命中率 H = 命中次数 / 总访问次数
平均访问时间 = H × Cache访问时间 + (1-H) × 主存访问时间

涉及知识点：3.3节 主存与Cache的映射

常考真题示例

1. 主存容量64KB，Cache容量4KB，块大小为16B，按字节编址。求直接映射时tag/index/offset的位数。

解：主存地址16位。offset=log₂16=4位。Cache行数=4K/16=256→index=log₂256=8位。tag=16-8-4=4位。

2. 对于连续地址序列{0,1,2,...,7,0,1,...,7,0,1,2,3}的访存，在2路组相联(每组2行)、LRU替换、块大小=4、Cache共4行的情况下，求命中率。

解：Cache共4行，2路组相联→共2组，每组2行。地址0-3在块0，4-7在块1。块0映射到组0，块1映射到组1。序列分析可得命中率。

补充：DRAM刷新与存储芯片扩展题 ⭐⭐

题型特征

  • 计算DRAM刷新间隔、刷新死时间、刷新次数
  • 根据芯片容量和主存容量计算芯片片数
  • 判断字扩展、位扩展、字位同时扩展
  • 结合地址线、数据线、片选信号考查

核心解法

1. DRAM刷新计算

刷新间隔 = 刷新周期 / 行数
集中刷新死时间 = 行数 × 单行刷新时间
异步刷新：每隔“刷新间隔”刷新一行
刷新方式判断关键词易错点
集中刷新集中一段时间刷新所有行有死时间
分散刷新每个存取周期后刷新一行存取周期变长
异步刷新均匀分散到刷新周期内常考刷新间隔

2. 存储芯片扩展

位扩展片数 = 目标字长 / 单芯片位宽
字扩展组数 = 目标字数 / 单组字数
总芯片数 = 位扩展片数 × 字扩展组数
芯片内地址线 = log₂(单芯片字数)

解题提醒：先统一单位。若题目“按字节编址”，容量要换成字节数再求地址线；若芯片写成 16K×4位，16K是字数，4位是位宽。

涉及知识点：3.2节 主存储器

六、指令寻址与地址计算题 ⭐⭐

题型特征

  • 给定寻址方式和参数，计算有效地址(EA)
  • 基址、变址、相对三种偏移寻址的地址计算与区别
  • 选择题为主，较小概率出综合题

核心解法

寻址方式EA公式应用场景
立即寻址操作数=指令中直接给出常量赋值
直接寻址EA=A（指令地址码）访问固定地址变量
间接寻址EA=(A)指针访问
寄存器寻址EA=Ri寄存器变量
寄存器间接EA=(Ri)指针变量
相对寻址EA=(PC)+A转移/循环/重定位
基址寻址EA=(BR)+A多道程序/重定位
变址寻址EA=(IX)+A数组/字符串处理
堆栈寻址隐含SP函数调用/参数传递

三种偏移寻址对比（易混淆）：

寻址基地址偏移量来源用途
相对PC提供指令地址码A程序转移
基址BR提供指令地址码A程序重定位
变址指令地址码AIX提供数组循环

涉及知识点：4.2节 寻址方式

补充：扩展操作码编码题 ⭐⭐

题型特征

  • 给定指令字长、地址码长度和各类地址指令数量，判断能否编码
  • 计算某类指令最多还能设计多少条
  • 区分定长操作码与扩展操作码

核心解法

通用思路：短地址指令的未用编码，可作为长操作码指令的前缀。

某层剩余前缀数 = 该层操作码总编码数 - 已分配该层指令条数
下一层可扩展条数 = 剩余前缀数 × 2^(释放出的地址码位数)

做题步骤

  1. 画出指令格式：操作码字段 + 地址码字段。
  2. 从地址码最多的指令开始分配，因为它的操作码最短。
  3. 每少一个地址码，就把释放出的地址码位并入操作码扩展。
  4. 检查各层已用编码是否超过可用编码数。

易错点：不能只看最终总编码数是否够，还要看每一层前缀是否已经被短操作码占满。

涉及知识点：4.1节 指令格式

七、CISC vs RISC 对比题 ⭐

题型特征

  • 选择题给出若干条CISC/RISC的特点，判断正误
  • 通常以对比表格形式出现
  • 几乎每年1题

核心解法

背记CISC和RISC的核心区别：

维度CISCRISC
指令数量多少
指令长度变长定长（多为32位）
寻址方式多少
访存方式多种指令可访存仅LOAD/STORE
控制器微程序硬布线
寄存器少多
流水线不易实现容易实现
编译器简单复杂
代表x86ARM, MIPS, RISC-V

涉及知识点：4.3节 CISC和RISC

八、数据通路与指令执行分析题 ⭐⭐

题型特征

  • 分析某条指令通过数据通路各阶段的控制信号流程
  • 画出单总线结构下指令的执行流程（取指周期、执行周期）
  • 比较多总线结构的优劣
  • 综合题为主

核心解法

单总线结构下的典型指令执行流程：

取指周期（公共操作）：

PC→MAR, 读存储器 → MDR→IR, PC+1→PC

加法指令 ADD R0, R1 的执行周期：

R1→Y（暂存）, R0+Y→Z（ALU运算）, Z→R0（写回）

涉及知识点：5.1-5.3节 CPU结构与控制器

补充：微程序控制器题 ⭐⭐

题型特征

  • 判断微命令、微操作、微指令、微程序、机器指令之间的关系
  • 计算控制存储器容量
  • 比较水平型/垂直型微指令，直接编码/字段编码
  • 分析微地址形成方式

核心解法

1. 层次关系

机器指令
  └─ 对应一段微程序
       └─ 多条微指令
            └─ 多个微命令，控制多个微操作

2. 控制存储器容量

控制存储器容量 = 微指令条数 × 微指令字长
若结果为bit，换算Byte时除以8

3. 微指令格式对比

项目水平型微指令垂直型微指令
并行性强弱
字长长短
执行速度快慢
编码复杂度低，控制位多高，需译码

4. 编码方式对比

  • 直接编码：一个控制信号一位，最快但最长。
  • 字段直接编码：互斥微命令分组编码，需译码。
  • 字段间接编码：一个字段解释依赖另一个字段，最省位但最慢。

涉及知识点：5.3节 控制器的功能和工作原理

九、指令流水线冒险分析与性能计算题 ⭐⭐⭐

题型特征

  • 给定代码序列，分析数据冒险和控制冒险
  • 流水线时空图绘制与分析
  • 计算流水线的吞吐率、加速比、效率
  • 408统考高频综合题考点

核心解法

1. 数据冒险识别与解决

RAW（写后读）冒险：

  • 识别：前条指令写某寄存器，后条指令读同一寄存器且间隔<流水段数
  • 解决：转发/旁路（将EX/MEM或MEM/WB结果直接前递到EX阶段输入）

Load-Use冒险：

  • LOAD指令后紧跟使用其结果的指令
  • 必须插入一个气泡/阻塞(stall)，转发无法完全解决

2. 控制冒险处理

方式说明
阻塞等转移结果，损失2-3个时钟
静态分支预测"总是预测不跳转"
动态分支预测BTB记录历史跳转信息
延迟分支转移指令后插入一条不受影响的指令

3. 流水线性能计算

经典五段流水线（IF-ID-EX-MEM-WB）：

执行n条指令所需时间：T = k + n - 1 个时钟周期（k=5）
非流水执行：T_non = k × n
加速比：S = (k×n)/(k+n-1)
吞吐率：TP = n/(k+n-1) (条/时钟周期)
效率：E = n/(k+n-1)

涉及知识点：5.5节 指令流水线

常考真题示例

1. 分析以下代码段在五段流水线中各存在何种数据冒险及解决方式：

ADD R1, R2, R3  // R1←R2+R3
SUB R4, R1, R5  // R4←R1-R5  ← RAW冒险于R1
AND R6, R1, R7  // R6←R1&R7  ← RAW冒险于R1

解：ADD在EX段产生R1，SUB在EX段需要R1→需一次转发。AND在EX段需要R1→ADD在MEM段转发。

2. 五段流水线执行100条指令，无冒险时，需多少周期？加速比？

解：T=5+100-1=104周期。非流水=5×100=500。加速比=500/104≈4.81。

十、中断与DMA方式对比题 ⭐⭐

题型特征

  • 比较程序查询、中断、DMA三种I/O方式的特点与适用场景
  • 中断响应过程及中断向量计算
  • DMA传送过程
  • 选择题为主

核心解法

特性程序查询程序中断DMA
CPU参与数据传送全程每次传送仅开始和结束
传送单位字/字节字/字节数据块
对CPU利用率影响极大(踏步等待)中等(中断开销)小(仅初始化)
适用设备速度极低速中低速高速
额外硬件无中断控制器DMA控制器
数据传送路径设备→CPU→主存设备→CPU→主存设备↔主存(绕过CPU)

涉及知识点：7.2节 I/O控制方式

常考真题示例

1. 比较程序中断和DMA方式，DMA方式的主要优势是？

答：DMA方式下数据在设备和主存之间直接传送，不经CPU中转，传送过程CPU可继续执行其他程序，大幅提高CPU利用率。每次DMA传送整块数据，而不是逐字传送。

2. CPU响应DMA请求与响应中断请求的时刻有何不同？

答：CPU通常在每条指令执行结束时采样中断请求；但DMA请求可在任何总线周期结束时被响应（只要CPU不占用总线）。

十一、存储器扩展与交叉编址题 ⭐⭐

题型特征

  • 根据存储芯片容量和主存容量，计算所需芯片数和地址线数
  • 低位交叉编址下连续地址的访问时间计算
  • 选择题+综合题

核心解法

存储器芯片数量计算：

所需芯片数 = (主存容量) / (单芯片容量)

低位交叉编址访问时间：

  • m体低位交叉，存取周期T，总线周期τ
  • 连续访问m个地址的时间 = T + (m-1)×τ
  • 若τ << T，可实现接近m倍的带宽提升

涉及知识点：3.2节 主存储器

十二、总线带宽与定时方式题 ⭐

  • 计算总线带宽、传输时间
  • 同步/异步定时方式特点判断

  • 选择题为主

核心解法

总线带宽计算：

总线带宽 = 总线宽度(字节) × 总线时钟频率 / 每次传输所需时钟数
猝发传输带宽 = 数据总量 / (地址阶段 + 数据阶段×n)

定时方式判定：

特征同步异步半同步
时钟控制统一时钟握手信号时钟+等待
速度快较慢较快
灵活性低高中
